# CSV ตัวชี้วัดหลักสูตรแกนกลาง (Q-matrix)

ไฟล์ในโฟลเดอร์นี้คือรายการ **สาระ → มาตรฐาน → ตัวชี้วัด** ที่ admin นำเข้าระบบ (DESIGN §2.3, §20.2) ครูใช้เลือกตัวชี้วัดให้ข้อในการบ้าน รายวิชา หน่วย และแผนการสอน และระบบใช้คิดความเข้าใจ (mastery) และกราฟ

- `template.csv` คือ**ตัวอย่างรูปแบบ** 3 แถว (สาระ มาตรฐาน ตัวชี้วัด อย่างละหนึ่ง) ไม่ใช่รายการทั้งหมด
- ไฟล์ทั้งหลักสูตรทีมเป็นคนเตรียม (ดูหัวข้อ "เตรียมไฟล์ทั้งหลักสูตร") ห้ามแต่งหรือสรุปข้อความเอง ให้คัดลอกจากเอกสารหลักสูตรทางการเท่านั้น
- งานเดิมใน KICKOFF (งานที่ 1) ใช้รูปแบบเดิม 5 คอลัมน์ ไฟล์แบบนั้นยัง import ได้ (ดูหัวข้อ "รูปแบบเดิม")

## รูปแบบไฟล์

UTF-8 **ไม่มี BOM** คั่นด้วยจุลภาค แถวแรกเป็นหัวตาราง ช่องที่มีจุลภาคอยู่ในข้อความให้ครอบด้วย `"…"` (Google Sheets ทำให้เองตอน export)

```csv
subject_code,level,code,parent_code,grade_level,name
ค,strand,ค 1,,,จำนวนและพีชคณิต
ค,standard,ค 1.1,ค 1,,เข้าใจความหลากหลายของการแสดงจำนวน ระบบจำนวน …
ค,indicator,ค 1.1 ป.5/1,ค 1.1,5,แสดงวิธีหาคำตอบของโจทย์ปัญหาการบวก การลบ การคูณ การหารเศษส่วนและจำนวนคละ
```

| คอลัมน์ | ต้องมี | ความหมาย |
|---|---|---|
| `subject_code` | ✓ | อักษรกลุ่มสาระ `ท` `ค` `ว` `ส` `พ` `ศ` `ง` `ต` (ไม่เกิน 20 ตัวอักษร) กลุ่มสาระที่ยังไม่มีในระบบจะถูกสร้างให้ |
| `level` | ✓ (รูปแบบใหม่) | `strand` (สาระ), `standard` (มาตรฐาน), `indicator` (ตัวชี้วัด) หรือ `sub_indicator` (ทักษะย่อยของโรงเรียน ไม่ใส่ในไฟล์หลักสูตร) |
| `code` | ✓ | รหัสตามเอกสาร เช่น `ค 1` `ค 1.1` `ค 1.1 ป.5/1` ไม่เกิน 40 ตัวอักษร **ห้ามซ้ำกันในไฟล์** |
| `parent_code` | | รหัสของแถวแม่: มาตรฐาน → สาระ, ตัวชี้วัด → มาตรฐาน สาระต้องเว้นว่าง แถวแม่อยู่ก่อนหรือหลังแถวลูกในไฟล์ก็ได้ |
| `grade_level` | | ชั้นของตัวชี้วัด 1–12 (ป.1 = 1 … ป.6 = 6, ม.1 = 7 … ม.6 = 12) สาระและมาตรฐานเว้นว่าง ตัวชี้วัดช่วงชั้น ม.4–6 (เช่น `ม.4-6/1`) เว้นว่าง |
| `name` | ✓ | ข้อความของสาระ มาตรฐาน หรือตัวชี้วัด ตามเอกสาร ไม่ต้องใส่รหัสซ้ำในข้อความ |

ลำดับคอลัมน์ไม่สำคัญ (ระบบดูจากหัวตาราง) คอลัมน์รหัสจะชื่อ `code` หรือ `skill_code` ก็ได้ แต่ห้ามมีทั้งสองคอลัมน์ คอลัมน์ที่ระบบไม่รู้จักจะถูกข้ามพร้อมคำเตือน

**การเขียนรหัส** ให้เขียนแบบเดียวกันทั้งไฟล์ตามเอกสาร (เว้นวรรคหลังอักษรกลุ่มสาระ และหลังเลขมาตรฐาน เช่น `ค 1.1 ป.5/1`) ระบบจับคู่รหัสที่ AI อ่านจากเอกสารของครูกับรหัสในไฟล์โดยไม่สนใจช่องว่างและจุด (§20.1) แต่รหัสที่ครูเห็นในแอปคือรหัสในไฟล์นี้

## รูปแบบเดิม (ยังใช้ได้)

```csv
subject_code,skill_code,parent_code,grade_level,name
```

ไม่มีคอลัมน์ `level` ระบบถือว่าแถวที่ไม่มี `parent_code` เป็นตัวชี้วัด และแถวที่มี `parent_code` เป็นทักษะย่อย ไฟล์ทั้งหลักสูตรควรใช้รูปแบบใหม่เพื่อให้กราฟแยกตามมาตรฐานได้ (§20.3)

## เตรียมไฟล์ทั้งหลักสูตร

1. ดาวน์โหลดเอกสารหลักสูตรแกนกลางการศึกษาขั้นพื้นฐานฉบับที่โรงเรียนใช้จริง (ตัวชี้วัดและสาระการเรียนรู้แกนกลางของแต่ละกลุ่มสาระ) จากเว็บของหน่วยงานที่ออกเอกสาร เก็บ PDF ไว้ใน Drive `01-curriculum/sources/` และจดชื่อเอกสาร ปี และหน้าที่ใช้ลงตาราง "แหล่งที่มา" ด้านล่าง
2. พิมพ์ใน Google Sheet แยกแท็บต่อกลุ่มสาระ (หัวตารางตาม `template.csv`) ทีละสาระ → มาตรฐาน → ตัวชี้วัดของทุกชั้นตามลำดับในเอกสาร คัดลอกข้อความตรงตัว
3. ตรวจในชีตก่อน export: รหัสไม่ซ้ำ (`=COUNTIF(C:C, C2)=1`), ทุก `parent_code` มีอยู่ในคอลัมน์ `code` (`=OR(D2="", COUNTIF(C:C, D2)>0)`), `level` สะกดถูก
4. File → Download → Comma Separated Values แล้วเปิดด้วย VS Code ดูว่าเป็น `UTF-8` ไม่ใช่ `UTF-8 with BOM` **ห้ามเปิดแล้วบันทึกทับด้วย Excel** (Excel ใส่ BOM และอาจเปลี่ยนรหัสที่ดูเหมือนตัวเลข)
5. ตั้งชื่อไฟล์ `curriculum-<กลุ่มสาระ>.csv` เช่น `curriculum-math.csv` แล้วอัปโหลดเข้าโฟลเดอร์นี้ผ่านหน้าเว็บ GitHub (branch ใหม่ + PR ตาม KICKOFF) หลายไฟล์ import ทีละไฟล์ได้

ไฟล์เหล่านี้เป็นข้อมูลสาธารณะของหลักสูตร ใส่ใน repo ได้ แต่**ห้ามมีข้อมูลนักเรียน**หรือข้อมูลเฉพาะของโรงเรียน

## การนำเข้า

- **Filament** (admin): หน้า "ทักษะ (ตัวชี้วัด)" → ปุ่ม "นำเข้า CSV" (ไม่เลือกโรงเรียน = หลักสูตรแกนกลางของทุกโรงเรียน) ไฟล์ไม่เกิน 20 MB
- **คำสั่ง**: `php artisan eduvision:import-skills docs/curriculum/curriculum-math.csv` (ใส่ `--school=<id>` เมื่อเป็นแถวของโรงเรียน)

ผลการนำเข้ารายงานเป็น `สร้างใหม่ / อัปเดต / ไม่เปลี่ยน` และรายการ `บรรทัด n: ปัญหา`

- แถวที่ผิด (รหัสว่างหรือซ้ำ, `level` ผิด, ชั้นไม่อยู่ใน 1–12, จำนวนคอลัมน์ไม่ครบ) ถูก**ข้าม** แถวอื่นยังนำเข้า แก้แล้ว import ไฟล์เดิมซ้ำได้
- `parent_code` ที่หาไม่เจอ: แถวนั้นถูกบันทึกโดยไม่เปลี่ยนแถวแม่ และแจ้งเลขบรรทัด
- ถ้าหัวตารางผิดหรือไฟล์ไม่มีข้อมูล จะไม่มีอะไรถูกบันทึกเลย
- **import ซ้ำได้เสมอ**: แถวที่มี `code` เดิมถูกอัปเดต (ไม่สร้างซ้ำ) และแถวที่หายไปจากไฟล์**ไม่ถูกลบ** เพราะอาจมีผลการประเมินของนักเรียนอยู่แล้ว ถ้าต้องลบจริงให้แจ้งผู้พัฒนา
- import ได้ทีละงาน ถ้ามีอีกงานกำลังทำอยู่ระบบจะให้ลองใหม่ภายหลัง ไฟล์หลายหมื่นแถวใช้เวลาไม่กี่วินาที

## ตัวชี้วัดที่ครูเพิ่มเอง

ถ้าหลักสูตรที่นำเข้าขาดตัวชี้วัดที่ครูต้องใช้ ครูเพิ่มได้ในแอปใต้มาตรฐาน (เป็นตัวชี้วัด) หรือใต้ตัวชี้วัด (เป็นทักษะย่อย) ตัวที่ครูเพิ่มเป็นของโรงเรียนนั้นเท่านั้น ครูทุกคนในโรงเรียนเห็นและเลือกใช้ได้ และแอปแสดงป้าย **"ครูเพิ่มเอง"** ถ้าครูไม่ใส่รหัส ระบบตั้งให้เป็น `<รหัสแถวแม่>/ค<ลำดับ>` เช่น `ค 1.1/ค1` (§20.2, §20.7)
