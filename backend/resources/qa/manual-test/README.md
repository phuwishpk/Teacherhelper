# ทดสอบด้วยมือ: เส้นทางเว็บตั้งแต่สมัครจนตัดเกรด

checklist นี้พาทดสอบ Krucheck บน **production** (`https://teacherhelper.phuwish.com/app/`) ครบเส้นทางหลักของเว็บแอป ตั้งแต่ครูสมัครบัญชี นักเรียนเข้าห้อง การบ้าน AI ตรวจ ตรวจทาน ขอตรวจใหม่ เช็คชื่อ จนถึงประกาศเกรด ทำตามเลข 1 ถึง 128 ตามลำดับ เพราะแต่ละข้อใช้ผลของข้อก่อนหน้า ข้อ 81–128 คือเส้นทาง Google Classroom (ครูมีชั้นเรียนใน Classroom นักเรียนเข้าชั้นเรียนของครู แล้ว Krucheck ดึงงานมาตรวจและส่งคะแนนกลับ) ข้ามได้ถ้ารอบนี้ไม่ทดสอบ Classroom

- **ผู้เล่น**: **ครู** 1 บัญชี, **นร.1** และ **นร.2** (นักเรียน 2 บัญชี), **นร.3** (ใช้เฉพาะส่วน Google Classroom: มีชื่ออยู่ใน Classroom เท่านั้น ยังไม่มีบัญชี Krucheck) และ **แอดมิน** (บัญชีผู้ดูแลระบบที่มีอยู่แล้ว ใช้อนุมัติครูในข้อ 11–13 และหน้าทดสอบการเชื่อม Google) ส่วน Google Classroom ต้องมี **ผู้พัฒนา** (เจ้าของ Google Cloud project) ทำข้อ 81 ให้ก่อน
- **เวลา**: ประมาณ 2–3 ชั่วโมงสำหรับข้อ 1–80 และอีก 1–1.5 ชั่วโมงสำหรับ Google Classroom ส่วนใหญ่รอ AI ตรวจ (ข้อละ 1–3 นาที) และรอซิงก์กับ Classroom (ไม่เกิน 5 นาที)
- **ตรงกับ Test Lab**: เส้นทางนี้คือสถานการณ์ PR-01 (เริ่มใช้), PR-03 (การบ้านที่ไม่ใช้ใบงาน) และ PR-05 (ตัดเกรด) ฉบับเว็บ บวกการตรวจทานกับขอตรวจใหม่ของ PR-02 ส่วน Google Classroom คือ PR-06, IT-M07 และ IT-M08 บันทึกผลซ้ำใน `/qa/run` ได้
- **ไม่รวม**: สแกนใบงานและข้อสอบกระดาษด้วยกล้อง (ต้องใช้แอป Android) และส่งคะแนนสอบไป Classroom

> **ติ๊กบนเว็บได้**: เปิดหน้า **เช็คลิสต์ทดสอบด้วยมือ** ใน Test Lab (`/qa/checklist`) ติ๊กทีละข้อได้ (จำไว้ในเบราว์เซอร์ที่ใช้) และกดดาวน์โหลดไฟล์ทดสอบได้จากหน้านั้น
