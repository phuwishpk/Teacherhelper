# สมุดคะแนนและการตัดเกรด

สมุดคะแนนรวมคะแนนของทุกงานในรายวิชาไว้ในตารางเดียว คะแนนจากการบ้านและข้อสอบที่ตรวจด้วยแอปเข้ามาเองหลังเผยแพร่ผล ครูเพิ่มรายการที่ให้คะแนนนอกแอปได้ เช่น จิตพิสัย โครงงาน หรือการเข้าเรียน แล้วระบบคิดคะแนนรวมและเกรดตามน้ำหนักและเกณฑ์ที่ครูตั้ง

| คำ | ความหมาย |
|---|---|
| **หมวดคะแนน** | กลุ่มของรายการคะแนน เช่น คะแนนเก็บ กลางภาค ปลายภาค แต่ละหมวดมี **น้ำหนัก** เป็นร้อยละ รวมกันต้องเท่ากับ 100 |
| **รายการคะแนน** | หนึ่งคอลัมน์ในสมุดคะแนน ได้แก่ การบ้าน ข้อสอบ หรือรายการที่ครูเพิ่มเอง |
| **เกณฑ์เกรด** | คะแนนรวมขั้นต่ำของเกรด 4, 3.5, 3, 2.5, 2, 1.5 และ 1 |
| **ประกาศเกรด** | ทำให้นักเรียนเห็นเกรด คะแนนรวม และคะแนนรายหมวดของตัวเอง |

สมุดคะแนนเป็นของ **รายวิชา** การตั้งค่าหมวดและเกณฑ์เกรดใช้ร่วมกันทุกห้องของรายวิชานั้น ส่วนคะแนนและการประกาศเกรดแยกตามห้อง

## แท็บตัดเกรด

เปิดแท็บ **ตัดเกรด** จะเห็นรายวิชาของครูแยกตาม **ปีการศึกษา** (และภาคเรียน ถ้าปีนั้นมีมากกว่าหนึ่งภาค)

แต่ละห้องของรายวิชามีป้ายสถานะหนึ่งป้าย

| ป้าย | ความหมาย |
|---|---|
| **ยังไม่ตั้งหมวดคะแนน** | ยังไม่ได้เริ่มสมุดคะแนนของรายวิชานี้ กด **ตั้งค่าหมวดคะแนน** |
| **ยังขาดคะแนน N หมวด** | บางหมวดยังไม่มีรายการที่นับคะแนนได้ จึงยังตัดเกรดไม่ได้ |
| **พร้อมประกาศ** | ทุกหมวดมีคะแนนแล้ว ประกาศเกรดได้ |
| **ประกาศแล้ว (วันที่)** | นักเรียนเห็นเกรดแล้ว |
| **ประกาศแล้ว แต่คะแนนเปลี่ยน** | มีการแก้คะแนนหรือการตั้งค่าหลังประกาศ นักเรียนยังเห็นฉบับเดิมจนกว่าจะประกาศใหม่ |

ป้ายสีแดง **อาจติด มส N คน** และ **ร N · มส N** จะขึ้นเมื่อมีนักเรียนเข้าข่าย ไอคอนท้ายแถวสามอันคือ **เปิดสมุดคะแนน** (เหมือนแตะที่แถว) **ตั้งค่าสมุดคะแนน** และ **ส่งออก CSV**

## เริ่มสมุดคะแนนและตั้งหมวดคะแนน

### เริ่มครั้งแรก

เปิดสมุดคะแนนของรายวิชาที่ยังไม่เคยตั้งค่า (จากแท็บตัดเกรด หรือปุ่ม **สมุดคะแนน** ในหน้ารายวิชา) ระบบแสดงหน้า **เริ่มสมุดคะแนน** ให้เลือกรูปแบบตั้งต้น

| ตัวเลือก | หมวดที่ได้ |
|---|---|
| **คะแนนเก็บ 70 : ปลายภาค 30** | คะแนนเก็บ 70% (หมวดของการบ้าน) และปลายภาค 30% |
| **การบ้าน 30, กลางภาค 20, ปลายภาค 30, จิตพิสัย 20** | สี่หมวดตามชื่อ โดยการบ้านเป็นหมวดของการบ้าน |
| **ตั้งหมวดเอง** | เริ่มจากหน้าว่าง |

หลังเลือก ระบบเปิดหน้าตั้งค่าให้ปรับต่อได้ทันที การบ้านที่มีอยู่แล้วของรายวิชาจะเข้าไปอยู่ใน **หมวดตั้งต้นของการบ้าน** ส่วนข้อสอบต้องเลือกหมวดเองในฟอร์มของข้อสอบ รูปแบบตั้งต้นเลือกได้ครั้งเดียว หลังจากนั้นให้แก้ที่หน้าตั้งค่า

### หน้าตั้งค่าสมุดคะแนน

**หมวดคะแนน** (สูงสุด 10 หมวด)

- **ชื่อหมวด** และ **น้ำหนัก** เป็นร้อยละ แถบด้านล่างบอก **รวม X%** เป็นสีเขียวเมื่อเท่ากับ 100 พอดี ปุ่ม **บันทึก** กดได้เมื่อรวมได้ 100 เท่านั้น
- รายการเลือก **ไม่ตัดคะแนนต่ำสุด** หรือ **ตัดต่ำสุด 1–5 รายการ** ระบบจะไม่นับรายการที่นักเรียนได้ร้อยละต่ำสุดของหมวดนั้นตามจำนวนที่ตั้ง (เหลืออย่างน้อยหนึ่งรายการเสมอ)
- ป้าย **หมวดตั้งต้นของการบ้าน** แตะเพื่อเลือกหมวดที่การบ้านใหม่จะเข้าไปอยู่เอง เลือกได้หมวดเดียว
- ลากไอคอนขีดสองขีดด้านขวาเพื่อเรียงลำดับ ไอคอนถังขยะใช้ **ลบหมวด** และ **เพิ่มหมวด** อยู่ใต้รายการ

ถ้าลบหมวดที่มีรายการอยู่ รายการเหล่านั้นจะกลายเป็น **ยังไม่ระบุหมวด** และไม่นับในคะแนนจนกว่าจะเลือกหมวดใหม่

**เกณฑ์เกรด (คะแนนรวมขั้นต่ำ)**

กรอกคะแนนขั้นต่ำของเกรดทั้ง 7 ระดับเป็นจำนวนเต็ม ลดหลั่นจากเกรด 4 ลงไปเกรด 1 และห้ามซ้ำกัน กด **ใช้ค่าตั้งต้น** เพื่อเติม 80 / 75 / 70 / 65 / 60 / 55 / 50 คะแนนรวมที่ต่ำกว่าเกณฑ์ของเกรด 1 ได้เกรด 0

เสร็จแล้วกด **บันทึก**

**แก้การตั้งค่าหลังประกาศเกรดได้**
ระบบไม่ล็อกการตั้งค่าหลังประกาศ ถ้าแก้หมวด น้ำหนัก เกณฑ์เกรด หรือคะแนน ห้องนั้นจะขึ้นว่า **ประกาศแล้ว แต่คะแนนเปลี่ยน** นักเรียนยังเห็นฉบับที่ประกาศไว้จนกว่าครูจะกด **ประกาศใหม่**

## อ่านตารางสมุดคะแนน

| ส่วนของตาราง | ความหมาย |
|---|---|
| แถบบนสุด | สถานะการประกาศ และปุ่ม **เพิ่มรายการคะแนน**, **ประกาศเกรด** (หรือ **ประกาศใหม่**), **ส่งออก CSV**, **ถอนประกาศ** |
| **เลขที่** และ **ชื่อ** | ตรึงไว้ทางซ้าย แตะแถวเพื่อดูรายละเอียดคะแนนของนักเรียน |
| กลุ่มคอลัมน์ **(ชื่อหมวด) (น้ำหนัก%)** | รายการคะแนนของหมวดนั้น หัวคอลัมน์บอกชื่อรายการและคะแนนเต็ม |
| ไอคอนดินสอหน้าชื่อรายการ | รายการที่ครูกรอกคะแนนเองในตารางนี้ ไอคอนปฏิทินคือรายการคะแนนการเข้าเรียน |
| คอลัมน์สีจาง | รายการที่ยังไม่นับคะแนนในห้องนี้ เช่น การบ้านที่ยังไม่ถึงกำหนดส่งและยังไม่เผยแพร่ผล รายการที่ยังไม่มีใครมีคะแนน หรือรายการที่ตั้งเป็น **ไม่นับเกรด** |
| กลุ่ม **สรุป** | ร้อยละของแต่ละหมวด **รวม** (คะแนนรวมที่ปัดเป็นจำนวนเต็มแล้ว) และ **เกรด** |

ถ้ารายวิชามีหลายห้อง จะมีป้ายชื่อห้องด้านบนให้สลับ ไอคอนตัวเลื่อนมุมขวาบนเปิดหน้าตั้งค่า

ข้อความที่อาจเห็นในช่องคะแนน

| ข้อความ | ความหมาย | นับคะแนนอย่างไร |
|---|---|---|
| ตัวเลข | คะแนนที่ได้ | นับตามจริง |
| **ไม่ส่ง** | งานที่ตรวจด้วยแอป ไม่ได้ส่ง และเลยกำหนดหรือปิดรับแล้ว | นับเป็น 0 |
| **ไม่มีคะแนน** | รายการที่ครูกรอกเองแต่เว้นว่างไว้ | นับเป็น 0 |
| **ยังไม่ถึงกำหนด** | ยังไม่เลยวันส่ง | ไม่นับ |
| **รอประกาศผล** | ส่งแล้ว แต่ครูยังไม่เผยแพร่ผล | ไม่นับ |
| **ยกเว้น** | ครูยกเว้นรายการนี้ให้นักเรียนคนนี้ | ไม่นับ |
| **ไม่ได้รับมอบ** | การบ้านที่ครูมอบให้นักเรียนบางคน (ส่งถึง **เลือกนักเรียน** หัวข้อ 5.1) และนักเรียนคนนี้ไม่ได้รับมอบ | ไม่นับ และไม่กลายเป็น 0 เมื่อเลยกำหนด |
| คะแนนขีดฆ่า **ตัดออก** | ถูกตัดตามกฎตัดคะแนนต่ำสุดของหมวด | ไม่นับ |
| **–** | คอลัมน์ที่ยังไม่นับ | ไม่นับ |

ป้ายหลังชื่อนักเรียน: **ร** หรือ **มส** (เกรดพิเศษที่ครูตั้ง) **อาจติด มส** (คำเตือนอัตโนมัติ) และ **ออกจากรายวิชา**

แถบข้อความเหนือตารางเตือนสิ่งที่ควรรู้ เช่น **คะแนนระหว่างภาค: ยังไม่มีรายการที่นับในหมวด … ยังตัดเกรดและประกาศเกรดไม่ได้** หรือ **มี N รายการที่ยังไม่ระบุหมวด (ไม่นับ) เลือกหมวดได้ที่ฟอร์มของงานหรือข้อสอบ**

## กรอกและแก้คะแนน

### เพิ่มรายการคะแนน

ใช้กับคะแนนที่ให้นอกแอป กด **เพิ่มรายการคะแนน** แล้วกรอก

| ช่อง | ความหมาย |
|---|---|
| **ชื่อรายการ** | ไม่เกิน 100 ตัวอักษร |
| **คะแนนเต็ม** | มากกว่า 0 ไม่เกิน 1,000 ทศนิยมได้ 2 ตำแหน่ง |
| **หมวดคะแนน** | หมวดที่รายการนี้อยู่ |
| **เป็นคะแนนการเข้าเรียน** | เปิดเมื่อรายการนี้คือคะแนนการเข้าเรียน ระบบใช้เตือน **อาจติด มส** เมื่อต่ำกว่า 80% |
| **เพิ่มให้ทุกห้องของรายวิชา** | มีเมื่อรายวิชามีหลายห้อง เปิดเพื่อสร้างรายการเดียวกันให้ทุกห้อง |

### กรอกคะแนนทีละช่อง

แตะช่องของนักเรียนในคอลัมน์ที่มีไอคอนดินสอ พิมพ์ **คะแนน** (เว้นว่าง = ไม่มีคะแนน) แล้วกด **บันทึก** คะแนนต้องอยู่ระหว่าง 0 ถึงคะแนนเต็ม ทศนิยมไม่เกิน 2 ตำแหน่ง เปิด **ยกเว้น** ถ้าไม่ต้องการนำช่องนี้เข้าค่าเฉลี่ยของนักเรียนคนนั้น

คอลัมน์ของการบ้านหรือข้อสอบที่ตรวจด้วยแอป แก้คะแนนในสมุดคะแนนไม่ได้ ตั้งได้เฉพาะ **ยกเว้น** และกด **เปิดหน้าผล** เพื่อดูงานของนักเรียน

คอลัมน์ **การเข้าเรียน** ที่ระบบสร้างจากการเช็คชื่อ (หัวข้อ 13.3) ไม่มีไอคอนดินสอ แตะช่องแล้วจะเห็นคะแนนพร้อมข้อความ เช่น **คะแนน 9/10 จากการเช็คชื่อ แก้ได้ที่หน้าเช็คชื่อของรายวิชา** (หรือ **ยังไม่มีคะแนน จากการเช็คชื่อ …** เมื่อยังไม่เคยเช็คชื่อนักเรียนคนนั้น) กล่องนี้มีเพียงปุ่ม **ปิด** ไม่มีปุ่มบันทึกและสวิตช์ **ยกเว้น** ถ้าคะแนนไม่ถูก ให้แก้การเช็คชื่อหรือค่าคะแนนของแต่ละสถานะในหน้าเช็คชื่อ

### กรอกทั้งคอลัมน์

แตะ **หัวคอลัมน์** ของรายการที่ครูกรอกเอง

- **ให้เต็มทั้งห้อง** ใส่คะแนนเต็มให้ทุกคนที่ยังว่าง ไม่ทับค่าที่กรอกไว้ และข้ามคนที่ยกเว้น
- **วางคะแนนจาก Excel** คัดลอกคอลัมน์คะแนนจาก Excel หรือ Google Sheets (หนึ่งค่าต่อบรรทัด เรียงตามเลขที่) แล้วเปิดเมนูนี้ เลือก **เริ่มจาก** นักเรียนคนใด ระบบแสดงตัวอย่างว่าบรรทัดใดจะบันทึก บรรทัดใดผิด (ไม่บันทึก) แล้วกด **บันทึก N ค่า** บรรทัดว่างหมายถึงไม่เปลี่ยนค่าของนักเรียนคนนั้น
- **แก้รายการ** และ **ลบรายการ** (เฉพาะรายการที่ครูเพิ่มเอง การลบจะลบคะแนนที่กรอกไว้ด้วย)

หัวคอลัมน์ของการบ้านหรือข้อสอบมีเพียง **เปิดการบ้าน** หรือ **เปิดข้อสอบ**

### ย้ายหมวดหรือไม่นับเกรด

- รายการที่ครูเพิ่มเอง: **แก้รายการ** แล้วเปลี่ยน **หมวดคะแนน**
- การบ้านและข้อสอบ: เปิดฟอร์มของงานนั้น (ไอคอนดินสอ) แล้วเปลี่ยนช่อง **หมวดคะแนน** หรือเปิด **ไม่นับเกรด** สำหรับงานฝึกที่ต้องการให้แสดงในสมุดคะแนนแบบจางและไม่เข้าสูตรคะแนน

## เกรดพิเศษ ร และ มส

แตะ **แถวของนักเรียน** เพื่อเปิดรายละเอียด

- คะแนนของแต่ละหมวด เช่น **คะแนนเก็บ (70%): 86.67% → 60.67 คะแนน**
- คะแนนรวมและเกรด เช่น **คะแนนรวม 86.67 → 87 เกรด 4** ถ้ายังมีหมวดที่ไม่มีคะแนน จะแสดงเป็น **คะแนนระหว่างภาค** แทน
- **เกรดพิเศษ** เลือก **ไม่มี**, **ร** หรือ **มส** และพิมพ์ **หมายเหตุ** ได้ (นักเรียนไม่เห็นหมายเหตุ)

**ร** และ **มส** ใช้แทนเกรดที่คำนวณได้ ระบบไม่ตั้งให้เอง คำเตือน **อาจติด มส: การเข้าเรียนต่ำกว่า 80%** คิดจากรายการที่ตั้งเป็นคะแนนการเข้าเรียน เป็นเพียงคำเตือน ครูเป็นผู้ตัดสิน

## ประกาศเกรด

1. ตรวจว่าทุกหมวดมีคะแนน และไม่มีแถบเตือนสีส้มเหนือตาราง
2. กด **ประกาศเกรด** ระบบบอกจำนวนนักเรียนที่จะเห็นเกรด และรายการที่ควรตรวจก่อน เช่น ช่องที่ยัง **รอประกาศผล** หรือ **ยังไม่ถึงกำหนด** (ซึ่งไม่นับคะแนน) คำเตือนเหล่านี้ไม่ห้ามประกาศ
3. กด **ประกาศ**

นักเรียนเห็น **เกรด คะแนนรวม และคะแนนรายหมวดของตัวเอง** เท่านั้น ไม่เห็นของเพื่อนหรือค่าเฉลี่ยของห้อง (บทที่ 21)

- **ประกาศใหม่** ใช้เมื่อมีการแก้คะแนนหลังประกาศ นักเรียนจะเห็นค่าล่าสุด
- **ถอนประกาศ** นักเรียนจะกลับไปเห็นฉบับที่ประกาศก่อนหน้า หรือไม่เห็นเกรดเลยถ้าไม่มีฉบับก่อนหน้า

**ห้องเก่า**
ห้องที่ปิดแล้ว (ห้องเก่า) ยังเปิดดูสมุดคะแนนและส่งออกได้ แต่กรอกหรือแก้คะแนน ตั้ง **ยกเว้น** เพิ่ม แก้ หรือลบรายการ ตั้ง ร หรือ มส ประกาศ และถอนประกาศไม่ได้ ถ้ากด ระบบขึ้นว่า **ห้องนี้ปิดแล้ว (ห้องเก่า) ดูข้อมูลได้แต่แก้ไขไม่ได้** ส่วนหมวดคะแนนและเกณฑ์เกรดเป็นการตั้งค่าของรายวิชา จึงยังแก้ได้ตามปกติ

## ส่งออก CSV

กด **ส่งออก CSV** ในสมุดคะแนนหรือไอคอนแชร์ในแท็บตัดเกรด ได้ไฟล์ชื่อ `gradebook-(รหัสวิชา)-(ห้อง).csv` เปิดด้วย Excel ได้ทันที ภาษาไทยไม่เพี้ยน ในแอป Android ระบบเปิดหน้าต่างแชร์ให้เลือกแอปปลายทาง เช่น LINE, Google Drive หรืออีเมล บนเว็บ เบราว์เซอร์จะเปิดหน้าต่างแชร์หรือดาวน์โหลดไฟล์ให้ ขึ้นกับเบราว์เซอร์ที่ใช้

| คอลัมน์ในไฟล์ | ค่า |
|---|---|
| **เลขที่**, **ชื่อ** | ตามรายชื่อของห้อง |
| **(ชื่อหมวด) (น้ำหนัก)** | คะแนนที่ได้ของหมวดนั้นหลังคูณน้ำหนัก ทศนิยม 2 ตำแหน่ง |
| **รวม** | คะแนนรวมที่ปัดเป็นจำนวนเต็ม |
| **เกรด** | 4 ถึง 0, ร หรือ มส |

ไฟล์ใช้ค่าปัจจุบันในสมุดคะแนน ไม่ใช่ฉบับที่ประกาศ และไม่มีคะแนนรายรายการ ถ้าห้องยังมีหมวดที่ไม่มีคะแนน คอลัมน์รวมจะเป็น **รวมระหว่างภาค (ร้อยละ)** และคอลัมน์เกรดว่าง ยกเว้นนักเรียนที่ครูตั้ง **ร** หรือ **มส** ไว้ ซึ่งยังแสดง ร หรือ มส ตามเดิม

## ระบบคิดคะแนนอย่างไร

1. **ร้อยละของรายการ** = คะแนนที่ได้ ÷ คะแนนเต็ม
2. **ร้อยละของหมวด** = ค่าเฉลี่ยของร้อยละของรายการที่นับในหมวดนั้น หลังตัดรายการต่ำสุดตามที่ตั้งไว้
3. **คะแนนของหมวด** = น้ำหนักของหมวด × ร้อยละของหมวด ÷ 100
4. **คะแนนรวม** = ผลรวมคะแนนของทุกหมวด แล้วปัดครึ่งขึ้นเป็นจำนวนเต็ม (79.50 ปัดเป็น 80)
5. **เกรด** = เกรดสูงสุดที่คะแนนรวมถึงเกณฑ์ ถ้าไม่ถึงเกณฑ์ของเกรด 1 ได้ 0

ตัวอย่าง รายวิชาตั้ง คะแนนเก็บ 70% และปลายภาค 30% นักเรียนได้คะแนนเก็บเฉลี่ย 86.67% และปลายภาค 26 จาก 30 (86.67%)

| หมวด | ร้อยละ | × น้ำหนัก | คะแนนของหมวด |
|---|---|---|---|
| คะแนนเก็บ | 86.67% | 70 | 60.67 |
| ปลายภาค | 86.67% | 30 | 26.00 |
| **รวม** | | | **86.67 → ปัดเป็น 87 → เกรด 4** |

ทุกรายการในหมวดเดียวกันมีน้ำหนักเท่ากัน ไม่ว่าคะแนนเต็มจะเป็นเท่าใด ถ้าต้องการให้งานชิ้นใดมีผลมากกว่า ให้แยกไปอยู่อีกหมวดและตั้งน้ำหนักของหมวดนั้น

ขณะที่บางหมวดยังไม่มีรายการที่นับได้ ระบบแสดง **คะแนนระหว่างภาค** โดยคิดจากหมวดที่มีคะแนนแล้วเท่านั้น และยังไม่ออกเกรด
