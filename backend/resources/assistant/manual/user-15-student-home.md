# หน้าหลักและวิชาของฉัน

หลังเข้าสู่ระบบ นักเรียนจะเห็นหน้า **วิชาของฉัน** ซึ่งรวมทุกวิชาที่เรียนอยู่ งานที่ต้องส่ง และผลที่ครูเผยแพร่แล้ว

| จุด | คืออะไร |
|---|---|
| (1) | **บัญชีของฉัน** ดูชื่อผู้ใช้ เปลี่ยนรหัสผ่าน และเชื่อมบัญชี Google (บทที่ 22) |
| (2) | **ออกจากระบบ** |
| (3) | **เกรดทั้งหมด** เปิดรายการเกรดของทุกวิชาที่ครูประกาศแล้ว (บทที่ 21) ข้างกันมี **ตารางเรียน** และ **การเข้าเรียน** ของนักเรียน และ **เข้าห้องด้วยรหัส** (หัวข้อ 16.3) |
| (4) | **การ์ดของวิชา** บอกรหัสและชื่อวิชา ห้อง ชื่อครู จำนวนงานที่ต้องส่ง และจำนวนผลที่ออกแล้ว แตะเพื่อเปิดหน้าของวิชานั้น |
| (5) | **เกรด** ของวิชานั้น แสดงเมื่อครูประกาศเกรดแล้ว |
| (6) | **เมนูหลัก** 5 ปุ่ม ดูตารางถัดไป |

บรรทัดบนสุดบอกว่า **ต้องส่งอีก N งาน** หรือ **ไม่มีงานค้าง** ปุ่ม **เข้าห้องด้วยรหัส** ใช้เข้าห้องของครูเพิ่มด้วยรหัสห้องที่ครูให้ (หัวข้อ 16.3)

## เมนูหลัก 5 ปุ่ม

| ปุ่ม | ใช้ทำอะไร | อ่านต่อ |
|---|---|---|
| **วิชาของฉัน** | ดูทุกวิชา งานที่ค้าง และเกรด | บทนี้ |
| **ส่งงาน** | ดูการบ้านที่ครูเปิดรับ แล้วถ่ายรูปหรือเลือกไฟล์ส่ง | บทที่ 18 |
| **ผลการบ้าน** | ดูคะแนนและคำอธิบายของงานและข้อสอบที่ครูเผยแพร่แล้ว | บทที่ 19 |
| **แบบฝึก** | ทำข้อฝึกในเรื่องที่ยังไม่มั่นใจ | บทที่ 20 |
| **ทักษะ** | ดูว่าเข้าใจเรื่องใดแล้ว เรื่องใดควรทบทวน | บทที่ 20 |

บนมือถือเมนูอยู่ด้านล่าง บนแท็บเล็ตและคอมพิวเตอร์เมนูย้ายไปอยู่ด้านซ้าย รายการในทุกหน้าโหลดใหม่ได้ด้วยการลากลง

## หน้าของวิชา

แตะการ์ดของวิชาเพื่อเปิดหน้าของวิชานั้น () ด้านบนบอกชื่อวิชา ห้อง และชื่อครู มี 5 แท็บ เรียงจาก **โพสต์** **งาน** **ผล** **เกรด** และ **กราฟ** (การ์ด **อื่นๆ** ที่ไม่มีรายวิชามีเพียงสามแท็บแรก)

| แท็บ | มีอะไร |
|---|---|
| **โพสต์** | ประกาศ เอกสารประกอบ และงานของวิชานี้ (ดูหัวข้อ 17.4) |
| **งาน** | การบ้านของวิชานี้ แต่ละแถวบอกกำหนดส่งและสถานะ **ส่งแล้ว** หรือ **ประกาศผลแล้ว** แตะเพื่อส่งงานหรือดูผล |
| **ผล** | ผลที่ครูเผยแพร่แล้วของวิชานี้ พร้อมคะแนนรวม |
| **เกรด** | เกรด คะแนนรวม และคะแนนรายหมวด เมื่อครูประกาศเกรดแล้ว |
| **กราฟ** | ระดับความเข้าใจของตัวเองในวิชานี้ |

ถ้าเรียนหลายวิชา ไอคอน **เปลี่ยนวิชา** ที่มุมขวาบนใช้สลับไปวิชาอื่นได้โดยไม่ต้องกลับไปหน้าหลัก งานที่ครูสั่งโดยไม่ได้ระบุรายวิชาจะอยู่ในการ์ดชื่อ **อื่นๆ**

## เรียนหลายห้อง และห้องเก่า

- นักเรียนมีบัญชีเดียว ถ้าอยู่หลายห้อง (เช่น ห้องประจำชั้นกับห้องวิชาเลือก) ทุกวิชาของทุกห้องจะรวมอยู่ในหน้าเดียว ป้ายบนการ์ดบอกว่าเป็นของห้องใด
- เข้าห้องของครูคนอื่นเพิ่มได้เองด้วยรหัสห้องหรือ QR ที่ครูให้ (หัวข้อ 16.3) ไม่ต้องมีบัญชีใหม่
- เมื่อจบปีการศึกษาและครูปิดห้อง วิชาของห้องนั้นจะย้ายไปอยู่ในกลุ่ม **ห้องเก่า** ด้านล่าง ยังเปิดดูผลและเกรดเดิมได้ แต่ส่งงานเพิ่มและขอให้ครูตรวจใหม่ไม่ได้ และห้องเก่าเข้าด้วยรหัสห้องไม่ได้

| ข้อความ | ความหมาย |
|---|---|
| **ยังไม่ได้อยู่ในห้องเรียน** | ครูยังไม่ได้เพิ่มนักเรียนเข้าห้อง กด **เข้าห้องด้วยรหัส** แล้วกรอกรหัสห้องที่ครูให้ หรือแจ้งครู |
| **ยังไม่มีรายวิชา** | ห้องยังไม่มีรายวิชาหรืองานที่ครูสั่ง รอครูสั่งงาน |
| **ไม่มีรายวิชาในห้องที่เปิดอยู่** | มีแต่ห้องเก่า ดูผลและเกรดของห้องเก่าได้ด้านล่าง |

## ตารางเรียน การเข้าเรียน และโพสต์ของครู

ใต้บรรทัด **ต้องส่งอีก N งาน** บนหน้าหลักมีปุ่ม **ตารางเรียน** และ **การเข้าเรียน** ส่วนโพสต์ของครูอยู่ในแท็บ **โพสต์** ของแต่ละวิชา และการ์ด **โพสต์ล่าสุด** บนหน้าหลัก (แสดงเมื่อมีโพสต์ แตะเพื่อเปิดโพสต์นั้น)

| ที่ไหน | มีอะไร |
|---|---|
| **ตารางเรียน** | คาบของทุกห้องที่เรียนอยู่ในสัปดาห์ เลื่อนด้วยลูกศร บนมือถือเป็นการ์ดรายวัน บนแท็บเล็ตเป็นตาราง แต่ละคาบบอกเลขคาบ วิชา เวลา ห้อง และชื่อครู คาบที่ครูยกเลิกมีขีดฆ่าพร้อมคำว่า **ยกเลิก** ถ้าครูยังไม่ใส่คาบ ขึ้นว่า **ยังไม่มีตารางเรียน** |
| **การเข้าเรียน** | หน้า **การเข้าเรียนของฉัน** หนึ่งการ์ดต่อวิชา บอกจำนวนแต่ละสถานะและอัตราการเข้าเรียนเป็นเปอร์เซ็นต์ (ต่ำกว่า 80% เป็นสีแดง) แตะการ์ดเพื่อดูทุกคาบที่ครูเช็ค พร้อมสถานะ **มาตรงเวลา**, **มาสาย**, **ขาด**, **ลากิจ** หรือ **ลาป่วย** และหมายเหตุของครู |
| แท็บ **โพสต์** | **สตรีม** คือทุกอย่างของวิชานี้เรียงตามเวลา ทั้งประกาศ เอกสารประกอบ การบ้านที่เปิดให้ส่ง และผลที่ประกาศแล้ว (แตะการบ้านหรือผลเพื่อไปหน้านั้น) **งานของชั้นเรียน** คือเอกสารประกอบและการบ้านจัดกลุ่มตามหัวข้อ โพสต์ที่มีป้าย **ถึงคุณโดยเฉพาะ** ครูส่งถึงนักเรียนบางคนเท่านั้น |

ไฟล์แนบในโพสต์ แตะแล้วแอป Android เปิดด้วยแอปดูไฟล์ในเครื่อง ส่วนบนเว็บจะดาวน์โหลดไฟล์ ลิงก์เปิดในเบราว์เซอร์ ข้อความในโพสต์คัดลอกได้ ถ้าเปิดไม่ได้จะขึ้นว่า **เปิดลิงก์ไม่ได้** หรือ **เปิดไฟล์ไม่ได้** ให้ลองใหม่หรือบอกครู
