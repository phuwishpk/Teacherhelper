# รู้จัก Krucheck

Krucheck เป็นระบบช่วยครูตรวจการบ้านและข้อสอบ ครูสร้างการบ้านในระบบ พิมพ์ใบงานแจกนักเรียน แล้วใช้มือถือสแกนใบงานที่ทำเสร็จ ระบบใช้ AI อ่านลายมือและให้คะแนนเบื้องต้นพร้อมคำอธิบายรายข้อ ครูเป็นผู้ตรวจทานและตัดสินทุกครั้งก่อนที่นักเรียนจะเห็นผล

คู่มือนี้อธิบายการใช้งานทีละขั้น แบ่งเป็นสองส่วน คือส่วนของครู (บทที่ 2–14) และส่วนของนักเรียน (บทที่ 15–22) ภาพหน้าจอในคู่มือถ่ายจากระบบจริงด้วยข้อมูลตัวอย่าง ชื่อครูและนักเรียนในภาพเป็นชื่อสมมติ

## Krucheck ทำอะไรได้บ้าง

<div class="flow">
<div><b>1 เตรียม</b>สร้างห้องเรียน รายวิชา และการบ้านหรือข้อสอบ</div>
<div><b>2 พิมพ์</b>พิมพ์ใบงานหรือกระดาษคำตอบที่มี QR</div>
<div><b>3 เก็บงาน</b>สแกนด้วยมือถือ หรืออัปโหลดรูป</div>
<div><b>4 ตรวจทาน</b>ดูคะแนนที่ AI ให้ แก้ไข แล้วเผยแพร่</div>
<div><b>5 ติดตาม</b>สมุดคะแนน เกรด และทักษะรายคน</div>
</div>

| งาน | สิ่งที่ระบบทำให้ |
|---|---|
| **การบ้าน** | สร้างคำถาม 4 ประเภท (ปรนัย เติมคำตอบสั้น แสดงวิธีทำ อัตนัย) พิมพ์ใบงานรายคน สแกนแล้วให้ AI อ่านลายมือและให้คะแนนพร้อมคำอธิบาย |
| **งานในสมุดหรือใบงานของครูเอง** | นักเรียนถ่ายรูปส่ง หรือครูอัปโหลดรูปแทน AI ตรวจจากรูปทั้งหน้า |
| **ข้อสอบ** | พิมพ์เล่มข้อสอบและกระดาษคำตอบแบบฝน สแกนด้วยมือถือแล้วได้คะแนนทันที ทำได้แม้ไม่มีอินเทอร์เน็ต |
| **ตรวจทาน** | ระบบจัดลำดับข้อที่ครูควรดูก่อน ครูแก้คะแนนและคำอธิบายได้ทุกข้อ |
| **สมุดคะแนน** | รวมคะแนนตามหมวดและน้ำหนัก ตัดเกรด 8 ระดับ ตั้ง ร และ มส ประกาศเกรด ส่งออกเป็นไฟล์ |
| **ติดตามผล** | ตารางทักษะของห้องตามตัวชี้วัด กราฟรายวิชา ข้อความวิเคราะห์รายคน และแบบฝึกซ่อมเสริม |
| **นักเรียน** | ดูผลและคำอธิบายของตัวเอง ขอให้ครูตรวจใหม่ ทำแบบฝึก ดูเกรด |

## ใครใช้ส่วนไหน

| ผู้ใช้ | ทำอะไร |
|---|---|
| **ครูประจำชั้น** | เป็นเจ้าของห้องเรียน เพิ่มและแก้รายชื่อนักเรียน ให้นักเรียนเข้าห้องด้วยรหัสห้องหรือ QR เชิญครูร่วมสอน และทำทุกอย่างที่ครูประจำวิชาทำได้ |
| **ครูประจำวิชา** | สอนรายวิชาของตัวเองในห้องของครูท่านอื่นได้ เมื่อตอบรับคำเชิญของครูประจำชั้น สั่งงาน ตรวจ และตัดเกรดเฉพาะรายวิชาของตัวเอง |
| **นักเรียน** | เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน หรือบัญชี Google เข้าห้องของครูหลายคนได้ด้วยรหัสห้อง ดูงาน ผลการตรวจ แบบฝึก และเกรดของตัวเอง |
| **ผู้ดูแลระบบ** | อนุมัติบัญชีครู ดูแลบัญชีผู้ใช้และตัวชี้วัด และช่วยแก้ปัญหาให้ครู (มีคู่มือการติดตั้งระบบแยกอีกเล่ม) |

ครูหนึ่งคนเป็นครูประจำชั้นของห้องหนึ่ง และเป็นครูประจำวิชาของอีกห้องหนึ่งได้ในบัญชีเดียวกัน บัญชีครูแต่ละบัญชีเป็นอิสระ ไม่ต้องสังกัดโรงเรียนเดียวกัน ห้องเรียน รายวิชา และตัวชี้วัดที่ครูเพิ่มเองเป็นของครูคนนั้น ส่วนนักเรียนมีบัญชีเดียวและเข้าห้องของครูกี่คนก็ได้

## ใช้บนเว็บหรือแอป Android

Krucheck ใช้ได้สองทาง หน้าตาและข้อมูลเป็นชุดเดียวกัน ต่างกันที่งานซึ่งต้องใช้กล้อง

| | เว็บ (เบราว์เซอร์) | แอป Android |
|---|---|---|
| เปิดจาก | คอมพิวเตอร์ แท็บเล็ต หรือมือถือ ผ่านเบราว์เซอร์ เช่น Chrome | แอปที่ผู้ดูแลระบบแจกให้ติดตั้ง |
| สร้างห้อง การบ้าน ข้อสอบ พิมพ์ PDF | ได้ | ได้ |
| ตรวจทาน เผยแพร่ สมุดคะแนน กราฟ | ได้ | ได้ |
| อัปโหลดรูปหรือ PDF ของงานเพื่อตรวจ | ได้ | ได้ |
| **สแกนใบงานและกระดาษคำตอบด้วยกล้อง** | ไม่ได้ | ได้ |
| **สแกนแบบไม่มีอินเทอร์เน็ต และคิวอัปโหลด** | ไม่ได้ | ได้ |
| นักเรียนเข้าห้องด้วยรหัสห้อง | ได้ (สแกน QR ด้วยกล้องมือถือจะเปิดหน้านี้ให้) | ได้ (กรอกรหัส 6 ตัว) |
| การแจ้งเตือนบนเครื่อง | ไม่มี | มี เมื่อผู้ดูแลระบบเปิดใช้ |

**วิธีใช้ที่สะดวก**
เตรียมงาน ตรวจทาน และดูสมุดคะแนนบนคอมพิวเตอร์ซึ่งจอกว้าง แล้วใช้มือถือ Android เฉพาะตอนสแกนกระดาษ ทั้งสองเครื่องเข้าด้วยบัญชีเดียวกันและเห็นข้อมูลเดียวกัน

## สิ่งที่ครูต้องมี

- **บัญชีครู** สมัครเองได้ในหน้าเข้าสู่ระบบ แล้วรอผู้ดูแลระบบอนุมัติ (บทที่ 2)
- **Gemini API key** สำหรับให้ AI ตรวจการบ้าน ครูใส่ key ของตัวเองในหน้าตั้งค่า เว้นแต่ผู้ดูแลระบบตั้ง key กลางไว้ให้ (หัวข้อ 2.5) ข้อสอบแบบฝนและการตัดเกรดไม่ใช้ key
- **เครื่องพิมพ์** สำหรับใบงานและกระดาษคำตอบ (กระดาษ A4)
- **มือถือ Android** ถ้าต้องการสแกนด้วยกล้อง

## AI ทำอะไร และครูทำอะไร

- AI อ่านลายมือ ให้คะแนนเบื้องต้น และเขียนคำอธิบายสำหรับนักเรียน **ผลจาก AI ยังไม่ถึงนักเรียน** จนกว่าครูจะตรวจทานและกดเผยแพร่
- ข้อปรนัยของการบ้าน และข้อสอบแบบฝนทั้งหมด ระบบตรวจจากวงที่ฝนเทียบกับเฉลยโดยตรง ไม่ใช้ AI
- ระบบไม่ส่งชื่อ เลขที่ หรือห้องของนักเรียนให้ AI สำหรับใบงานของแอป ระบบส่งเฉพาะภาพช่องคำตอบ โจทย์ และเฉลย ส่วนงานที่ตรวจจากรูปทั้งหน้า AI เห็นทุกอย่างที่อยู่ในรูป จึงไม่ควรให้นักเรียนเขียนข้อมูลส่วนตัวอื่นลงในหน้ากระดาษ

## สัญลักษณ์ในคู่มือ

ชื่อปุ่ม เมนู และข้อความบนหน้าจอพิมพ์ด้วย **ตัวหนา** ตรงตามที่แสดงในระบบ ตัวเลขในวงกลมสีแดง เช่น (1) หมายถึงจุดที่มีเลขเดียวกันในภาพประกอบ กล่องสีเหลืองคือข้อควรระวัง และกล่องสีเขียวอมฟ้าคือสิ่งที่ทำได้เฉพาะในแอป Android
