# ส่วนที่ 1 สำหรับครู

# เริ่มต้นใช้งาน

บทนี้พาครูตั้งแต่เปิดระบบครั้งแรก สมัครบัญชี เข้าสู่ระบบ รู้จักหน้าหลัก ไปจนถึงใส่ Gemini API key ซึ่งต้องทำก่อนให้ AI ตรวจการบ้าน

## เปิด Krucheck

**บนเว็บ** เปิดเบราว์เซอร์ (แนะนำ Chrome หรือ Edge รุ่นปัจจุบัน) แล้วไปที่ที่อยู่ของระบบที่ผู้ดูแลระบบแจ้ง ตัวอย่างเช่น

```
https://teacherhelper.phuwish.com
```

ระบบจะพาไปหน้าเข้าสู่ระบบเอง ใช้ได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ โดยไม่ต้องติดตั้งอะไร

**บนมือถือ Android** ติดตั้งแอป Krucheck จากไฟล์ที่ผู้ดูแลระบบแจก (ไฟล์ `.apk`) เมื่อ Android ถามว่าอนุญาตให้ติดตั้งแอปจากแหล่งนี้หรือไม่ ให้อนุญาต แล้วเปิดแอปจากหน้าจอหลัก แอปใช้ได้กับ Android 8.0 ขึ้นไป

**แอป Android แต่ละไฟล์ผูกกับที่อยู่ของระบบไว้แล้ว ครูไม่ต้องตั้งค่าที่อยู่เอง ถ้าเปิดแอปแล้วเข้าสู่ระบบไม่ได้ทั้งที่รหัสถูก ให้ถามผู้ดูแลระบบว่าเป็นไฟล์ของระบบนี้หรือไม่**

## สมัครใช้งาน

ครูสมัครบัญชีเองได้ แต่ต้องรอผู้ดูแลระบบอนุมัติก่อนจึงจะเข้าใช้ได้

1. ที่หน้า **เข้าสู่ระบบ** แท็บ **ครู** กด **ยังไม่มีบัญชี? สมัครใช้งาน**
2. ที่หน้า **สมัครใช้งาน (ครู)** กรอก **ชื่อ-นามสกุล** **อีเมล** และ **รหัสผ่าน (อย่างน้อย 8 ตัว)** แล้วพิมพ์ซ้ำในช่อง **ยืนยันรหัสผ่าน** ช่อง **ชื่อโรงเรียน** เว้นว่างได้และแก้ภายหลังได้ในหน้าตั้งค่า ชื่อนี้แสดงในแอปและในหน้าเข้าห้องที่นักเรียนเห็น
3. กด **สมัครใช้งาน** ระบบแสดงกล่อง **สมัครสำเร็จ** บอกว่าบัญชีอยู่ระหว่างรอผู้ดูแลระบบอนุมัติ กด **รับทราบ**
4. แจ้งผู้ดูแลระบบให้อนุมัติ เมื่ออนุมัติแล้วจึงเข้าสู่ระบบได้

**บัญชีครูเป็นอิสระต่อกัน**
ไม่ต้องเลือกโรงเรียนและไม่ต้องมีรหัสของโรงเรียน ห้องเรียน รายวิชา และตัวชี้วัดที่ครูเพิ่มเองเป็นของครูคนนั้น ครูท่านอื่นจะเห็นห้องของครูได้ก็ต่อเมื่อครูเชิญมาร่วมสอน (หัวข้อ 3.6) นักเรียนเข้าห้องของครูด้วยรหัสห้อง (หัวข้อ 3.3)

**ปุ่ม Google**
ปุ่ม **เข้าสู่ระบบด้วย Google** และ **สมัครด้วย Google** แสดงเฉพาะเมื่อผู้ดูแลระบบเปิดใช้การเข้าสู่ระบบด้วย Google ครูที่เข้าด้วยบัญชี Google ที่ยังไม่มีในระบบจะได้บัญชีครูทันทีด้วยชื่อและอีเมลจากบัญชี Google และใช้งานได้เลยโดยไม่ต้องรออนุมัติ ครูที่สมัครด้วยอีเมลไว้แล้ว ถ้าบัญชี Google ใช้อีเมลเดียวกับบัญชี Krucheck กด **เข้าสู่ระบบด้วย Google** ได้เลย ระบบเชื่อมสองบัญชีให้เองในครั้งแรก ส่วนบัญชี Google ที่อีเมลต่างกัน ให้เข้าด้วยรหัสผ่านก่อน แล้วเชื่อมบัญชี Google ในหน้าตั้งค่า (หัวข้อ 2.5)

## เข้าสู่ระบบและออกจากระบบ

1. ที่หน้า **เข้าสู่ระบบ** เลือกแท็บ **ครู**
2. กรอก **อีเมล** และ **รหัสผ่าน** แล้วกด **เข้าสู่ระบบ**

ข้อความที่อาจพบใต้ฟอร์ม

| ข้อความ | ความหมายและสิ่งที่ต้องทำ |
|---|---|
| **อีเมลหรือรหัสผ่านไม่ถูกต้อง** | ตรวจตัวพิมพ์เล็กใหญ่และช่องว่าง แล้วลองใหม่ |
| **บัญชีของคุณกำลังรอการอนุมัติจากผู้ดูแลระบบ** | ผู้ดูแลระบบยังไม่ได้อนุมัติ แจ้งผู้ดูแลระบบ |
| **บัญชีของคุณถูกระงับการใช้งาน** | บัญชีถูกระงับ ติดต่อผู้ดูแลระบบ |
| ข้อความว่าเข้าสู่ระบบถี่เกินไป | ลองผิดเกิน 10 ครั้งใน 1 นาทีจากเครือข่ายเดียวกัน รอ 1 นาทีแล้วลองใหม่ บัญชีไม่ได้ถูกล็อก |

**ออกจากระบบ** กดไอคอนประตูที่มุมขวาบนของหน้าหลัก (2) ใน  บนคอมพิวเตอร์ไอคอนอยู่ที่มุมล่างของแถบด้านซ้าย

**เครื่องที่ใช้ร่วมกัน**
บนเว็บ ระบบจำการเข้าสู่ระบบของครูไว้ 30 วัน ถ้าใช้คอมพิวเตอร์ของโรงเรียนหรือเครื่องที่คนอื่นใช้ด้วย ให้กดออกจากระบบทุกครั้งที่เลิกใช้

**เปลี่ยนรหัสผ่านและลืมรหัสผ่าน**
ครูเปลี่ยนรหัสผ่านเองได้ที่หน้าตั้งค่า โดยต้องกรอกรหัสผ่านปัจจุบัน (หัวข้อ 2.5) ถ้าลืมรหัสผ่าน ระบบไม่มีปุ่มรีเซ็ตรหัสผ่านด้วยตัวเอง ให้แจ้งผู้ดูแลระบบตั้งรหัสผ่านใหม่ให้ ระหว่างรอ ถ้าเชื่อมบัญชี Google ไว้แล้ว ยังเข้าสู่ระบบด้วยปุ่ม Google ได้

## หน้าหลักและเมนู

หลังเข้าสู่ระบบ ครูจะเห็นหน้าหลัก ซึ่งเป็นจุดเริ่มของทุกงาน

| จุด | คืออะไร |
|---|---|
| (1) | **ตั้งค่า** แก้ข้อมูลของครู เปลี่ยนรหัสผ่าน ใส่ Gemini API key เชื่อมบัญชี Google |
| (2) | **ออกจากระบบ** |
| (3) | การ์ด **Gemini API key** บอกว่าใส่ key แล้วหรือยัง |
| (4) | **รอดำเนินการ** รายการที่รอครูจัดการ เช่น เฉลยรออนุมัติ งานส่งใหม่รอกดตรวจ ถ้าไม่มีจะขึ้นว่า **ไม่มีงานค้าง** |
| (5) | **อัปโหลดรูปเพื่อตรวจ** ทางลัดไปหน้าแนบรูปหรือ PDF ของงานนักเรียน (บทที่ 7) |
| (6) | ปุ่ม **สแกนใบงาน** เปิดกล้องสแกน (ใช้ได้ในแอป Android) |
| (7) | แถบเมนูหลัก 5 แท็บ |

เมื่อเลื่อนหน้าหลักลงจะเห็น **ภาพรวม** (จำนวนห้องเรียน การบ้านที่เปิดอยู่ ข้อรอตรวจทาน คำขอตรวจใหม่ และข้อฝึกรออนุมัติ แตะตัวเลขเพื่อไปยังหน้านั้น) **ติดตามผลการเรียน** (ทางลัดไปตัดเกรด คลังแบบฝึก และทักษะของห้อง) และ **เริ่มต้นใช้งาน** ซึ่งสรุปขั้นตอน 4 ขั้นสำหรับครูใหม่

### แท็บเมนูหลัก

| แท็บ | ใช้ทำอะไร | อ่านต่อ |
|---|---|---|
| **หน้าหลัก** | ภาพรวมและทางลัด | บทนี้ |
| **ห้องเรียน** | สร้างห้อง เพิ่มนักเรียน ให้นักเรียนเข้าห้องด้วยรหัสห้อง เชิญครูร่วมสอน | บทที่ 3 |
| **การบ้าน** | สร้างและเปิดการบ้านกับข้อสอบ | บทที่ 5, 7, 9 |
| **ตรวจทาน** | ตรวจคะแนนที่ AI ให้ เผยแพร่ผล ตอบคำขอตรวจใหม่ | บทที่ 8 |
| **ตัดเกรด** | สมุดคะแนนของทุกรายวิชา | บทที่ 10 |

### บนจอกว้าง

บนคอมพิวเตอร์ (จอกว้างตั้งแต่ 1200 จุดขึ้นไป) เมนูย้ายไปอยู่แถบด้านซ้าย ปุ่ม **สแกนใบงาน** อยู่ด้านบนของแถบ ชื่อครูกับปุ่มตั้งค่าและออกจากระบบอยู่ด้านล่าง บนแท็บเล็ตเมนูเป็นแถบไอคอนแคบๆ ด้านซ้าย ทุกหน้าทำงานเหมือนกันทุกขนาดจอ

**ในแอป Android แถบบนมีไอคอนรูปเมฆ **คิวอัปโหลด** เพิ่มอีกหนึ่งปุ่ม พร้อมตัวเลขจำนวนภาพสแกนที่ยังส่งไม่เสร็จ (หัวข้อ 6.4)**

## ใส่ Gemini API key และตั้งค่าบัญชี

Krucheck ใช้ AI ของ Google ชื่อ Gemini อ่านลายมือและให้คะแนน การเรียกใช้ต้องมี "key" ซึ่งเป็นรหัสประจำตัวผู้ใช้บริการ ครูแต่ละคนใส่ key ของตัวเอง ระบบใช้ key ของครูก่อน ถ้าไม่มีจึงใช้ key กลางของเซิร์ฟเวอร์ (ถ้าผู้ดูแลระบบตั้งไว้)

การ์ด **Gemini API key** บนหน้าหลักบอกสถานะให้

| ข้อความบนการ์ด | ความหมาย |
|---|---|
| **ใส่แล้ว (••••abcd)** | มี key ของครูแล้ว แสดงเฉพาะ 4 ตัวท้าย |
| **ยังไม่ได้ใส่** พร้อมข้อความว่ามี key กลางของเซิร์ฟเวอร์ | ใช้งานได้ ระบบจะใช้ key กลางตรวจแทน |
| **ยังไม่ได้ใส่** พร้อมข้อความ **ใส่ key ก่อนสแกน** | ยังไม่มี key ใดเลย ข้อที่ต้องใช้ AI จะค้างให้ครูตรวจเอง |

### ขอ key จาก Google

1. เปิด `https://aistudio.google.com` แล้วเข้าสู่ระบบด้วยบัญชี Google
2. เลือกเมนูสำหรับสร้าง API key (ชื่อเมนูประมาณ **Get API key**) แล้วสร้าง key ใหม่
3. คัดลอก key ที่ได้เก็บไว้ key เป็นข้อความยาวบรรทัดเดียว ไม่มีช่องว่าง

**ใช้ key ของบัญชีที่เปิดการชำระเงินเท่านั้น**
ระบบแนะนำให้ใช้ key ของบัญชีที่เปิด billing (paid tier) เพราะแบบไม่เสียเงิน (free tier) อนุญาตให้ Google นำข้อมูลที่ส่งไปใช้ได้ ค่าใช้จ่ายของ AI คิดกับเจ้าของ key ตามอัตราของ Google อย่าส่ง key ให้ผู้อื่นทางแชต และอย่าใช้ key เดียวกันหลายคน

### ใส่ key ในระบบ

1. กดไอคอนเฟือง **ตั้งค่า** หรือกด **ใส่ key** บนการ์ดที่หน้าหลัก
2. ที่การ์ด **Gemini API key** วาง key ลงในช่อง **วาง Gemini API key** (กดไอคอนรูปตาเพื่อดู key ที่วาง)
3. กด **ทดสอบและบันทึก** ระบบทดสอบ key กับ Google ก่อน ถ้าผ่านจะขึ้นว่า **ทดสอบผ่านและบันทึก key แล้ว**

| ข้อความ | สาเหตุ | วิธีแก้ |
|---|---|---|
| **วาง Gemini API key ก่อน** | ช่องว่าง | วาง key แล้วกดใหม่ |
| **key ต้องไม่มีช่องว่าง ตรวจว่าคัดลอกมาครบบรรทัดเดียว** | คัดลอกมาไม่ครบหรือมีช่องว่างปน | คัดลอกใหม่ทั้งบรรทัด |
| **Gemini ไม่ยอมรับ key นี้ ...** | key ผิด ถูกลบ หรือยังไม่ได้เปิดใช้บริการ | ตรวจ key ในหน้าของ Google แล้วสร้างใหม่ถ้าจำเป็น |

- key ถูกเก็บแบบเข้ารหัสบนเซิร์ฟเวอร์ ไม่เก็บไว้ในเครื่อง และจะไม่แสดงเต็มอีกหลังบันทึก
- เปลี่ยน key: วาง key ใหม่ในช่อง **key ใหม่ (แทนที่ key เดิม)** แล้วกด **ทดสอบและบันทึก**
- ลบ key: กด **ลบ key** แล้วยืนยัน หลังลบ ระบบจะใช้ key กลาง (ถ้ามี) หรือปล่อยข้อที่ต้องใช้ AI ค้างเป็น **ตรวจเอง**

**ถ้ายังไม่มี key**
ครูยังสร้างการบ้าน พิมพ์ใบงาน และสแกนได้ตามปกติ ข้อปรนัยได้คะแนนทันที ส่วนข้ออื่นจะรอในหน้าตรวจทานพร้อมป้าย **ตรวจเอง · ไม่มี key** ครูให้คะแนนเองได้ หรือใส่ key ภายหลังแล้วกด **ตรวจข้อที่ค้างใหม่** ให้ AI ตรวจย้อนหลัง (หัวข้อ 8.6)

### เชื่อมบัญชี Google สำหรับเข้าสู่ระบบ

ถ้าผู้ดูแลระบบเปิดใช้ หน้าตั้งค่าจะมีการ์ด **บัญชี Google สำหรับเข้าสู่ระบบ** กด **เชื่อมบัญชี Google** แล้วเลือกบัญชี หลังเชื่อมแล้วครูเข้าสู่ระบบด้วยปุ่ม Google ได้โดยไม่ต้องพิมพ์รหัสผ่าน ระบบเก็บเฉพาะรหัสบัญชี ชื่อ อีเมล และรูปโปรไฟล์จาก Google ไม่เข้าถึงอีเมลหรือไฟล์ ยกเลิกได้ทุกเมื่อด้วยปุ่ม **ยกเลิกการเชื่อม** ในการ์ดเดียวกัน

การเชื่อมที่หน้านี้จำเป็นเฉพาะเมื่อใช้บัญชี Google ที่อีเมลไม่ตรงกับบัญชี Krucheck ถ้าอีเมลตรงกัน ระบบเชื่อมให้เองตอนกด **เข้าสู่ระบบด้วย Google** ครั้งแรก บัญชีที่สมัครด้วยปุ่ม Google และยังไม่เคยตั้งรหัสผ่าน ต้องตั้งรหัสผ่านก่อน (หัวข้อย่อยถัดไป) จึงจะยกเลิกการเชื่อมได้ เพราะไม่เช่นนั้นจะเข้าสู่ระบบไม่ได้อีก

### แก้ข้อมูลของครูและเปลี่ยนรหัสผ่าน

การ์ดบนสุดของหน้าตั้งค่ามีแถวชื่อของครู (บอกอีเมลและชื่อโรงเรียน) และแถว **เปลี่ยนรหัสผ่าน**

1. แตะแถวชื่อของครู ได้กล่อง **แก้ไขข้อมูลของฉัน** แก้ **ชื่อ-นามสกุล** หรือ **ชื่อโรงเรียน** แล้วกด **บันทึก** ระบบขึ้นว่า **บันทึกข้อมูลแล้ว** อีเมลแก้ในแอปไม่ได้ ถ้าต้องเปลี่ยนให้แจ้งผู้ดูแลระบบ
2. แตะ **เปลี่ยนรหัสผ่าน** กรอก **รหัสผ่านปัจจุบัน** **รหัสผ่านใหม่** (อย่างน้อย 8 ตัว) และ **พิมพ์รหัสผ่านใหม่อีกครั้ง** แล้วกด **บันทึก**
3. ระบบขึ้นว่า **เปลี่ยนรหัสผ่านแล้ว เครื่องอื่นถูกออกจากระบบ** เครื่องที่ใช้อยู่ยังเข้าสู่ระบบต่อได้

บัญชีที่สมัครด้วยปุ่ม Google และยังไม่เคยตั้งรหัสผ่าน เว้นช่อง **รหัสผ่านปัจจุบัน** ว่างได้ หลังบันทึกจึงเข้าสู่ระบบด้วยอีเมลและรหัสผ่านได้ด้วย ถ้ารหัสผ่านปัจจุบันผิด ระบบขึ้นว่า **รหัสผ่านปัจจุบันไม่ถูกต้อง** ถ้าลืมรหัสผ่านปัจจุบัน ให้แจ้งผู้ดูแลระบบตั้งรหัสผ่านใหม่ให้

## ลำดับงานสำหรับครั้งแรก

ทำตามลำดับนี้หนึ่งรอบ จะได้ใช้ครบทุกส่วนของระบบ

1. **ใส่ Gemini API key** (หัวข้อ 2.5)
2. **สร้างห้องเรียนและเพิ่มนักเรียน** หรือให้นักเรียนเข้าห้องเองด้วยรหัสห้องหรือ QR (บทที่ 3)
3. **สร้างรายวิชา** เลือกตัวชี้วัด แล้วผูกกับห้อง (บทที่ 4) การบ้านทุกชิ้นต้องอยู่ในรายวิชา
4. **สร้างการบ้าน** เพิ่มคำถาม ใส่เฉลย แล้วพิมพ์ใบงาน (บทที่ 5)
5. **สแกนใบงาน** ที่นักเรียนทำแล้ว (บทที่ 6) หรืออัปโหลดรูป (บทที่ 7)
6. **ตรวจทานและเผยแพร่** (บทที่ 8)
7. **ตั้งค่าสมุดคะแนน** แล้วดูเกรดและทักษะของห้อง (บทที่ 10 และ 11)
