# ปัญหาที่พบบ่อยของนักเรียน

## เข้าสู่ระบบ

| ปัญหา | วิธีแก้ |
|---|---|
| ลืมรหัสผ่าน | บอกครู ครูจะรีเซ็ตให้รหัสผ่านกลับเป็นรหัสเริ่มต้น `123456` แล้วระบบให้ตั้งรหัสผ่านของตัวเองตอนเข้า ถ้าจำรหัสผ่านได้ เปลี่ยนเองได้ที่ **บัญชีของฉัน** |
| ลืมชื่อผู้ใช้ | ถามครู ชื่อผู้ใช้อยู่ในรายชื่อของห้อง |
| ใส่รหัสผ่านผิดจนถูกล็อก | รอ 15 นาทีแล้วลองใหม่ หรือขอให้ครูรีเซ็ตรหัสผ่าน |
| สแกน QR เข้าห้องแล้วไม่เกิดอะไร | ใช้แอปกล้องของมือถือสแกน แล้วแตะลิงก์ที่ขึ้น หรือกรอกรหัสห้อง 6 ตัวที่อยู่ใต้ QR ด้วยปุ่ม **เข้าห้องด้วยรหัส** |
| ไม่มีปุ่ม Google | ผู้ดูแลระบบยังไม่เปิดใช้ เข้าด้วยชื่อผู้ใช้และรหัสผ่าน |
| เข้าแล้วไม่มีวิชาเลย | ยังไม่ได้อยู่ในห้องหรือครูยังไม่ได้สั่งงาน กด **เข้าห้องด้วยรหัส** ด้วยรหัสห้องที่ครูให้ หรือแจ้งครู |
| เข้าแล้วเป็นชื่อของคนอื่น | ออกจากระบบทันที แล้วตรวจชื่อผู้ใช้ที่กรอก ถ้าเลือกชื่อผิดตอนเข้าห้อง ให้แจ้งครูเอาออกจากห้องแล้วเข้าใหม่ |

## ส่งงาน

| ปัญหา | วิธีแก้ |
|---|---|
| ไม่เห็นการบ้านในแท็บส่งงาน | การบ้านยังไม่พร้อมให้ส่ง (ครูยังสร้างใบงานหรืออนุมัติเฉลยไม่เสร็จ) หรือครูมอบงานนั้นให้นักเรียนบางคนเท่านั้น การบ้านแบบใบงานของแอปก็แสดงในแท็บนี้ด้วย ส่วนข้อสอบไม่แสดง เพราะทำบนกระดาษ ลากรายการลงเพื่อโหลดใหม่ ถ้ายังไม่เห็นให้ถามครู |
| ไม่มีปุ่มถ่ายรูป | บนเว็บมีเฉพาะปุ่ม **เลือกรูปหรือ PDF** ให้ถ่ายรูปด้วยกล้องของเครื่องก่อน แล้วเลือกไฟล์รูปนั้น |
| ส่งไม่ได้ ขึ้นว่าปิดรับงานแล้ว | เลยกำหนดและครูไม่รับงานส่งช้า ติดต่อครูผู้สอน |
| ส่งผิดไฟล์ | ก่อนครูประกาศผล เปิดการบ้านนั้นแล้วกด **ส่งงานใหม่** |
| อัปโหลดค้างหรือไม่สำเร็จ | ตรวจอินเทอร์เน็ต ลดขนาดรูป แล้วส่งอีกครั้ง อย่าปิดหน้าจอระหว่างส่ง |
| ส่งแล้วแต่ยังไม่มีคะแนน | ครูต้องตรวจทานและเผยแพร่ก่อน คะแนนจึงจะขึ้นในแท็บผลการบ้าน |

## ผล แบบฝึก และเกรด

| ปัญหา | วิธีแก้ |
|---|---|
| คะแนนไม่ตรงกับที่คิดไว้ | อ่านคำอธิบายของข้อนั้น ถ้ายังเห็นว่าไม่ถูก กด **ขอให้ครูตรวจใหม่** พร้อมเหตุผล |
| ไม่มีปุ่มขอให้ครูตรวจใหม่ | ข้อนั้นเคยขอไปแล้ว (ขอได้ข้อละครั้ง) หรือเป็นข้อสอบที่ครูยังไม่เปิดให้ดูเฉลย |
| ไม่เห็นภาพคำตอบของตัวเอง | ภาพมีเฉพาะงานที่ครูสแกนจากใบงาน และภาพเก่าอาจถูกลบตามนโยบายการเก็บข้อมูล |
| ไม่มีแบบฝึกให้ทำ | ยังไม่มีผลที่เผยแพร่ ครูยังไม่ได้อนุมัติข้อฝึก หรือทำครบแล้ว ข้อเดิมจะกลับมาหลัง 7 วัน |
| ตอบแบบฝึกผิดแล้วอยากแก้ | แก้ไม่ได้ รออีก 7 วันข้อนั้นจะกลับมาให้ทำใหม่ |
| ไม่เห็นเกรด | ครูยังไม่ประกาศเกรดของวิชานั้น |
| เกรดหรือคะแนนในหมวดไม่ถูก | สอบถามครูผู้สอน ครูแก้แล้วประกาศใหม่ได้ |

## เครื่องและอินเทอร์เน็ต

| ปัญหา | วิธีแก้ |
|---|---|
| **เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ (…)** | ตรวจ Wi-Fi หรือเน็ตมือถือ แล้วกด **ลองใหม่** |
| หน้าจอค้างหรือข้อมูลไม่อัปเดต | ลากรายการลงเพื่อโหลดใหม่ บนเว็บกดโหลดหน้าใหม่ของเบราว์เซอร์ |
| ใช้เครื่องของโรงเรียนร่วมกับเพื่อน | กด **ออกจากระบบ** ทุกครั้งหลังใช้ |
| เปลี่ยนมือถือเครื่องใหม่ | ติดตั้งแอปหรือเปิดเว็บ แล้วเข้าสู่ระบบด้วยข้อมูลเดิม ข้อมูลทั้งหมดอยู่บนเซิร์ฟเวอร์ ไม่หาย |
