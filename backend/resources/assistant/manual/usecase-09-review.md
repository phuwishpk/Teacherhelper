# ตรวจทานและเผยแพร่ผล

หลัง AI ตรวจ คะแนนยังเป็นเพียงข้อเสนอ ครูตรวจทานในแท็บ **ตรวจทาน** แล้วจึงเผยแพร่ นักเรียนไม่เห็นผลใดจนกว่าครูจะเผยแพร่ ทุก use case ในบทนี้ทำได้เฉพาะครูผู้สอนรายวิชาของงานนั้น ครูประจำชั้นที่ไม่ได้สอนรายวิชานั้นเปิดดูคะแนนและคำตอบได้อย่างเดียว ข้อสอบใช้คิวตรวจทาน การเผยแพร่ และคำขอให้ตรวจใหม่ชุดเดียวกัน แต่ครูอ่านรอยฝนแทนการแก้คะแนนของ AI (UC-T56)

## ตรวจทานคำตอบทีละข้อ

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: ตรวจคะแนนที่ AI เสนอทีละข้อ แก้ถ้าไม่ถูก แล้วบันทึกเป็นผลที่ครูยืนยัน
เงื่อนไขก่อนเริ่ม: มีงานของนักเรียนเข้ามาแล้ว และผลของนักเรียนคนนั้นยังไม่เผยแพร่
ผลลัพธ์: ข้อนั้นตรวจทานแล้ว นักเรียนยังไม่เห็นจนกว่าจะเผยแพร่ (UC-T43)
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. เปิดแท็บ **ตรวจทาน** แล้วแตะการบ้านใน **เลือกการบ้านที่จะตรวจทาน**
2. เลือกแท็บ **ต้องตรวจ** **ควรดู** หรือ **มั่นใจ** (ตัวเลขในวงเล็บคือข้อที่ยังไม่ตรวจทาน) แล้วแตะข้อ
3. ดู **ภาพคำตอบ** เทียบกับ **สิ่งที่อ่านได้** และ **เหตุผลของคะแนน**
4. ปรับ **คะแนน** ด้วย **−** **+** **0** หรือ **เต็ม** แล้วตรวจ **ระดับความเข้าใจ** และ **ประเภทข้อผิดพลาด** ที่ AI เลือกไว้
5. ถ้าคะแนนต่างจากที่ AI ให้ เลือก **เหตุผลที่แก้คะแนน (จำเป็น)**
6. กด **บันทึกและข้อถัดไป** หรือ **บันทึก** ระบบแสดง **บันทึกผลข้อนี้แล้ว**

**กรณีอื่น**

- **3ก** ข้อมีป้าย **ตรวจเอง** หรือ **หาคำตอบในภาพไม่เจอ**: AI ไม่ได้ให้คะแนน ดูภาพแล้วให้คะแนนเอง (ข้อที่ค้างเพราะไม่มี key ดู UC-T46)
- **3ข** ข้อมีป้าย **น่าสงสัย**: ลายมือมีข้อความที่พยายามสั่งผู้ตรวจหรือขอคะแนน อ่านเองก่อนบันทึก
- **6ก** บันทึกไม่ได้: ระบบบอกเหตุ เช่น **เลือกระดับความเข้าใจก่อนบันทึก** หรือ **ข้อนี้ AI ยังตรวจไม่เสร็จ รอสักครู่แล้วลองใหม่** ผลที่เผยแพร่แล้วแก้จากหน้านี้ไม่ได้ (UC-T45)
- **ทุกขั้น** ครูประจำชั้นที่ไม่ได้สอนรายวิชานั้นบันทึกไม่ได้: **เฉพาะครูผู้สอนรายวิชานี้ที่ทำได้ ครูประจำชั้นดูได้อย่างเดียว**

## แก้คำอธิบายสำหรับนักเรียน

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ให้คำอธิบายรายข้อที่นักเรียนจะเห็นถูกต้องและเหมาะกับนักเรียน
เงื่อนไขก่อนเริ่ม: เปิดข้อในคิวตรวจทานแล้ว (UC-T40) และผลยังไม่เผยแพร่ การให้ AI เขียนใหม่ต้องใส่ Gemini API key แล้ว (UC-T05)
ผลลัพธ์: นักเรียนเห็นข้อความนี้หลังเผยแพร่ ทั้งในหน้าผลและในประกาศส่วนตัวของ Google Classroom ถ้างานอยู่ใน Classroom
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ในรายละเอียดของข้อ ไปที่การ์ด **คำอธิบายสำหรับนักเรียน**
2. พิมพ์แก้ในกล่อง หรือกด **ให้ AI เขียนคำอธิบายใหม่**
3. ใส่ **คำแนะนำถึง AI (ไม่บังคับ)** แล้วกด **เขียนใหม่** ระบบแสดง **AI เขียนคำอธิบายใหม่แล้ว ตรวจก่อนบันทึก**
4. อ่านข้อความใหม่ แก้ต่อได้ แล้วกด **บันทึก** หรือ **บันทึกและข้อถัดไป**

**กรณีอื่น**

- **2ก** กลับไปใช้ข้อความเดิมของ AI: เปิด **ดูข้อความเดิมของ AI** กด **ใช้ข้อความของ AI** แล้วบันทึก
- **3ก** ข้อปรนัยที่ไม่ได้คะแนนเต็ม หรือข้อที่ AI ไม่มีข้อความที่อ่านได้: **ข้อนี้ไม่มีข้อความที่ AI อ่านได้ ให้ครูเขียนคำอธิบายเอง**
- **3ข** ไม่มี key หรือ AI ขัดข้อง: **ยังไม่มี Gemini API key ให้ใช้ ใส่ key ที่หน้าตั้งค่าก่อนแล้วลองอีกครั้ง** หรือ **AI เขียนคำอธิบายไม่สำเร็จ ลองใหม่อีกครั้ง หรือเขียนคำอธิบายเอง**

**ข้อความที่ AI เขียนใหม่ถูกเก็บทันทีแม้ยังไม่กดบันทึก ส่วนข้อความที่ครูพิมพ์เองต้องกดบันทึก ในคำแนะนำถึง AI อย่าใส่ชื่อหรือข้อมูลของนักเรียน**

## อนุมัติทั้งกลุ่มมั่นใจ

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: ยืนยันข้อที่ AI มั่นใจทั้งหมดในครั้งเดียว แทนการเปิดทีละข้อ
เงื่อนไขก่อนเริ่ม: แท็บ **มั่นใจ** ของคิวตรวจทานมีข้อที่ยังไม่ตรวจทาน
ผลลัพธ์: ข้อในกลุ่มตรวจทานแล้วด้วยคะแนน ระดับความเข้าใจ ประเภทข้อผิดพลาด และคำอธิบายที่ AI ให้
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. เปิดคิวตรวจทานของการบ้าน (UC-T40) แล้วเลือกแท็บ **มั่นใจ**
2. เลื่อนดูคะแนนคร่าวๆ และเปิดบางข้อเพื่อสุ่มตรวจ
3. กด **อนุมัติทั้งกลุ่มมั่นใจ (N ข้อ)** ที่บนสุดของแท็บ
4. ระบบถาม **อนุมัติ N ข้อในกลุ่มมั่นใจ?** กด **อนุมัติ**
5. ระบบแสดง **อนุมัติแล้ว N ข้อ**

**กรณีอื่น**

- **3ก** ไม่มีปุ่ม: ข้อในแท็บนี้ตรวจทานครบแล้ว ข้อที่มีป้าย **น่าสงสัย** หรือ **ตัวตนไม่ตรง** และข้อที่มีคำขอให้ตรวจใหม่ไม่ถูกอนุมัติด้วยวิธีนี้ ต้องเปิดดูเอง (UC-T40)
- **3ข** ข้อสอบ: ข้อที่อ่านรอยฝนได้ชัดถูกตรวจทานให้ตั้งแต่ตอนสแกน จึงไม่ต้องใช้ปุ่มนี้

## เผยแพร่ผล

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: ให้นักเรียนเห็นผลการบ้านที่ครูตรวจทานครบแล้ว
เงื่อนไขก่อนเริ่ม: ทุกข้อของนักเรียนคนนั้นตรวจทานแล้ว และได้งานครบทุกหน้า
ผลลัพธ์: นักเรียนเห็นคะแนนรวม คะแนนรายข้อ ภาพคำตอบ และคำอธิบาย (UC-S11) และได้รับการแจ้งเตือน คะแนนเริ่มนับในสมุดคะแนนและตารางทักษะ
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. เปิดคิวตรวจทานของการบ้าน (UC-T40)
2. กดไอคอนรูปเครื่องบินกระดาษ **เผยแพร่ทั้งการบ้าน** ที่มุมขวาบน
3. ระบบถาม **เผยแพร่ผลทั้งการบ้าน?** พร้อมจำนวนนักเรียนที่ตรวจทานครบและที่ยังไม่ครบ กด **เผยแพร่**
4. ระบบแสดง **เผยแพร่แล้ว N คน** คนที่ยังตรวจไม่ครบยังไม่เห็นผล กดเผยแพร่อีกครั้งได้เมื่อพร้อม

**กรณีอื่น**

- **2ก** เผยแพร่ทีละคน: ในแท็บ **รายคน** กด **เผยแพร่** ท้ายชื่อ แล้วยืนยัน
- **2ข** ปุ่มเผยแพร่กดไม่ได้: ยังไม่มีใครตรวจทานครบหรือได้งานครบทุกหน้า แถวในแท็บ **รายคน** บอก **ตรวจทานแล้ว x/y ข้อ**
- **4ก** การบ้านอยู่ใน Google Classroom: ระบบส่งผลไป Classroom ต่อให้เอง (UC-T78)

**เผยแพร่แล้วถอนไม่ได้**
ไม่มีปุ่มยกเลิกการเผยแพร่ และภาพเต็มหน้าของใบงานถูกลบหลังเผยแพร่ (UC-X06) ถ้าต้องแก้ภายหลัง ดู UC-T45

## ตอบคำขอตรวจใหม่

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: ตอบคำขอของนักเรียนที่ขอให้ตรวจข้อหนึ่งใหม่ ด้วยการปรับคะแนนหรือยืนยันคะแนนเดิม
เงื่อนไขก่อนเริ่ม: นักเรียนขอให้ตรวจใหม่หลังเผยแพร่ผล (UC-S12)
ผลลัพธ์: นักเรียนได้รับแจ้งและเห็น **ครูปรับผลแล้ว** หรือ **ครูยืนยันผลเดิม** ถ้าปรับคะแนน นักเรียนเห็นคะแนนใหม่ทันทีโดยไม่ต้องเผยแพร่ใหม่
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ในแท็บ **ตรวจทาน** แตะการ์ด **คำขอให้ตรวจใหม่** (หรือ **คำขอตรวจใหม่** ในหน้าหลัก)
2. อ่านเลขข้อ ชื่อนักเรียน **คะแนนตอนนี้** และ **เหตุผลของนักเรียน** กด **ดูคำตอบ** ถ้าต้องการดูภาพ
3. กด **ตอบคำขอ** แล้วเลือก **ปรับคะแนน** และตั้งคะแนนใหม่ หรือ **ยืนยันคะแนนเดิม**
4. พิมพ์ **ข้อความถึงนักเรียน (ไม่บังคับ)** หรือ **เหตุผลถึงนักเรียน** เมื่อยืนยันคะแนนเดิม
5. กด **ส่งคำตอบ** ระบบแสดง **ตอบคำขอแล้ว ระบบแจ้งนักเรียนให้ทราบ**

**กรณีอื่น**

- **2ก** หน้า **ดูคำตอบ** แก้คะแนนไม่ได้เพราะผลเผยแพร่แล้ว ต้องปรับผ่าน **ตอบคำขอ**
- **4ก** ยืนยันคะแนนเดิมแต่ไม่พิมพ์เหตุผล: **บอกเหตุผลให้นักเรียนทราบว่าทำไมยืนยันคะแนนเดิม**
- **5ก** ข้อนั้นถูกสแกนใหม่และยังไม่เผยแพร่ผลใหม่: **ข้อนี้ถูกสแกนใหม่และกำลังตรวจอีกครั้ง ตอบคำขอได้หลังเผยแพร่ผลใหม่**

**นักเรียนขอได้ข้อละครั้ง ข้อสอบขอได้เฉพาะเมื่อครูเปิด **ให้นักเรียนดูเฉลย** (UC-T47)**

## แก้ผลที่เผยแพร่แล้ว

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: แก้คะแนนของนักเรียนที่เผยแพร่หรือประกาศผลไปแล้วเมื่อพบว่าผิด
เงื่อนไขก่อนเริ่ม: ผลของนักเรียนคนนั้นเผยแพร่แล้ว (UC-T43, UC-T56)
ผลลัพธ์: นักเรียนเห็นผลที่แก้ ทันทีเมื่อแก้ผ่านคำขอตรวจใหม่ หรือหลังเผยแพร่อีกครั้งเมื่อใช้วิธีอื่น
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. สแกนแผ่นนั้นอีกครั้งด้วยแอป Android (UC-T33, UC-T55) คิวอัปโหลดขึ้น **รอครูยืนยัน**
2. กด **ยืนยันแทนที่** ที่รายการนั้น หรือกด **ใช้สแกนใหม่** ในการ์ด **สแกนใหม่ของผลที่เผยแพร่แล้ว** ของคิวตรวจทาน แล้วยืนยัน
3. ระบบตรวจหน้านั้นใหม่ และซ่อนผลเดิมจากนักเรียน
4. ตรวจทานข้อของหน้านั้น แล้วเผยแพร่อีกครั้ง (UC-T40, UC-T43 หรือ UC-T56)

**กรณีอื่น**

- **1ก** นักเรียนขอให้ตรวจข้อนั้นใหม่แล้ว: ตอบคำขอด้วย **ปรับคะแนน** (UC-T44)
- **1ข** งานที่ส่งเป็นรูปหรือไฟล์: อัปโหลดงานใหม่ (UC-T39) แถวในแท็บ **รายคน** ขึ้น **ส่งใหม่ รอครูกดตรวจ** กด **ตรวจ** แล้วยืนยัน
- **1ค** เฉลยการบ้านผิด: แก้เฉลยแล้วกด **ตรวจใหม่ทั้งห้อง** (UC-T38)
- **2ก** สแกนใหม่ที่รอยืนยันเกิน 30 วันหมดอายุ ต้องสแกนหน้านั้นใหม่

**ข้อที่เผยแพร่แล้วมีแถบ **ผลนี้เผยแพร่แล้ว แก้ได้ผ่านคำขอตรวจใหม่หรือการสแกนใหม่เท่านั้น** ถ้าแก้คะแนนแล้วกดบันทึก ระบบแจ้ง **เผยแพร่ผลของนักเรียนคนนี้แล้ว แก้ได้ผ่านคำขอตรวจใหม่หรือการสแกนใหม่เท่านั้น** ให้ใช้วิธีข้างต้น**

## ส่งข้อที่ค้างให้ AI ตรวจหลังใส่ key

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ให้ AI ตรวจข้อที่ค้างเพราะตอนตรวจยังไม่มี Gemini API key หรือ key ใช้ไม่ได้
เงื่อนไขก่อนเริ่ม: คิวตรวจทานของการบ้านมีแถบ **ยังไม่ได้ใส่ Gemini API key** หรือแถบที่บอกจำนวนข้อที่ค้าง (ข้อที่ค้างมีป้าย **ตรวจเอง · ไม่มี key**)
ผลลัพธ์: ข้อที่ค้างและครูยังไม่ได้ให้คะแนนเองกลับไปให้ AI ตรวจ แล้วรอตรวจทานตามปกติ
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ในคิวตรวจทาน กด **ไปใส่ key** แล้วใส่ key ที่หน้าตั้งค่า (UC-T05)
2. กลับมาที่คิว แถบเปลี่ยนเป็น **มี N ข้อค้างจากตอนที่ยังไม่มี Gemini API key**
3. กด **ตรวจข้อที่ค้างใหม่** ระบบแสดง **ส่ง N ข้อกลับไปให้ AI ตรวจแล้ว ดึงรายการใหม่อีกครั้งในไม่กี่นาที**
4. รอสักครู่แล้วกดไอคอน **ดึงรายการใหม่** จากนั้นตรวจทานตามปกติ (UC-T40)

**กรณีอื่น**

- **1ก** ไม่ต้องการใช้ AI: ให้คะแนนข้อที่ค้างเองได้เลย ข้อที่ให้คะแนนแล้วไม่ถูกส่งตรวจซ้ำ
- **1ข** ข้อค้างเพราะ **Gemini API key ใช้ไม่ได้**: ใส่ key ใหม่แล้วใช้ปุ่มเดียวกัน
- **3ก** ยังไม่มี key: **ยังไม่มี Gemini API key ให้ใช้ ใส่ key ที่หน้าตั้งค่าก่อนแล้วลองอีกครั้ง**
- **3ข** ไม่มีข้อค้างแล้ว: **ไม่มีข้อที่ค้างเพราะไม่มี key**
