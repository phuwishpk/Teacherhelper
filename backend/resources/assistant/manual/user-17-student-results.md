# ดูผลและขอให้ครูตรวจใหม่

นักเรียนเห็นผลของงานหรือข้อสอบเมื่อครู **เผยแพร่ผล** แล้วเท่านั้น ก่อนหน้านั้นจะเห็นเพียงว่าส่งแล้ว ในแอป Android ที่เปิดการแจ้งเตือน นักเรียนจะได้รับแจ้งเมื่อผลออก

## เปิดดูผล

แตะ **ผลการบ้าน** ที่เมนูหลัก จะเห็นรายการผลที่เผยแพร่แล้ว ทั้งการบ้านและข้อสอบ แต่ละแถวบอกชื่องาน วันที่เผยแพร่ และคะแนนรวม แตะแถวเพื่อดูรายละเอียด

## อ่านผลของการบ้าน

ด้านบนคือชื่องาน วิชา วันที่เผยแพร่ และ **คะแนนรวม** ถัดลงมาเป็นการ์ดของแต่ละข้อ

| ส่วน | ความหมาย |
|---|---|
| **ข้อ N** และ **x/y คะแนน** | คะแนนที่ได้ของข้อนั้น เป็นสีเขียวเมื่อได้เต็ม |
| โจทย์ | โจทย์ของข้อนั้น |
| ป้ายระดับ | **เข้าใจดี** (เขียว) **เข้าใจบางส่วน** (ส้ม) หรือ **ยังไม่เข้าใจ** (แดง) |
| ภาพคำตอบ | ภาพคำตอบที่นักเรียนเขียน แตะเพื่อขยาย มีเฉพาะงานที่ครูสแกนจากใบงาน |
| **จุดที่ควรระวัง** | ประเภทของข้อผิดพลาดที่ครูยืนยัน เช่น คำนวณพลาด ตีความโจทย์ผิด |
| คำอธิบาย | ข้อความอธิบายว่าผิดตรงไหน และควรทำอย่างไร |
| **ขอให้ครูตรวจใหม่** | ปุ่มสำหรับขอให้ครูดูข้อนั้นอีกครั้ง |

**อ่านคำอธิบายทุกข้อที่ยังไม่ได้เต็ม**
คำอธิบายบอกจุดที่ผิดและวิธีคิดที่ถูก ลองทำข้อนั้นใหม่ในสมุดตามคำอธิบาย แล้วไปทำแบบฝึกของเรื่องเดียวกันในแท็บ **แบบฝึก** (บทที่ 19)

## อ่านผลของข้อสอบ

ผลของข้อสอบแสดงคะแนนรวม ชุดข้อสอบ (ถ้าสอบหลายชุด) และ **คะแนนรายตอน**

- ถ้าครูยังไม่เปิดให้ดูเฉลย จะขึ้นว่า **ครูยังไม่เปิดให้ดูเฉลยและผลรายข้อของข้อสอบนี้**
- เมื่อครูเปิดให้ดูเฉลย จะเห็นทุกข้อพร้อม **คำตอบของเรา** และ **คำตอบที่ถูก** และมีปุ่ม **ขอให้ครูตรวจใหม่**

ผลของข้อสอบไม่มีภาพกระดาษคำตอบ ป้ายระดับ และคำอธิบายรายข้อ

## ขอให้ครูตรวจใหม่

ถ้าคิดว่าครูให้คะแนนข้อใดไม่ถูก เช่น ระบบอ่านลายมือผิด นักเรียนขอให้ครูดูข้อนั้นอีกครั้งได้ **ข้อละ 1 ครั้ง**

1. เปิดผลของงานนั้น เลื่อนไปที่ข้อที่ต้องการ
2. กด **ขอให้ครูตรวจใหม่**
3. พิมพ์ **เหตุผล** (ไม่บังคับ ไม่เกิน 500 ตัวอักษร) เช่น "ครูช่วยดูบรรทัดที่ 2 อีกครั้ง" ยิ่งบอกชัด ครูยิ่งตรวจได้ตรงจุด
4. กด **ส่งคำขอ**

ปุ่มจะเปลี่ยนเป็นกล่องบอกสถานะของคำขอ ถ้าส่งไม่สำเร็จ ระบบแสดงเหตุผล เช่น **ข้อนี้ขอให้ครูตรวจใหม่ไปแล้ว** หรือ **ห้องนี้ปิดแล้ว (ห้องเก่า) ดูข้อมูลได้แต่แก้ไขไม่ได้** เมื่อครูปิดห้องไปแล้ว

| สถานะ | ความหมาย |
|---|---|
| **คำขอให้ครูตรวจใหม่: รอครูตรวจ** | ส่งคำขอแล้ว ครูยังไม่ได้ตอบ |
| **ครูปรับผลแล้ว** | ครูแก้คะแนนของข้อนั้น คะแนนรวมเปลี่ยนตาม |
| **ครูยืนยันผลเดิม** | ครูตรวจแล้วเห็นว่าคะแนนเดิมถูกต้อง |

ถ้าครูเขียนข้อความตอบ จะแสดงใต้สถานะขึ้นต้นด้วย **ครู:** ในแอป Android ที่เปิดการแจ้งเตือน นักเรียนจะได้รับแจ้งว่า **ครูตอบคำขอตรวจใหม่แล้ว**

**ขอได้ครั้งเดียวต่อข้อ**
เมื่อส่งคำขอของข้อใดไปแล้ว ขอซ้ำในข้อเดิมไม่ได้อีก จึงควรตรวจคำตอบของตัวเองกับคำอธิบายให้ดีก่อนส่ง และเขียนเหตุผลให้ครบในครั้งเดียว

## สิ่งที่นักเรียนไม่เห็น

- คะแนนที่ยังไม่เผยแพร่ และคะแนนที่ AI ให้ก่อนครูตรวจทาน
- คะแนน ผล หรืออันดับของเพื่อน
- เฉลยของข้อสอบ จนกว่าครูจะเปิดให้ดู
