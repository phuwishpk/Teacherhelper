# ผู้ช่วย Krucheck

บทนี้รวมงานที่ครูทำผ่านแชทกับ **ผู้ช่วย Krucheck** ตั้งแต่ถามวิธีใช้ระบบ ให้สร้างข้อ rubric ตัวชี้วัด การตั้งค่าสมุดคะแนน และแบบฝึก ถามเรื่องผลของนักเรียน ไปจนถึงให้อ่านไฟล์ของครู ผู้ช่วยใช้ Gemini API key ของครูเอง (UC-T05) ไม่ใช้ key กลางของเซิร์ฟเวอร์ ถามได้วันละ 100 ข้อความต่อครู ทุกคำสั่งที่บันทึกข้อมูลแสดงเป็นการ์ดให้ครูยืนยันก่อน และผลที่บันทึกเป็นแบบเดียวกับที่ครูทำเองในหน้าปกติ ผู้ช่วยไม่เผยแพร่ผล ไม่ลบ ไม่ปลดล็อกงาน และไม่ส่งอะไรถึงนักเรียนหรือ Google Classroom

## ถามผู้ช่วย Krucheck เรื่องการใช้ระบบ

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ได้คำตอบเรื่องวิธีใช้ Krucheck การให้คะแนน และการตัดเกรดโดยไม่ต้องค้นคู่มือเอง
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นครูแล้ว และใส่ Gemini API key ของตัวเองแล้ว (UC-T05)
ผลลัพธ์: ผู้ช่วยตอบเป็นภาษาไทยจากคู่มือของระบบ คำถามและคำตอบถูกเก็บในบทสนทนา
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. กดปุ่มรูปหุ่นยนต์ **ผู้ช่วย Krucheck** บนคอมพิวเตอร์อยู่ใกล้ล่างสุดของแถบด้านซ้ายและเปิดเป็นแผงด้านขวา บนแท็บเล็ตและมือถืออยู่มุมล่างซ้ายและเปิดเต็มหน้า
2. หน้าแชทว่างแสดง **ถามเรื่องการใช้ Krucheck การให้คะแนน หรือการตัดเกรดได้เลย** พร้อมตัวอย่างคำถาม เช่น **ตัดเกรดในสมุดคะแนนยังไง** แตะตัวอย่าง หรือพิมพ์คำถามในช่อง **พิมพ์คำถาม**
3. กดปุ่ม **ส่ง** ระหว่างรอ แชทแสดง **ผู้ช่วยกำลังคิด…** และช่องพิมพ์ถูกล็อก
4. อ่านคำตอบ แล้วถามต่อในบทสนทนาเดิมได้ ผู้ช่วยจำข้อความล่าสุดของบทสนทนา
5. ใต้ช่องพิมพ์แสดง **วันนี้ถามแล้ว N/100 ข้อความ** และจำนวนโทเค็นที่บทสนทนานี้ใช้

**กรณีอื่น**

- **1ก** ยังไม่ได้ใส่ key ของตัวเอง แชทแสดงข้อความว่าผู้ช่วยใช้ Gemini API key ของครูเอง พร้อมปุ่ม **ไปที่ตั้งค่า** (UC-T05) key กลางของเซิร์ฟเวอร์ใช้กับผู้ช่วยไม่ได้
- **3ก** ผู้ช่วยตอบไม่สำเร็จ ฟองข้อความแสดง **ผู้ช่วยตอบไม่สำเร็จ** สาเหตุ และรหัส เช่น **AI-QUOTA · #48213** หรือ **NET-OFFLINE** กดปุ่มคัดลอกรหัสเพื่อส่งให้ผู้ดูแลระบบ (UC-A16) หรือกด **ลองใหม่** การลองใหม่ไม่นับเป็นข้อความใหม่ของวัน
- **3ข** ถามครบ 100 ข้อความของวันนี้แล้ว ระบบแสดงรหัส **CHAT-LIMIT** ถามต่อได้วันถัดไป (นับตามวันของประเทศไทย) คำถามยาวได้ไม่เกิน 2,000 ตัวอักษร
- **4ก** ผู้ช่วยไม่แน่ใจ ผู้ช่วยบอกตรงๆ และแนะนำให้เปิดคู่มือการใช้งาน (UC-T08) ผู้ช่วยไม่แต่งฟังก์ชันที่ระบบไม่มี

## สร้างข้อผ่านผู้ช่วย

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ได้ข้อพร้อมเฉลยในการบ้านหรือข้อสอบจากการคุยกับผู้ช่วย โดยไม่ต้องพิมพ์ทีละข้อในหน้าปกติ
เงื่อนไขก่อนเริ่ม: ใช้ผู้ช่วยได้แล้ว (UC-T92) และมีห้องกับรายวิชา หรือการบ้านหรือข้อสอบที่ยังเพิ่มข้อได้
ผลลัพธ์: ข้อที่ครูติ๊กถูกสร้างในงานปลายทาง อยู่ในสถานะเดียวกับที่ครูพิมพ์เอง
ใช้ได้บน: เว็บ, Android
ขยายจาก: T92
```

**ขั้นตอนการใช้งาน**

1. พิมพ์สิ่งที่ต้องการ เช่น **ช่วยออกโจทย์ปรนัยเรื่องเศษส่วน 5 ข้อ ลงการบ้าน** หรือวางโจทย์ที่มีอยู่แล้วให้ผู้ช่วยแยกเป็นข้อพร้อมเฉลย
2. ถ้าข้อมูลไม่พอ เช่น ไม่บอกงาน จำนวนข้อ หรือคะแนน ผู้ช่วยถามกลับหนึ่งคำถาม ตอบแล้วผู้ช่วยทำการ์ดต่อ
3. ผู้ช่วยตอบเป็นการ์ด **ข้อที่เสนอ** แต่ละข้อมีช่องติ๊ก ชนิด คะแนน โจทย์ ตัวเลือก เฉลย **ทำไมถูก** และตัวชี้วัดที่เสนอ หัวการ์ดบอกงานปลายทาง (**ไปที่: «ชื่องาน»**)
4. ตรวจงานปลายทาง ถ้าไม่ใช่ กด **เปลี่ยน** แล้วเลือก **งานที่มีอยู่** หรือ **งานใหม่** สำหรับงานใหม่ กรอกห้อง รายวิชา **ชื่องาน** และ **ชนิด** (**ใบงานของแอป** **การบ้านไม่ใช้ใบงาน** หรือ **ข้อสอบกระดาษ**)
5. ติ๊กข้อที่ต้องการ แล้วกด **สร้างเลย (N ข้อ)** หรือพิมพ์ยืนยัน เช่น "โอเค สร้างเลย"
6. การ์ดเปลี่ยนเป็น **สร้างแล้ว N ข้อใน «ชื่องาน»** พร้อมข้อที่ข้ามและเหตุผล กด **เปิดการบ้าน** หรือ **เปิดข้อสอบ** เพื่อทำต่อ

**กรณีอื่น**

- **3ก** ข้อที่มีป้าย **ต้องใส่รูปเอง** ต้องใส่รูปประกอบในหน้าแก้ข้อหลังสร้าง (AI วาดรูปไม่ได้) ข้อที่มีป้าย **เฉลยไม่ครบ** หรือชนิดที่ใช้กับงานนั้นไม่ได้ ไม่ถูกติ๊กไว้ก่อน
- **3ข** อยากแก้ข้อที่เสนอ พิมพ์บอก เช่น "ข้อ 3 ยากไป" ผู้ช่วยทำการ์ดใหม่ทั้งชุด การ์ดเดิมที่ยังไม่ได้สร้างใช้ไม่ได้อีก
- **4ก** งานใหม่ที่สร้างจากการ์ดเป็นร่าง ยังไม่มีวันส่ง และยังไม่ส่งไป Google Classroom ข้อสอบใหม่ตรวจด้วยแอปและมี 1 ชุด
- **5ก** การบ้านที่ **พร้อมแล้ว** การ์ดเตือนว่า **งานนี้พร้อมแล้ว เพิ่มข้อแล้วงานจะกลับเป็นร่าง และต้องสร้าง layout ใหม่** การบ้านที่ปิดแล้วและข้อสอบที่พิมพ์แล้วเพิ่มข้อผ่านแชทไม่ได้ การ์ดพาไปหน้าข้อสอบแทน
- **6ก** หลังสร้าง การบ้านแบบใบงานกด **สร้าง layout** ได้เลย (UC-T30) การบ้านแบบไม่ใช้ใบงานต้องตรวจเฉลยแล้วกด **อนุมัติเฉลย** (UC-T37) ข้อแสดงวิธีทำและข้ออัตนัยต้องอนุมัติ rubric (UC-T29) และตัวชี้วัดที่ผู้ช่วยเสนอต้องยืนยันในหน้าจับคู่ตัวชี้วัด (UC-T31) ไม่มีปุ่มย้อนกลับ ลบข้อในหน้าปกติ (UC-T28)

## ร่าง rubric และจัดการตัวชี้วัดผ่านผู้ช่วย

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ให้ผู้ช่วยร่าง rubric ของข้อ เพิ่มตัวชี้วัด หรือเสนอตัวชี้วัดให้ข้อของงาน
เงื่อนไขก่อนเริ่ม: ใช้ผู้ช่วยได้แล้ว (UC-T92) สำหรับ rubric ต้องมีข้อแสดงวิธีทำหรืออัตนัยในงานที่ยังไม่ปิด
ผลลัพธ์: rubric ร่างถูกบันทึกให้ครูอนุมัติ หรือตัวชี้วัดถูกสร้าง เพิ่มลงตัวชี้วัดของฉัน หรือเสนอให้ข้อรอครูยืนยัน
ใช้ได้บน: เว็บ, Android
ขยายจาก: T92
```

**ขั้นตอนการใช้งาน**

1. rubric: พิมพ์งานและเลขข้อ เช่น "ทำ rubric ข้อ 5 ของการบ้านเรียงความ" ผู้ช่วยตอบเป็นการ์ด **ร่าง rubric ข้อ N** มีเกณฑ์และคะแนน (อัตนัย) หรือขั้นตอนอ้างอิง (แสดงวิธีทำ)
2. กด **บันทึกเป็นร่าง** การ์ดแสดง **บันทึก rubric ร่างของข้อ N แล้ว** กด **เปิดหน้า rubric** แล้วตรวจและกด **อนุมัติ** (UC-T29)
3. ตัวชี้วัด: พิมพ์สิ่งที่ต้องการ เช่น ให้เพิ่มตัวชี้วัดใหม่ใต้มาตรฐาน หรือให้เสนอตัวชี้วัดสำหรับข้อของงาน ผู้ช่วยตอบเป็นการ์ด **ตัวชี้วัดที่เสนอ** ให้ติ๊ก
4. ติ๊กรายการ แล้วกด **ทำตามที่เลือก (N)** ผลบอกว่า **เพิ่มตัวชี้วัดใหม่ N ตัว** **เพิ่มลงตัวชี้วัดของฉัน N ตัว** และ **เสนอให้ข้อ N รายการ**
5. กด **เปิดตัวชี้วัดของฉัน** (UC-T88) หรือ **เปิดหน้าจับคู่ตัวชี้วัด** เพื่อยืนยันข้อเสนอ (UC-T31)

**กรณีอื่น**

- **1ก** การ์ดมีปัญหา เช่น ข้อปรนัยหรือตอบสั้นไม่ต้องใช้ rubric คะแนนรวมไม่เท่าคะแนนเต็ม หรือไม่พบข้อ การ์ดแสดงปัญหาและปุ่มกดไม่ได้ ไม่ระบุข้อ ผู้ช่วยให้คำแนะนำเป็นข้อความแทนการ์ด
- **2ก** ข้อที่มี rubric อนุมัติแล้ว การ์ดเตือน **ข้อนี้มี rubric ที่อนุมัติแล้ว ร่างนี้จะแทนที่ และต้องอนุมัติใหม่** ถ้าข้อถูกแก้ชนิดหรือคะแนนหลังผู้ช่วยเสนอ ระบบไม่บันทึก ให้ขอการ์ดใหม่
- **3ก** ตัวชี้วัดใหม่ การ์ดเตือน **ตัวชี้วัดที่เพิ่มเองจะแชร์ให้ครูทุกคนในโรงเรียน** รหัสที่มีอยู่แล้วแสดง **รหัสนี้มีอยู่แล้ว** และรหัสแม่ที่ไม่พบแสดง **ไม่พบรหัสนี้ในหลักสูตร** รายการเหล่านี้ติ๊กไม่ได้
- **4ก** ตัวชี้วัดที่ไม่อยู่ในแผนหรือรายวิชาของงานเสนอให้ข้อไม่ได้ และตัวที่ **อยู่ในตัวชี้วัดของฉันแล้ว** ไม่ถูกเพิ่มซ้ำ

## ตั้งค่าสมุดคะแนนและสร้างแบบฝึกผ่านผู้ช่วย

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ตั้งหมวดคะแนน น้ำหนัก และเกณฑ์เกรดของรายวิชา หรือได้ข้อฝึกของตัวชี้วัดจากการคุยกับผู้ช่วย
เงื่อนไขก่อนเริ่ม: ใช้ผู้ช่วยได้แล้ว (UC-T92) สมุดคะแนนต้องเป็นรายวิชาที่ครูสร้างเอง
ผลลัพธ์: การตั้งค่าสมุดคะแนนถูกแทนทั้งชุด หรือข้อฝึกถูกบันทึกเป็นร่างรออนุมัติในคลังแบบฝึก
ใช้ได้บน: เว็บ, Android
ขยายจาก: T92
```

**ขั้นตอนการใช้งาน**

1. สมุดคะแนน: พิมพ์ เช่น "ตั้งหมวดคะแนนวิชาคณิต เก็บ 50 กลางภาค 20 ปลายภาค 30" ผู้ช่วยตอบเป็นการ์ด **ตั้งค่าสมุดคะแนน** แสดง **หมวดคะแนนใหม่** เทียบกับค่าเดิม และ/หรือ **เกณฑ์เกรด (4 ถึง 1)**
2. ตรวจการ์ด แล้วกด **บันทึกการตั้งค่า** การ์ดแสดง **บันทึกการตั้งค่าสมุดคะแนนของ «รายวิชา» แล้ว** กด **เปิดตั้งค่าหมวดคะแนน** เพื่อดูในหน้าปกติ (UC-T59)
3. แบบฝึก: พิมพ์ตัวชี้วัดและจำนวนข้อ ผู้ช่วยตอบเป็นการ์ด **แบบฝึกที่เสนอ N ข้อ** (ไม่เกิน 20 ข้อ ปรนัย ตอบสั้น หรือตัวเลข)
4. ติ๊กข้อที่ต้องการ แล้วกด **บันทึกเป็นร่าง (N)** การ์ดแสดง **บันทึกแบบฝึก N ข้อเป็นร่างแล้ว**
5. กด **เปิดคลังแบบฝึก** ตรวจและอนุมัติ นักเรียนจึงจะเห็น (UC-T70)

**กรณีอื่น**

- **1ก** หมวดที่ชื่อตรงกับหมวดเดิมใช้หมวดเดิม งานในหมวดนั้นอยู่ต่อ หมวดเดิมที่ไม่อยู่ในชุดใหม่ถูกเอาออก การ์ดบอกว่า **หมวด «ชื่อ» จะถูกเอาออก** และงานกี่ชิ้นในหมวดนั้นจะเป็น "ยังไม่ระบุหมวด"
- **1ข** น้ำหนักรวมไม่ครบ 100 ชื่อหมวดซ้ำ หรือเกณฑ์เกรดไม่ลดหลั่น การ์ดแสดงปัญหาและปุ่มกดไม่ได้ ให้พิมพ์บอกผู้ช่วยแก้
- **2ก** เกรดที่ประกาศแล้วไม่เปลี่ยนเอง การ์ดเตือน **ถ้าประกาศเกรดไว้แล้ว หลังบันทึกต้องประกาศอีกครั้ง** (UC-T63)
- **4ก** ข้อฝึกที่ไม่ผ่านการตรวจของระบบมีข้อความบอกเหตุผลและติ๊กไม่ได้

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ได้คำตอบเรื่องคะแนน การส่งงาน ตัวชี้วัดที่อ่อน เกรด และการเข้าเรียนของห้องที่สอน
เงื่อนไขก่อนเริ่ม: ใช้ผู้ช่วยได้แล้ว (UC-T92) และผู้ดูแลระบบไม่ได้ปิดความสามารถนี้ (UC-A12)
ผลลัพธ์: ผู้ช่วยตอบจากตัวเลขที่ระบบคำนวณ โดย Gemini เห็นนักเรียนเป็นรหัสแทนชื่อ แอปแสดงชื่อจริงพร้อมลิงก์
ใช้ได้บน: เว็บ, Android
ขยายจาก: T92
```

**ขั้นตอนการใช้งาน**

1. กดชิป **ข้อมูลนักเรียน** เหนือช่องพิมพ์
2. ครั้งแรก อ่านคำอธิบายว่าผู้ช่วยจะส่งคะแนน การส่งงาน ผลรายข้อ ตัวชี้วัด และการเข้าเรียนของนักเรียนในห้องที่ครูสอนไปให้ Gemini โดยแทนนักเรียนด้วยรหัส เช่น S1 แล้วกด **เข้าใจแล้ว**
3. เลือกขอบเขต **ห้อง** **นักเรียน** หรือ **งาน** ชิปขึ้นเป็น **ข้อมูล: (ชื่อ)**
4. พิมพ์คำถาม เช่น **ห้องไหนส่งงานไม่ครบบ้าง** หรือ "ข้อไหนในข้อสอบกลางภาคที่ห้องนี้ผิดมาก"
5. อ่านคำตอบ ชื่อนักเรียนในคำตอบเป็นชื่อจริง และมีชิปลิงก์ไปหน้าทักษะของนักเรียนคนนั้น (UC-T67)

**กรณีอื่น**

- **1ก** ไม่เลือกขอบเขต ผู้ช่วยเลือกชุดข้อมูลเอง (สรุปห้อง ประวัติรายคน หรือวิเคราะห์รายข้อของงาน) หรือถามกลับว่าห้องไหนหรือใคร
- **3ก** กด **เลิกใช้ข้อมูลนี้** เพื่อถามต่อโดยไม่ส่งข้อมูลนักเรียน
- **4ก** ชื่อนักเรียนที่ครูพิมพ์ถูกแทนด้วยรหัสก่อนส่งให้ AI ใต้ช่องพิมพ์เตือนว่า **ชื่อนักเรียนที่พิมพ์จะถูกแทนด้วยรหัสก่อนส่งให้ AI อย่าพิมพ์เลขประจำตัวหรือข้อมูลติดต่อ**
- **4ข** ข้อมูลมาจากห้องที่ครูสอนเท่านั้น ครูประจำชั้นเห็นทุกรายวิชาของห้อง ครูประจำวิชาเห็นเฉพาะรายวิชาของตัวเอง ขอบเขตที่ครูไม่มีสิทธิ์ ระบบไม่ส่งข้อมูล
- **ทุกขั้น** ผู้ดูแลระบบปิดความสามารถนี้ของพื้นที่ของครูไว้ ผู้ช่วยบอกว่าใช้ไม่ได้ และยังตอบคำถามอื่นได้ตามปกติ

**ข้อมูลที่ไม่ส่งให้ AI**
ระบบไม่ส่งชื่อ เลขที่ เลขประจำตัว ข้อมูลติดต่อ ภาพลายมือ หรือข้อความที่นักเรียนเขียนให้ Gemini ถ้าครูใช้ key ฟรี Google อาจนำข้อมูลไปปรับปรุงบริการ ควรใช้ key ของบัญชีที่เปิดการชำระเงิน

## ให้ผู้ช่วยอ่านไฟล์

```uc
ผู้ใช้หลัก: ครู
ผู้ใช้รอง: Gemini
เป้าหมาย: ใช้ไฟล์ของครู (ใบงาน เฉลย ข้อสอบ คำอธิบายรายวิชา แผนการสอน) สร้างงานหรือข้อมูลในระบบผ่านแชท
เงื่อนไขก่อนเริ่ม: ใช้ผู้ช่วยได้แล้ว (UC-T92) และมีไฟล์ PDF หรือรูปของเอกสารครู
ผลลัพธ์: ได้การ์ดสร้างข้อจากไฟล์ หรือระบบอ่านไฟล์เบื้องหลังแล้วให้ครูตรวจผลในหน้าปกติ
ใช้ได้บน: เว็บ, Android
ขยายจาก: T92
```

**ขั้นตอนการใช้งาน**

1. กดไอคอนคลิปหนีบ **แนบเอกสารของครู (PDF หรือรูป)** แล้วเลือกไฟล์ ระบบอัปโหลดทันทีและแสดงไฟล์เป็นชิป พร้อมคำเตือน **แนบเฉพาะเอกสารของครู อย่าแนบไฟล์ที่มีชื่อหรือคำตอบของนักเรียน**
2. พิมพ์บอกว่าจะใช้ไฟล์ทำอะไร เช่น "ทำการบ้านจากใบงานนี้" หรือ "อ่านเฉลยการบ้านเศษส่วน"
3. ถ้าเป็นไฟล์ใบงานสำหรับการบ้าน และยังไม่ได้บอกแบบ ผู้ช่วยถามว่าจะทำเป็น (ก) ใบงานของแอป ซึ่งแนะนำ หรือ (ข) การบ้านไม่ใช้ใบงาน
4. แบบ (ก) หรือคำขอสร้างข้อจากไฟล์ ผู้ช่วยอ่านไฟล์แล้วตอบเป็นการ์ดข้อที่เสนอ ทำต่อตาม UC-T93
5. งานอ่านไฟล์อื่น ผู้ช่วยตอบเป็นการ์ด **อ่านไฟล์** เช่น **อ่านเฉลยจากไฟล์** **อ่านข้อสอบจากไฟล์** **อ่านคำอธิบายหรือโครงสร้างรายวิชาจากไฟล์** หรือ **อ่านแผนการสอนจากไฟล์** กด **ส่งไฟล์ไปอ่าน**
6. เมื่ออ่านเสร็จ กดปุ่มในการ์ด เช่น **เปิดหน้าเฉลย** **เปิดข้อสอบ** หรือ **ตรวจและนำเข้า** แล้วตรวจผลในหน้าปกติก่อนใช้ (UC-T37, UC-T49, UC-T26)

**กรณีอื่น**

- **1ก** ไฟล์ละไม่เกิน 10 MB และ 30 หน้า แนบได้ไม่เกิน 5 ไฟล์ต่อคำถาม กด **เอาไฟล์ออก** ก่อนส่งถ้าเลือกผิด
- **4ก** ไฟล์รวมเกิน 10 หน้า ผู้ช่วยสร้างการ์ดข้อจากไฟล์ไม่ได้ และแนะนำให้แบ่งไฟล์หรือใช้การ์ดอ่านไฟล์แทน
- **5ก** ผู้ช่วยหางานปลายทางไม่พบ การ์ดบอกให้พิมพ์บอกผู้ช่วยว่าจะใช้กับงานหรือรายวิชาไหน
- **5ข** ไฟล์ที่เคยอ่านแล้ว การ์ดแสดง **อ่านไฟล์นี้ไว้แล้ว ได้ผลทันที** อ่านไม่สำเร็จ การ์ดแสดง **อ่านไฟล์ไม่สำเร็จ**
- **6ก** ยังอ่านไม่เสร็จ การ์ดแสดง **ยังอ่านไฟล์ไม่เสร็จ ลองอีกครั้งในอีกสักครู่**

## จัดการบทสนทนากับผู้ช่วย

```uc
ผู้ใช้หลัก: ครู
เป้าหมาย: เริ่มเรื่องใหม่ กลับไปอ่านบทสนทนาเดิม หรือลบบทสนทนาที่ไม่ต้องการ
เงื่อนไขก่อนเริ่ม: เปิดผู้ช่วยแล้ว (UC-T92)
ผลลัพธ์: ครูอยู่ในบทสนทนาที่ต้องการ หรือบทสนทนาที่เลือกถูกลบ
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. กดปุ่ม **บทสนทนาใหม่** บนแถบของแชทเพื่อเริ่มเรื่องใหม่ ผู้ช่วยไม่เห็นข้อความของบทสนทนาอื่น
2. กดปุ่ม **บทสนทนาทั้งหมด** รายการแสดงบทสนทนาเดิมพร้อมเวลาล่าสุดและจำนวนโทเค็น
3. แตะบทสนทนาเพื่อเปิดอ่านและถามต่อ กด **กลับไปที่แชท** เพื่อกลับ
4. ลบ: กดปุ่ม **ลบบทสนทนา** ของบทสนทนานั้น กล่อง **ลบบทสนทนานี้?** บอกว่าจะถูกลบถาวร กด **ลบ**

**กรณีอื่น**

- **2ก** ยังไม่เคยถาม รายการแสดง **ยังไม่มีบทสนทนา**
- **ทุกขั้น** ปิดแผงหรือหน้าแชทระหว่างรอคำตอบไม่ทำให้คำตอบหาย เปิดกลับมาก็เห็นต่อ
- **ทุกขั้น** บทสนทนาที่ไม่ได้ใช้ 90 วันถูกลบเอง (UC-X06) ผู้ดูแลระบบเปิดอ่านได้เพื่อช่วยแก้ปัญหา (UC-A17)
