# ภาคผนวก

## ก. งานที่ทำได้บนเว็บและในแอป Android

| งาน | เว็บ | แอป Android |
|---|---|---|

| ครู สแกนใบงานและกระดาษคำตอบด้วยกล้อง | ไม่ได้ | ได้ |
| ครู สแกนกระดาษเฉลยของข้อสอบ | ไม่ได้ | ได้ |
| ครู คิวอัปโหลด และสแกนแบบไม่มีอินเทอร์เน็ต | ไม่มี | มี |
| ครู อัปโหลดรูปหรือ PDF ของงานนักเรียน | ได้ | ได้ |
| ครู ตรวจทาน เผยแพร่ ตอบคำขอให้ตรวจใหม่ | ได้ | ได้ |
| ครู สมุดคะแนน ตัดเกรด ส่งออก CSV | ได้ | ได้ |
| ครู ทักษะ กราฟ วิเคราะห์รายคน คลังแบบฝึก | ได้ | ได้ |
| **นักเรียน** เข้าด้วยชื่อผู้ใช้และรหัสผ่าน หรือ Google | ได้ | ได้ |
| นักเรียน เข้าห้องด้วยรหัสห้อง | ได้ (สแกน QR ด้วยกล้องมือถือจะเปิดหน้านี้) | ได้ (กรอกรหัส 6 ตัว) |
| นักเรียน ส่งงานด้วยการเลือกไฟล์ | ได้ | ได้ |

| นักเรียน ดูผล ขอให้ครูตรวจใหม่ ทำแบบฝึก ดูเกรดและกราฟ | ได้ | ได้ |
| **ครู** ผู้ช่วย Krucheck | ได้ | ได้ |
| กล่องการแจ้งเตือนในแอป (ปุ่มกระดิ่ง) | มี เมื่อผู้ดูแลระบบเปิดใช้ | มี เมื่อผู้ดูแลระบบเปิดใช้ |

## ข. ข้อจำกัดของระบบ

| เรื่อง | ค่า |
|---|---|
| นักเรียนที่เพิ่มต่อครั้ง | ไม่เกิน 100 คน เลขที่ 1–255 เลขประจำตัวไม่เกิน 20 ตัว |
| รหัสผ่านของนักเรียน | อย่างน้อย 6 ตัว ใส่ผิดหลายครั้งถูกล็อก 15 นาที |
| การจำการเข้าสู่ระบบ | ครู 30 วัน นักเรียน 180 วัน |
| เอกสารที่ส่งให้ AI อ่าน (เฉลย แผนการสอน ข้อสอบ) | PDF, JPEG, PNG, HEIC, WebP ไม่เกิน 10 ไฟล์ ไฟล์ละไม่เกิน 10 MB รวมกันไม่เกิน 20 MB และไม่เกิน 30 หน้าต่อการอ่านหนึ่งครั้ง |
| งานที่นักเรียนส่ง หรือครูอัปโหลดแทน | 1–5 ไฟล์ รวมไม่เกิน 5 หน้า ไฟล์ละไม่เกิน 10 MB |
| ภาพประกอบโจทย์ของข้อสอบ | JPG, PNG, WebP ไม่เกิน 5 MB หนึ่งภาพต่อโจทย์หรือตัวเลือก |
| ข้อสอบ | ไม่เกิน 10 ตอน 200 ข้อ ตัวเลือก 2–6 ตัว เติมตัวเลข 1–5 หลัก 1–4 ชุด กระดาษคำตอบไม่เกิน 2 หน้า |
| กระดาษคำตอบ | แบบ QR รายคน 100 ข้อต่อหน้า แบบฝนเลขประจำตัว 60 ข้อต่อหน้า |
| สมุดคะแนน | ไม่เกิน 10 หมวด คะแนนเต็มของรายการไม่เกิน 1,000 ตัดคะแนนต่ำสุดได้ไม่เกิน 5 รายการต่อหมวด |
| คำขอให้ครูตรวจใหม่ | ข้อละ 1 ครั้ง เหตุผลไม่เกิน 500 ตัวอักษร |
| แบบฝึก | แนะนำไม่เกิน 3 ข้อต่อทักษะ ข้อเดิมกลับมาหลัง 7 วัน |
| การรอสร้าง PDF | ไม่เกิน 5 นาทีต่อครั้ง |
| ผู้ช่วย Krucheck | 100 ข้อความต่อครูต่อวัน คำถามละไม่เกิน 2,000 ตัวอักษร แนบไม่เกิน 5 ไฟล์ต่อคำถาม |

## ค. การเก็บและลบข้อมูล

| ข้อมูล | เก็บไว้ถึงเมื่อใด |
|---|---|
| ภาพเต็มหน้าของใบงานและกระดาษคำตอบที่สแกน | ลบหลังเผยแพร่หรือประกาศผลของนักเรียนคนนั้น |
| ภาพคำตอบรายข้อ และรูปงานที่ส่งเป็นรูปทั้งหน้า | ถึงวันที่ผู้ดูแลระบบกำหนดให้ครูแต่ละคน ตามปกติคือสิ้นปีการศึกษา หลังจากนั้นหน้าผลจะขึ้นว่า **ภาพนี้ถูกลบตามนโยบายการเก็บข้อมูลแล้ว** |
| ไฟล์ PDF ที่ระบบสร้าง (ใบงาน ข้อสอบ) | 30 วันหลังสร้าง สร้างใหม่ได้ |
| เอกสารที่ครูแนบให้ AI อ่าน | 30 วันหลังอัปโหลด ส่วนผลที่อ่านได้เก็บต่อ |
| คะแนน ผลการตรวจ คำอธิบาย และเกรด | เก็บต่อเนื่อง ดูย้อนหลังได้แม้ปิดห้องแล้ว |
| ภาพสแกนที่ยังไม่ได้ส่ง (ในมือถือของครู) | อยู่ในเครื่องจนส่งสำเร็จ และถูกลบเมื่อออกจากระบบ |
| บทสนทนากับผู้ช่วย Krucheck | ลบเองเมื่อไม่ได้ใช้ 90 วัน ครูลบเองได้ทุกเมื่อ |
| รายการในกล่องการแจ้งเตือน | เก็บไว้ใน Firestore จนกว่าบัญชีจะถูกลบ ข้อความไม่มีคะแนน |
| บัญชีที่ผู้ดูแลระบบลบ | เข้าใช้ไม่ได้ทันที กู้คืนได้ภายใน 30 วัน หลังจากนั้นข้อมูลส่วนตัวถูกลบถาวร คะแนนเก็บต่อแบบไม่มีชื่อ ถ้าเป็นบัญชีครู ห้องที่ครูเป็นเจ้าของถูกลบทั้งห้อง |

ไฟล์ทุกชนิดไม่มีลิงก์สาธารณะ ต้องเข้าสู่ระบบและมีสิทธิ์จึงเปิดได้ นักเรียนเห็นเฉพาะข้อมูลของตัวเอง

## ง. คำศัพท์ที่ใช้ในระบบ

| คำ | ความหมาย |
|---|---|
| **ใบงานของแอป** | ใบงานที่พิมพ์จาก Krucheck มี QR และกรอบคำตอบ ใช้กับการสแกน |
| **Layout** | การจัดหน้าของใบงานหรือกระดาษคำตอบที่ระบบจำตำแหน่งไว้ มีเลขเวอร์ชัน |
| **Rubric** | เกณฑ์การให้คะแนนของข้อแสดงวิธีทำและข้ออัตนัย |
| **ตรวจทาน** | การที่ครูดูและยืนยันคะแนนที่ AI เสนอ |
| **เผยแพร่ / ประกาศผล** | ทำให้นักเรียนเห็นผลของการบ้านหรือข้อสอบ |
| **ประกาศเกรด** | ทำให้นักเรียนเห็นเกรดของรายวิชา |
| **ตัวชี้วัด / ทักษะ** | สิ่งที่หลักสูตรกำหนดให้นักเรียนทำได้ ระบบใช้ติดตามระดับความเข้าใจ |
| **ระดับความเข้าใจ** | เข้าใจดี เข้าใจบางส่วน หรือยังไม่เข้าใจ |
| **ครูประจำชั้น / ครูประจำวิชา** | เจ้าของห้องเรียน / ครูที่ตอบรับคำเชิญสอนร่วมและผูกรายวิชาของตัวเองกับห้องของครูท่านอื่น |
| **รหัสห้อง** | รหัส 6 ตัวของห้องเรียน นักเรียนใช้เข้าห้อง (พิมพ์หรือสแกน QR) |
| **ชื่อผู้ใช้** | ชื่อที่นักเรียนใช้เข้าสู่ระบบ ระบบตั้งให้และครูแก้ได้ |
| **ห้องเก่า** | ห้องเรียนที่ปิดแล้ว ดูได้อย่างเดียว |
| **Gemini API key** | รหัสสำหรับเรียกใช้ AI ของ Google ที่ครูใส่ในหน้าตั้งค่า |
| **ผู้ช่วย Krucheck** | แชทกับ AI สำหรับครู ทำงานด้วย Gemini API key ของครู |
| **ตัวชี้วัดของฉัน** | ตัวชี้วัดของวิชาและชั้นที่ครูเลือกไว้ว่าสอน หน้าเลือกตัวชี้วัดจะแสดงเฉพาะชุดนี้ |
| **รหัสข้อผิดพลาด** | รหัสเช่น AI-QUOTA · #48213 ที่บอกสาเหตุเมื่อ AI ทำงานไม่สำเร็จ ใช้แจ้งผู้ดูแลระบบ |
| **ข้อมูลสด (Firestore)** | บริการคลาวด์ที่ทำให้กล่องการแจ้งเตือนอัปเดตทันที ข้อมูลหลักยังอยู่บนเซิร์ฟเวอร์ของ Krucheck |
| **คิวอัปโหลด** | รายการภาพสแกนในมือถือที่รอส่งขึ้นเซิร์ฟเวอร์ |
| **CNN** | ตัวอ่านตัวเลขลายมือที่ทำงานในมือถือ ใช้ช่วยยืนยันคำตอบที่เป็นตัวเลข |
