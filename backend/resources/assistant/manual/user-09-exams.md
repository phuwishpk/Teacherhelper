# ข้อสอบและกระดาษคำตอบ

ข้อสอบใน Krucheck เป็นข้อสอบแบบ **ฝนคำตอบ** ครูพิมพ์เล่มข้อสอบและกระดาษคำตอบจากระบบ นักเรียนฝนด้วยดินสอ แล้วครูสแกนกระดาษคำตอบด้วยมือถือ แอปให้คะแนนทันทีจากรอยฝนเทียบกับเฉลย ไม่ได้ใช้ AI ตรวจ จึงไม่ต้องมี Gemini API key (ยกเว้นเมื่อให้ AI อ่านข้อสอบจากไฟล์)

## สร้างข้อสอบ

1. ที่แท็บ **การบ้าน** กด **สร้างข้อสอบ**
2. กรอกฟอร์มตามตารางด้านล่าง แล้วกด **สร้างข้อสอบ**
3. ระบบเปิดหน้าข้อสอบให้เพิ่มตอนและข้อได้ทันที

| ช่อง | ความหมาย |
|---|---|
| **ชื่อข้อสอบ** | ต้องกรอก พิมพ์บนเล่มข้อสอบและกระดาษคำตอบ |
| **ห้องเรียน** | ห้องที่สอบ เลือกได้ตอนสร้างเท่านั้น แก้ภายหลังไม่ได้ |
| **รายวิชา** | ต้องเลือก หลังเลือกแล้วจะมีช่อง **แผนการสอน (ไม่บังคับ)** |
| **เลือกวันสอบ** | ต้องกำหนด หลังวันสอบ สมุดคะแนนจะนับช่องที่ยังว่างเป็น 0 |
| **เวลาสอบ (นาที)** | ไม่บังคับ 1–600 นาที พิมพ์บนหน้าแรกของเล่มข้อสอบ |
| **วิธีตรวจ** | **ตรวจด้วยแอป** พิมพ์กระดาษคำตอบให้นักเรียนฝนแล้วสแกน หรือ **ครูตรวจเอง** ครูตรวจนอกแอปแล้วกรอกคะแนนรวมในสมุดคะแนน (หัวข้อ 9.9) |
| **จำนวนชุดข้อสอบ** | **1 ชุด** ถึง **4 ชุด** (ชุด ก–ง) ชุด ก เป็นลำดับต้นฉบับ ชุดอื่นสลับข้อภายในตอนและสลับตัวเลือก |
| **กระดาษคำตอบระบุตัวนักเรียนด้วย** | **QR รายคน** หรือ **ฝนเลขประจำตัว** ดูตารางถัดไป |
| **ให้นักเรียนดูเฉลย** | เมื่อเปิด นักเรียนเห็นเฉลยรายข้อหลังครูประกาศผล และขอให้ครูตรวจใหม่ได้ เมื่อปิด นักเรียนเห็นเฉพาะคะแนนรวมและคะแนนรายตอน |
| **หมวดคะแนน** | มีเมื่อตั้งค่าสมุดคะแนนของรายวิชาแล้ว ต้องเลือกเสมอ เช่น กลางภาค หรือปลายภาค ถ้าไม่เลือก ระบบขึ้นว่า **เลือกหมวดคะแนนของข้อสอบ** ข้อสอบที่ไม่ต้องการให้นับคะแนน ให้เลือกหมวดแล้วเปิด **ไม่นับเกรด** เพิ่ม สวิตช์นี้ใช้แทนการเลือกหมวดไม่ได้ (บทที่ 10) |

กระดาษคำตอบมี 2 แบบ เลือกให้เหมาะกับวิธีแจกกระดาษของโรงเรียน

| | **QR รายคน** | **ฝนเลขประจำตัว** |
|---|---|---|
| กระดาษคำตอบ | ของแต่ละคน มีชื่อและ QR พิมพ์ให้แล้ว | ใบเดียวใช้ทั้งห้อง ถ่ายเอกสารแจกได้ |
| นักเรียนต้องทำ | ฝนคำตอบอย่างเดียว | เขียนชื่อ ฝนเลขประจำตัว แล้วฝนคำตอบ |
| จำนวนข้อต่อหน้า | 100 ข้อ | 60 ข้อ |
| ตอนสแกน | แอปรู้ชื่อจาก QR | แอปอ่านเลขประจำตัวที่ฝน ถ้าอ่านไม่ได้ครูเลือกชื่อเอง |
| เหมาะกับ | ห้องที่พิมพ์ได้ครบทุกคน | ห้องที่ต้องถ่ายเอกสาร หรือสอบหลายห้องพร้อมกัน |

เมื่อเลือก **ฝนเลขประจำตัว** ให้ตั้ง **จำนวนหลักของเลขประจำตัว** (4–13 หลัก ระบบเสนอจากเลขที่ยาวที่สุดในห้อง) เลขที่สั้นกว่าให้นักเรียนฝนชิดขวา นักเรียนที่ไม่มีเลขประจำตัว ครูเลือกชื่อเองตอนสแกน

**เปลี่ยนวิธีตรวจภายหลัง**
เปลี่ยนจาก **ครูตรวจเอง** เป็น **ตรวจด้วยแอป** ได้ แต่คะแนนที่กรอกเองในสมุดคะแนนของข้อสอบนี้จะถูกลบ ส่วนการเปลี่ยนจาก **ตรวจด้วยแอป** เป็น **ครูตรวจเอง** ทำไม่ได้เมื่อมีกระดาษคำตอบสแกนเข้ามาแล้ว

## เพิ่มตอนและข้อ

ข้อสอบแบ่งเป็น **ตอน** แต่ละตอนมีข้อชนิดเดียวกัน ข้อสอบหนึ่งชุดมีได้สูงสุด 10 ตอน รวม 200 ข้อ

### เพิ่มตอน

กด **เพิ่มตอน** แล้วกรอก

| ช่อง | ความหมาย |
|---|---|
| **ชื่อตอน** และ **คำชี้แจง** | ไม่บังคับ พิมพ์เหนือข้อของตอนนั้นในเล่มข้อสอบ |
| **ชนิดของข้อ** | **ปรนัย**, **ถูก/ผิด** หรือ **เติมตัวเลข** เปลี่ยนภายหลังไม่ได้ ต้องลบตอนแล้วสร้างใหม่ |
| **จำนวนตัวเลือก** | เฉพาะปรนัย 2–6 ตัวเลือก |
| **จำนวนหลัก** | เฉพาะเติมตัวเลข 1–5 หลัก เปิด **มีช่องเครื่องหมายลบ** และ **มีจุดทศนิยม** ได้ |
| **คะแนนต่อข้อ** | มากกว่า 0 ถึง 100 |
| **จำนวนข้อ** | ระบบสร้างข้อเปล่าให้ตามจำนวนนี้ (0–100) แล้วครูกรอกโจทย์ทีหลัง |

เมนู **⋯** ของตอนมี **แก้ไขตอน**, **ย้ายขึ้น**, **ย้ายลง** และ **ลบตอน** (ข้อทั้งหมดในตอนรวมภาพและเฉลยจะถูกลบด้วย)

### กรอกโจทย์ของแต่ละข้อ

แตะข้อในรายการ หรือกด **เพิ่มข้อในตอนนี้** ()

1. พิมพ์ **โจทย์** (ไม่เกิน 2,000 ตัวอักษร สูตรให้พิมพ์เป็นข้อความ เช่น `x^2 + 3x = 10`) กด **เพิ่มภาพโจทย์** ถ้ามีรูปประกอบ (JPG, PNG หรือ WebP ไม่เกิน 5 MB หนึ่งรูป)
2. ข้อปรนัย พิมพ์ **ตัวเลือก** ก ข ค ง … แต่ละตัวเลือกใส่ภาพได้ ตัวเลือกที่เว้นว่างจะพิมพ์เฉพาะตัวอักษร
3. เลือก **เฉลย**
   - ปรนัย แตะตัวอักษรที่ถูก เลือกได้หลายตัว (นักเรียนฝนตัวใดตัวหนึ่งที่เลือกไว้ได้คะแนนเต็ม)
   - ถูก/ผิด เลือกหนึ่งอย่าง
   - เติมตัวเลข พิมพ์ **ค่าที่ยอมรับ** คั่นด้วยจุลภาค ได้สูงสุด 10 ค่า และต้องไม่ยาวเกินจำนวนหลักของตอน
4. แก้ **คะแนนเต็มของข้อ** ถ้าต้องการให้ต่างจากคะแนนต่อข้อของตอน
5. กด **บันทึก**

เปิด **ห้ามสลับตัวเลือก** กับข้อที่ลำดับตัวเลือกมีความหมาย เช่น มีตัวเลือก "ถูกทุกข้อ" ทุกชุดจะพิมพ์ตัวเลือกของข้อนี้ตามลำดับเดิม ระบบจะขึ้นการ์ด **แนะนำ: ห้ามสลับตัวเลือก** ให้เองเมื่อพบตัวเลือกลักษณะนี้

### อ่านข้อจากไฟล์ข้อสอบด้วย AI

ถ้ามีข้อสอบเป็นไฟล์อยู่แล้ว กด **อ่านข้อจากไฟล์ข้อสอบ** ต้องมี Gemini API key

1. เลือก **แนบไฟล์ (PDF หรือรูป)** หรือ **ถ่ายรูปข้อสอบ** (PDF, JPEG, PNG, HEIC, WebP ไม่เกิน 10 ไฟล์ ไฟล์ละไม่เกิน 10 MB รวมกันไม่เกิน 20 MB และ 30 หน้า)
2. ที่หน้า **ส่งให้ AI อ่านข้อสอบ** ตรวจ **ค่าใช้จ่ายโดยประมาณ** แล้วกดส่ง
3. รอ 1–3 นาที ระหว่างนี้ออกจากหน้าได้ เมื่อเสร็จ ระบบบอกว่า **อ่านได้ N ตอน M ข้อ**
4. ที่หน้า **ตรวจข้อที่อ่านจากไฟล์** ตรวจโจทย์ ตัวเลือก และเฉลยของแต่ละข้อ กด **แก้ไข** ถ้าผิด แล้วกด **อนุมัติข้อนี้** หรือ **เลือกทั้งหมด** แล้ว **อนุมัติที่เลือก (N)**

ข้อที่ฝนตอบไม่ได้ (เช่น ข้อเขียน) AI จะข้าม ข้อที่อ่านมามีป้าย **ร่างจากไฟล์ ยังไม่อนุมัติ** และพิมพ์ไม่ได้จนกว่าครูจะอนุมัติ ภาพประกอบจากไฟล์ PDF หรือ HEIC ต้องกด **สร้างภาพประกอบ** ในแอป Android

**ห้ามมีข้อมูลนักเรียนในไฟล์**
อย่าแนบไฟล์ที่มีชื่อหรือคำตอบของนักเรียน ผลการอ่านไฟล์ถูกเก็บไว้ใช้ซ้ำ

### คัดลอกจากข้อสอบเดิม

กด **คัดลอกจากข้อสอบเดิม** ค้นด้วยคำในโจทย์ หรือกรองตาม **รายวิชา** และ **ข้อสอบ** ติ๊กข้อที่ต้องการ เลือก **คัดลอกไปที่** (**ตอนใหม่ ตามตอนต้นทาง** หรือตอนที่มีอยู่) แล้วกด **คัดลอก N ข้อ** ข้อที่คัดลอกมาจะมีเฉลยและการอนุมัติติดมาด้วย คัดลอกได้เฉพาะจากข้อสอบของครูเอง

### ผูกข้อกับตัวชี้วัด

กด **จับคู่ตัวชี้วัด** เพื่อผูกแต่ละข้อกับตัวชี้วัดของรายวิชา วิธีใช้เหมือนของการบ้าน (หัวข้อ 5.6) ข้อที่ยังไม่ผูกได้คะแนนตามปกติ แต่ไม่นับในกราฟและตารางทักษะ หน้าข้อสอบจะเตือนว่า **มี N ข้อยังไม่ผูกตัวชี้วัด คะแนนข้อเหล่านี้จะไม่นับในกราฟ**

## ตารางเฉลยและการอนุมัติเฉลย

ข้อสอบต้อง **อนุมัติเฉลย** ก่อนจึงจะพิมพ์เล่มให้นักเรียน พิมพ์กระดาษคำตอบ สแกน และประกาศผลได้ การ์ดเฉลยในหน้าข้อสอบบอกว่ายังขาดข้อใด เช่น **เฉลยยังไม่ครบ N ข้อ**

1. กด **ตารางเฉลย** จะเห็นทุกข้อเรียงเป็นแถว
2. แตะตัวอักษรที่ถูกของแต่ละข้อ หรือพิมพ์ตัวเลขของข้อเติมตัวเลข แถวที่ยังไม่บันทึกมีจุดกำกับ
3. กด **บันทึก (N ข้อ)**
4. เมื่อเฉลยครบและบันทึกแล้วทุกข้อ กด **อนุมัติเฉลย**

เฉลยในตารางอ้างลำดับตัวเลือกของ **ชุด ก** เสมอ เฉลยของชุดอื่นระบบคำนวณให้เอง หลังอนุมัติแล้วยังแก้เฉลยได้ แต่ถ้าเฉลยไม่ครบ การอนุมัติจะถูกยกเลิก

**สแกนกระดาษเฉลยแทนการแตะทีละข้อ**
ถ้าข้อสอบมีหลายข้อ ครูพิมพ์ **กระดาษเฉลยของครู** (หัวข้อ 9.5) ฝนเฉลยของชุดใดชุดหนึ่งด้วยดินสอ แล้วในหน้าตารางเฉลยกดไอคอน **สแกนกระดาษเฉลย** ถ่ายทีละหน้า (เริ่มจากหน้า 1 และฝนวงชุดที่หน้า 1 ด้วย) จากนั้นกด **เติมในตารางเฉลย** ตรวจแถวที่มีหมายเหตุ เช่น **รอยฝนบนกระดาษเฉลยไม่ชัด ตรวจอีกครั้ง** แล้วกด **บันทึก** และ **อนุมัติเฉลย** การสแกนกระดาษเฉลยต้องต่ออินเทอร์เน็ต

## ชุดข้อสอบ

กด **ชุดข้อสอบ (N ชุด)** เพื่อดูหรือเปลี่ยนจำนวนชุด

- **จำนวนชุด** เลือก 1–4 ชุด ระบบบันทึกทันที
- **สุ่มใหม่** สุ่มลำดับข้อและตัวเลือกของชุด ข เป็นต้นไปอีกครั้ง ชุด ก คงลำดับต้นฉบับ ใช้ได้ก่อนพิมพ์เท่านั้น
- แท็บ **ชุด ก**, **ชุด ข** … แสดงว่าแต่ละข้อของชุดนั้นมาจากข้อต้นฉบับข้อใด ตัวเลือกเรียงอย่างไร และเฉลยคือตัวใด

ระบบสลับข้อ **ภายในตอนเดียวกัน** และสลับตัวเลือกของข้อปรนัย ยกเว้นข้อที่เปิด **ห้ามสลับตัวเลือก** นักเรียนฝน **วงชุด** บนกระดาษคำตอบหน้า 1 ให้ตรงกับเล่มที่ได้รับ

## พิมพ์เล่มข้อสอบ กระดาษคำตอบ และกระดาษเฉลย

กด **พิมพ์เล่มและกระดาษคำตอบ** หน้า **พิมพ์ข้อสอบ** มี 3 การ์ด

| การ์ด | ได้ไฟล์อะไร | เงื่อนไข |
|---|---|---|
| **เล่มข้อสอบ** | PDF หนึ่งไฟล์ต่อชุด ไม่มีชื่อนักเรียน ตัวนับ **สำเนา** ช่วยคิดว่าต้องถ่ายเอกสารชุดละกี่เล่ม | ต้องอนุมัติเฉลยก่อน |
| **กระดาษคำตอบ** | แบบ QR รายคน: แผ่นของแต่ละคน เลือก **ทั้งห้อง** หรือ **เลือกบางคน** แบบฝนเลขประจำตัว: **กระดาษคำตอบใบกลาง** หนึ่งแผ่นสำหรับถ่ายเอกสาร | ต้องอนุมัติเฉลยก่อน และห้องต้องมีนักเรียน |
| **กระดาษเฉลยของครู** | กระดาษสำหรับฝนเฉลยแล้วสแกนเข้าตารางเฉลย | ไม่ต้องอนุมัติเฉลยก่อน |

1. กด **สร้าง PDF** ที่การ์ดที่ต้องการ ครั้งแรกระบบจะเตือนว่า **พิมพ์ครั้งแรกจะล็อกโครงสร้าง** กด **พิมพ์**
2. รอจนสถานะเปลี่ยนจาก **อยู่ในคิว** เป็น **กำลังสร้าง PDF** และ **กำลังดาวน์โหลด…**
3. บนเว็บกด **ดาวน์โหลด** ในแอป Android กด **เปิด**, **บันทึกลงเครื่อง** หรือ **แชร์ / ส่งไปพิมพ์**
4. พิมพ์ลงกระดาษ A4 ขนาดจริง ไม่ย่อ ไม่ขยาย

**พิมพ์แล้วโครงสร้างถูกล็อก**
หลังสร้าง PDF ครั้งแรก ครูจะเพิ่ม ลบ หรือย้ายข้อและตอน เปลี่ยนจำนวนตัวเลือก จำนวนชุด หรือการห้ามสลับตัวเลือกไม่ได้ เพราะกระดาษที่พิมพ์ไปแล้วจะไม่ตรงกับข้อสอบ ส่วนข้อความ ภาพ คะแนน และเฉลยยังแก้ได้ ถ้าจำเป็นต้องแก้โครงสร้าง กด **ปลดล็อกเพื่อแก้โครงสร้าง** ซึ่งทำได้เฉพาะเมื่อยังไม่มีกระดาษคำตอบที่สแกนแล้ว และต้องพิมพ์เล่มข้อสอบ กระดาษคำตอบ และกระดาษเฉลยใหม่ทั้งหมด
**ับนักเรียนในวันสอบ**

- ใช้ดินสอ 2B ฝนให้เต็มวง ถ้าเปลี่ยนคำตอบให้ลบให้สะอาด
- ห้ามพับ ขีดเขียน หรือทำเลอะบน **สัญลักษณ์สี่เหลี่ยมที่มุมทั้ง 4** และ **QR**
- ข้อสอบหลายชุด ให้ฝน **วงชุด** ให้ตรงกับเล่มข้อสอบ ฝนเพียงวงเดียว
- แบบฝนเลขประจำตัว () เขียนเลขประจำตัวในช่องสี่เหลี่ยมช่องละ 1 หลัก แล้วฝนวงที่ตรงกับเลขของแต่ละหลักให้ครบทุกหลัก ถ้าเลขสั้นกว่าจำนวนช่อง ให้เขียนชิดขวาและเว้นช่องซ้ายว่าง

ไฟล์ PDF เก็บไว้ 30 วัน ถ้ารอเกิน 5 นาทีแล้วยังไม่เสร็จ ระบบจะแจ้งว่า **สร้าง PDF ใช้เวลานานเกินไป ลองดูสถานะใหม่ภายหลัง**

## สแกนกระดาษคำตอบ

**การสแกนกระดาษคำตอบใช้ได้เฉพาะในแอป Android**
**ิดข้อสอบแล้วกด **สแกนกระดาษคำตอบ** (กดได้หลังอนุมัติเฉลยและพิมพ์กระดาษคำตอบแล้ว) เมื่อเปิดหน้านี้ขณะมีอินเทอร์เน็ต แอปจะโหลดเฉลย รายชื่อ และตำแหน่งวงบนกระดาษมาเก็บในเครื่องให้เอง**

1. วางกระดาษคำตอบบนพื้นเรียบ ถือมือถือให้เห็น **สัญลักษณ์ครบ 4 มุม** แล้วถือให้นิ่ง
2. โหมด **สแกนต่อเนื่อง** (เปิดไว้ตั้งแต่ต้น) แอปถ่ายเองเมื่อเห็นกระดาษทั้งแผ่นและภาพคมชัด ถ้าปิดโหมดนี้ ให้กดปุ่ม **ถ่ายกระดาษคำตอบ** เอง
3. เครื่อง **สั่น 1 ครั้งพร้อมเสียงคลิก** แปลว่าบันทึกแล้ว **สั่นแรง 2 ครั้ง** แปลว่ามีปัญหา ให้ดูข้อความบนจอ
4. การ์ดผลแสดงเลขที่ ชื่อ หน้า ชุด และคะแนนของหน้านั้น เปลี่ยนเป็นกระดาษใบถัดไปได้เลย ไม่มีขั้นตอนยืนยัน
5. แถบสรุปด้านบนบอกว่า **สแกนแล้ว x/y คน** และยังขาดเลขที่ใด แตะเพื่อดูรายชื่อที่ยังขาด

คะแนนบนการ์ดคิดในเครื่องทันที ภาพจะเข้าคิวอัปโหลด (หัวข้อ 6.4) แล้วเซิร์ฟเวอร์คิดคะแนนของแต่ละหน้าอีกครั้งทันทีที่ได้รับหน้านั้น โดยใช้คะแนนของเซิร์ฟเวอร์เป็นผลจริง หน้า 2 ที่ไปถึงก่อนหน้า 1 ของข้อสอบหลายชุดจะถูกคิดเมื่อได้หน้า 1 เพราะต้องรู้ชุดก่อน

### กระดาษแบบฝนเลขประจำตัว

- ถ้าแอปอ่านเลขประจำตัวได้ชัดและตรงกับนักเรียนคนเดียวในห้อง แอปบันทึกให้เอง
- ถ้าไม่ได้ฝน ฝนไม่ครบ ฝนไม่ชัด หรือไม่พบเลขนั้นในห้อง แอปจะเปิดรายชื่อให้ครู **เลือกนักเรียนของกระดาษใบนี้** การ์ดผลจะมีคำว่า **ครูเลือกชื่อ**
- ถ้าไม่ใช่กระดาษของห้องนี้ กด **ไม่ใช่กระดาษของห้องนี้ ทิ้งภาพ**
- ในโหมดสแกนต่อเนื่อง แอปจะรอให้ **ยกกระดาษใบนี้ออก แล้ววางใบถัดไป** ก่อนถ่ายอีกครั้ง

### สิ่งที่แอปให้ครูตัดสิน

| สิ่งที่เห็น | ความหมาย | สิ่งที่ครูทำ |
|---|---|---|
| **ต้องตรวจ N ข้อ** | บางข้อฝนสองวง ฝนจาง หรืออ่านตัวเลขไม่ได้ | กระดาษถูกบันทึกแล้ว ไปตรวจข้อเหล่านั้นภายหลังที่ **ตรวจทานข้อที่สงสัย** (หัวข้อ 9.7) |
| **ให้ครูเลือกชุด** | ไม่ได้ฝนวงชุด หรือฝนหลายวง จึงยังคิดคะแนนไม่ได้ | เลือกชุดภายหลังที่หน้าผลสอบ |
| **วงชุดไม่ชัด** | อ่านชุดได้ แต่มีรอยฝนจางอีกวง | ตรวจว่าชุดถูกต้อง |
| **รอหน้า 1** | สแกนหน้า 2 ก่อน จึงยังไม่รู้ชุด | สแกนหน้า 1 ของนักเรียนคนนั้น |
| **สแกนใบนี้แล้ว** | กระดาษใบเดิมถูกสแกนซ้ำ | กด **สแกนแทนใบเดิม** หรือ **ข้าม** |

### เมื่อแอปไม่รับกระดาษ

| ข้อความ | สิ่งที่ต้องทำ |
|---|---|
| ข้อความเรื่องมุมกระดาษ QR หรือภาพไม่คมชัด | เหมือนการสแกนใบงาน (หัวข้อ 6.3) |
| **นี่คือใบงานของการบ้าน ไม่ใช่กระดาษคำตอบข้อสอบ ...** | สแกนใบงานจากปุ่ม **สแกนใบงาน** ที่หน้าหลัก |
| **กระดาษคำตอบนี้เป็นของข้อสอบอื่น (#N)** | เปิดข้อสอบให้ถูกชุดก่อนสแกน |
| **นี่คือกระดาษเฉลยของครู ...** | สแกนที่หน้าตารางเฉลย |
| **ข้อสอบนี้ใช้กระดาษคำตอบแบบ QR รายคน กระดาษแบบฝนเลขประจำตัวใบนี้ใช้ไม่ได้** (หรือกลับกัน) | ใช้กระดาษให้ตรงกับแบบที่ตั้งไว้ในข้อสอบ |
| **กระดาษคำตอบนี้พิมพ์จาก layout เวอร์ชัน A แต่ข้อมูลสแกนในเครื่องเป็นเวอร์ชัน B ...** | ต่ออินเทอร์เน็ตแล้วกดไอคอน **เตรียมสแกนใหม่** มุมขวาบน หรือพิมพ์กระดาษคำตอบใหม่ |
| **ไม่พบนักเรียนของกระดาษคำตอบนี้ในรายชื่อห้อง** | ต่ออินเทอร์เน็ตแล้วกด **เตรียมสแกนใหม่** เพื่อโหลดรายชื่อล่าสุด |
| **ยังไม่ได้พิมพ์กระดาษคำตอบ พิมพ์กระดาษคำตอบก่อนแล้วจึงสแกน** | สร้าง PDF กระดาษคำตอบก่อน (หัวข้อ 9.5) |

**สแกนในห้องที่ไม่มีอินเทอร์เน็ต**
เปิดหน้า **สแกนกระดาษคำตอบ** ของข้อสอบนั้นหนึ่งครั้งขณะมีอินเทอร์เน็ต จากนั้นสแกนแบบออฟไลน์ได้ แอปจะแจ้งว่าใช้เฉลยและรายชื่อที่เตรียมไว้เมื่อใด และส่งภาพเมื่อกลับมาออนไลน์ ปุ่ม **เตรียมสแกนออฟไลน์** ในหน้าห้องเรียนไม่ครอบคลุมข้อสอบ

## ตรวจทานและประกาศผล

กด **ตรวจทานและประกาศผล** ในหน้าข้อสอบ

- **สแกนครบ x/y คน** และรายชื่อเลขที่ที่ยังขาด
- **พร้อมประกาศ** สแกนครบทุกหน้าและไม่มีข้อที่ต้องตรวจ **รอตรวจทาน** มีข้อที่สงสัย ยังไม่รู้ชุด หรือขาดหน้า **ประกาศแล้ว** นักเรียนเห็นผลแล้ว
- แต่ละแถวของนักเรียนบอกหน้าที่สแกนแล้ว ชุด จำนวนข้อที่ต้องตรวจ และคะแนน

ขั้นตอนก่อนประกาศ

1. กด **ตรวจทานข้อที่สงสัย** ข้อที่แอปไม่แน่ใจอยู่ในแท็บ **ต้องตรวจ** พร้อมเหตุ **ฝนหลายวง**, **รอยฝนไม่ชัด** หรือ **ตัวเลขอ่านไม่ได้**
2. เปิดข้อ ดูภาพหน้ากระดาษคำตอบ แล้วเลือก **คำตอบที่นักเรียนตั้งใจ** และกด **ใช้คำตอบนี้** ระบบคิดคะแนนตามเฉลยให้ หรือใช้ **แก้คะแนนตรง** (ต้องใส่เหตุผล)
3. นักเรียนที่มีป้าย **ให้ครูเลือกชุด** แตะแถวของคนนั้น เปิดหน้าที่ต้องการ เลือกชุด แล้วกด **ใช้ชุดนี้และคิดคะแนน**
4. กด **ประกาศผลทั้งห้อง (N)** แล้วกด **ประกาศผล**

นักเรียนที่ตรวจทานครบจะเห็นคะแนนรวมและคะแนนรายตอน (พร้อมเฉลยรายข้อถ้าเปิด **ให้นักเรียนดูเฉลย**) และคะแนนเข้าไปในสมุดคะแนน คนที่ยังรอตรวจทาน รอเลือกชุด หรือขาดหน้า จะยังไม่ถูกประกาศ กดประกาศอีกครั้งได้เมื่อพร้อม

**ประกาศแล้วถอนไม่ได้**
เหมือนการเผยแพร่ผลการบ้าน และภาพหน้ากระดาษคำตอบจะถูกลบหลังประกาศ ถ้าต้องแก้ผลหลังประกาศ ให้สแกนกระดาษคำตอบของนักเรียนคนนั้นใหม่ แล้วกด **ยืนยันแทนที่** ในคิวอัปโหลด หรือตอบคำขอให้ตรวจใหม่ของนักเรียน (หัวข้อ 8.7) ซึ่งนักเรียนส่งได้เมื่อครูเปิด **ให้นักเรียนดูเฉลย**

## วิเคราะห์ผลสอบ

กด **วิเคราะห์ผล** ในหน้าข้อสอบ (ใช้ผลที่ประกาศแล้วเท่านั้น) หน้านี้แสดงการกระจายคะแนน ข้อที่ทั้งห้องผิดมากที่สุด ค่าความยากง่าย (p) และอำนาจจำแนก (r) เหมือนของการบ้าน ซึ่งอธิบายไว้ในหัวข้อ 11.1 และมีการ์ด **วิเคราะห์ตัวเลือก** เพิ่มสำหรับข้อสอบ

| สิ่งที่แสดง | ความหมาย |
|---|---|
| **N คน · x%** ของแต่ละตัวเลือก | จำนวนนักเรียนที่เลือกตัวเลือกนั้น ตัวที่เป็นเฉลยมีป้าย **เฉลย** |
| **กลุ่มสูง a · กลุ่มต่ำ b** | จำนวนคนที่เลือกตัวเลือกนั้นในกลุ่มคะแนนสูงและกลุ่มคะแนนต่ำ |
| **ไม่ตอบ**, **ฝนหลายตัว** | จำนวนคนที่ไม่ได้ฝน หรือฝนเกินหนึ่งวง |
| ป้าย **ตัวลวงที่ไม่มีใครเลือก** | ตัวลวงนั้นไม่ได้ผล ควรปรับ |
| ป้าย **ตัวลวงที่กลุ่มสูงเลือกมากกว่ากลุ่มต่ำ** | โจทย์หรือเฉลยอาจกำกวม ควรตรวจ |

ป้ายเตือนแสดงเมื่อประกาศผลแล้วตั้งแต่ 20 คนขึ้นไป เปิดตัวกรอง **เฉพาะข้อที่มีป้ายเตือน** เพื่อดูเฉพาะข้อที่ควรทบทวน

## ข้อสอบแบบครูตรวจเอง

เลือก **ครูตรวจเอง** เมื่อข้อสอบเป็นข้อเขียน หรือครูต้องการตรวจบนกระดาษตามเดิม แล้วใช้ Krucheck เก็บคะแนน

- กำหนด **คะแนนเต็ม** ในฟอร์มข้อสอบ ไม่ต้องอนุมัติเฉลย ไม่มีกระดาษคำตอบ การสแกน หน้าผลสอบ และการวิเคราะห์ผล
- ถ้าพิมพ์โจทย์ไว้ในระบบ กด **พิมพ์เล่มข้อสอบ** ได้ ส่วน **ตารางเฉลย** ไม่บังคับ
- กด **กรอกคะแนน** ระบบเปิดสมุดคะแนนที่คอลัมน์ของข้อสอบนี้ แตะช่องของนักเรียนแล้วพิมพ์คะแนน หรือแตะหัวคอลัมน์แล้วเลือก **วางคะแนนจาก Excel** (หัวข้อ 10.4)
