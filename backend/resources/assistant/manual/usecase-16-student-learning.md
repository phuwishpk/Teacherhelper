# เรียนและส่งงาน

บทนี้คือสิ่งที่นักเรียนทำเป็นประจำหลังเข้าสู่ระบบ ได้แก่ ดูวิชาของทุกห้องที่เรียน อ่านโพสต์ของครู ดูตารางเรียนและการเข้าเรียนของตัวเอง และส่งงาน ทุก use case ในบทนี้ต้องเข้าสู่ระบบเป็นนักเรียนแล้ว นักเรียนเห็นเฉพาะห้องที่ตนเป็นสมาชิก และห้องที่ครูปิดแล้ว (ห้องเก่า) ดูได้อย่างเดียว ส่งงานเพิ่มไม่ได้

## ดูวิชาของฉันและหน้าของวิชา

```uc
ผู้ใช้หลัก: นักเรียน
เป้าหมาย: เห็นทุกวิชาของทุกห้องที่เรียนอยู่ พร้อมงานที่ต้องส่ง ผลที่ออกแล้ว และเกรด ในหน้าเดียว แล้วเปิดดูแต่ละวิชา
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นนักเรียนแล้ว และอยู่ในห้องเรียนอย่างน้อย 1 ห้อง (UC-T11, UC-S04)
ผลลัพธ์: นักเรียนเห็นรายวิชาและสถานะงานของตัวเอง และเปิดหน้าของวิชาที่เลือกได้ (อ่านอย่างเดียว)
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. หลังเข้าสู่ระบบ ระบบเปิด **วิชาของฉัน** ซึ่งเป็นปุ่มแรกของเมนูหลัก (บนมือถือเมนูอยู่ด้านล่าง บนแท็บเล็ตและคอมพิวเตอร์อยู่ด้านซ้าย)
2. ดูบรรทัดบนสุด **ต้องส่งอีก N งาน** หรือ **ไม่มีงานค้าง** และปุ่ม **เข้าห้องด้วยรหัส**, **ตารางเรียน**, **การเข้าเรียน**, **เกรดทั้งหมด**
3. ดูการ์ดของแต่ละวิชา: รหัสและชื่อวิชา ห้อง ชื่อครู ป้าย **ต้องส่ง N งาน** และ **ผล N รายการ** และกล่องเกรดเมื่อครูประกาศเกรดแล้ว
4. แตะการ์ดเพื่อเปิดหน้าของวิชา แล้วเลือกแท็บตามตารางด้านล่าง
5. ถ้าเรียนหลายวิชา กดไอคอน **เปลี่ยนวิชา** ที่มุมขวาบนเพื่อสลับวิชาโดยไม่ต้องกลับหน้าหลัก

| แท็บ | มีอะไร |
|---|---|
| **โพสต์** | ประกาศ เอกสารประกอบ การบ้าน และผลของวิชานี้ (UC-S07) |
| **งาน** | การบ้านของวิชานี้ แตะเพื่อส่งงานหรือดูผล (UC-S10) |
| **ผล** | ผลที่ครูเผยแพร่แล้ว (UC-S11) |
| **เกรด** | เกรดและคะแนนรายหมวดเมื่อครูประกาศแล้ว (UC-S15) |
| **กราฟ** | ความเข้าใจของตัวเองในวิชานี้ (UC-S16) |

**กรณีอื่น**

- **1ก** ระบบแสดง **ยังไม่ได้อยู่ในห้องเรียน**: กด **เข้าห้องด้วยรหัส** (UC-S04) หรือแจ้งครู ถ้าขึ้น **ยังไม่มีรายวิชา** ครูยังไม่ได้สั่งงาน
- **3ก** ห้องที่ครูปิดแล้วรวมอยู่ใน **ห้องเก่า (N รายวิชา)** ด้านล่าง ยังดูผลและเกรดเดิมได้แต่ส่งงานไม่ได้ ถ้ามีแต่ห้องเก่า ระบบแสดง **ไม่มีรายวิชาในห้องที่เปิดอยู่**
- **4ก** งานที่ครูสั่งโดยไม่ระบุรายวิชาอยู่ในการ์ด **อื่นๆ** ซึ่งไม่มีแท็บ **เกรด** และ **กราฟ**

## อ่านโพสต์ของครู

```uc
ผู้ใช้หลัก: นักเรียน
เป้าหมาย: อ่านประกาศและเอกสารประกอบที่ครูโพสต์ แล้วเปิดไฟล์หรือลิงก์ที่แนบมา
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นนักเรียนแล้ว และครูเผยแพร่โพสต์ในห้องที่นักเรียนอยู่ (UC-T80)
ผลลัพธ์: นักเรียนอ่านโพสต์ เปิดไฟล์หรือลิงก์ และไปหน้าการบ้านหรือผลจากสตรีมได้ (อ่านอย่างเดียว)
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ที่หน้า **วิชาของฉัน** แตะการ์ดของวิชา ระบบเปิดแท็บ **โพสต์** หรือแตะโพสต์ในการ์ด **โพสต์ล่าสุด** บนหน้าหลักเพื่อเปิดโพสต์นั้นทันที
2. เลือก **สตรีม** (ทุกอย่างของวิชาเรียงจากใหม่ไปเก่า) หรือ **งานของชั้นเรียน** (เอกสารประกอบและการบ้านจัดตามหัวข้อ)
3. อ่านโพสต์: ชื่อโพสต์ ชื่อครู วันเวลา หัวข้อ และข้อความ ซึ่งเลือกคัดลอกได้
4. แตะไฟล์หรือลิงก์ที่แนบเพื่อเปิด
5. แตะแถว **การบ้าน: (ชื่องาน)** เพื่อไปหน้าส่งงาน (UC-S10) หรือ **ผลตรวจ: (ชื่องาน)** เพื่อไปหน้าผล (UC-S11)

**กรณีอื่น**

- **1ก** ระบบแสดง **ยังไม่มีโพสต์**: ครูยังไม่ได้โพสต์หรือสั่งงานในวิชานี้
- **3ก** โพสต์ที่มีป้าย **ถึงคุณโดยเฉพาะ** ครูส่งถึงนักเรียนบางคนเท่านั้น นักเรียนคนอื่นไม่เห็นโพสต์นี้
- **4ก** เปิดไม่ได้ ระบบแสดง **เปิดลิงก์ไม่ได้** หรือ **เปิดไฟล์ไม่ได้** ให้ลองใหม่หรือแจ้งครู

**การเปิดไฟล์และลิงก์**
แอป Android เปิดไฟล์ด้วยแอปดูไฟล์ในเครื่อง ส่วนบนเว็บจะดาวน์โหลดไฟล์ ลิงก์เปิดในเบราว์เซอร์ โพสต์ที่ครูไม่ได้ระบุรายวิชาขึ้นในทุกวิชาของห้องนั้น

## ดูตารางเรียน

```uc
ผู้ใช้หลัก: นักเรียน
เป้าหมาย: ดูคาบเรียนของทุกห้องที่เรียนอยู่ในแต่ละสัปดาห์ รวมถึงคาบที่ครูยกเลิก
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นนักเรียนแล้ว และครูใส่คาบในตารางสอนแล้ว (UC-T84)
ผลลัพธ์: นักเรียนเห็นตารางเรียนของสัปดาห์ที่เลือก (อ่านอย่างเดียว)
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ที่หน้า **วิชาของฉัน** กด **ตารางเรียน**
2. ระบบเปิดหน้า **ตารางเรียน** ของสัปดาห์นี้ ด้านบนบอกช่วงวันที่ของสัปดาห์
3. กดลูกศรซ้ายหรือขวาเพื่อดูสัปดาห์ก่อนหรือสัปดาห์ถัดไป
4. อ่านแต่ละคาบ: เลขคาบ รหัสและชื่อวิชา เวลา ห้อง และชื่อครู บนมือถือแสดงเป็นการ์ดรายวัน บนแท็บเล็ตและคอมพิวเตอร์แสดงเป็นตาราง

**กรณีอื่น**

- **2ก** ระบบแสดง **ยังไม่มีตารางเรียน**: ครูยังไม่ได้ใส่คาบในตารางสอน
- **4ก** คาบที่ครูยกเลิกในสัปดาห์นั้นมีขีดฆ่าพร้อมคำว่า **ยกเลิก** และหมายเหตุของครูถ้ามี
- **4ข** วันที่ไม่มีคาบแสดง **ไม่มีคาบ**

**ตารางรวมคาบของทุกห้องที่ยังเปิดอยู่ จากตารางสอนของครูทุกคนที่สอนนักเรียน ห้องที่ครูปิดแล้วไม่แสดงในตาราง**

## ดูการเข้าเรียนของตัวเอง

```uc
ผู้ใช้หลัก: นักเรียน
เป้าหมาย: ดูว่าตัวเองมาเรียน สาย ขาด หรือลา ในแต่ละคาบที่ครูเช็คชื่อ และอัตราการเข้าเรียนของแต่ละวิชา
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นนักเรียนแล้ว และครูเช็คชื่อแล้ว (UC-T85)
ผลลัพธ์: นักเรียนเห็นสรุปและประวัติการเข้าเรียนของตัวเองเท่านั้น (อ่านอย่างเดียว)
ใช้ได้บน: เว็บ, Android
```

**ขั้นตอนการใช้งาน**

1. ที่หน้า **วิชาของฉัน** กด **การเข้าเรียน**
2. ระบบเปิดหน้า **การเข้าเรียนของฉัน** หนึ่งการ์ดต่อวิชา บอกห้อง จำนวนคาบของแต่ละสถานะ และอัตราการเข้าเรียนเป็นเปอร์เซ็นต์ (ต่ำกว่า 80% เป็นสีแดง)
3. แตะการ์ดเพื่อดูทุกคาบที่ครูเช็ค เรียงจากใหม่ไปเก่า แต่ละคาบบอกวันที่ เลขคาบ สถานะ และหมายเหตุของครู
4. อ่านสถานะของแต่ละคาบ: **มาตรงเวลา**, **มาสาย**, **ขาด**, **ลากิจ** หรือ **ลาป่วย**

**กรณีอื่น**

- **2ก** ระบบแสดง **ยังไม่มีการเช็คชื่อ**: ครูยังไม่ได้เช็คชื่อในวิชาใดเลย
- **4ก** สถานะไม่ถูกต้อง เช่น ถูกบันทึกว่าขาดทั้งที่มา: แจ้งครูผู้สอนคาบนั้นให้แก้ (UC-T85) นักเรียนแก้เองไม่ได้

## ส่งงาน

```uc
ผู้ใช้หลัก: นักเรียน
เป้าหมาย: ส่งการบ้านเป็นรูปถ่ายหรือไฟล์ PDF ให้ครูและ AI ตรวจ
เงื่อนไขก่อนเริ่ม: เข้าสู่ระบบเป็นนักเรียนแล้ว และครูเปิดรับการบ้านนั้น (การบ้านขึ้นในแท็บ **ส่งงาน**)
ผลลัพธ์: งานถูกบันทึกพร้อมเวลาส่ง (ติดป้าย **ส่งช้า** ถ้าเลยกำหนด) และถูกส่งให้ AI ตรวจ
ใช้ได้บน: เว็บ, Android
เรียกใช้: X01
```

**ขั้นตอนการใช้งาน**

1. แตะ **ส่งงาน** ที่เมนูหลัก ระบบแสดงการบ้านที่ครูเปิดรับ จัดตามวิชา แต่ละแถวบอก **กำหนดส่ง** และสถานะ
2. แตะการบ้านที่จะส่ง หน้า **ส่งงาน** แสดงกำหนดส่ง คำชี้แจง และไฟล์แนบของครู
3. ในแอป Android กด **ถ่ายรูป** แล้วถ่ายงานทีละหน้า หรือกด **เลือกรูปหรือ PDF** เพื่อเลือกไฟล์ในเครื่อง (บนเว็บมีเฉพาะปุ่มนี้)
4. ตรวจรายการไฟล์ซึ่งมีป้าย **หน้า 1**, **หน้า 2** … ไฟล์ที่เลือกผิดกด ✕ เพื่อเอาออก
5. กด **ส่งงาน** แล้วรอจนขึ้น **ส่งงานแล้ว** พร้อมเวลาและจำนวนหน้า อย่าปิดหน้าจอระหว่างอัปโหลด
6. กด **เสร็จ** ระบบส่งงานให้ AI ตรวจ (UC-X01) คะแนนขึ้นในแท็บ **ผลการบ้าน** หลังครูเผยแพร่ผล (UC-T43)

**กรณีอื่น**

- **1ก** ระบบแสดง **ยังไม่มีงานที่ต้องส่ง**: ครูยังไม่เปิดรับการบ้าน ข้อสอบไม่มีการส่งในแอป ครูสแกนกระดาษคำตอบเอง (UC-T55) ส่วนใบงานที่ครูเก็บไปสแกนเอง (UC-T33) ให้ทำตามที่ครูบอก
- **2ก** ส่งไปแล้วแต่ส่งผิดหรือรูปไม่ชัด: เลือกไฟล์ใหม่ กด **ส่งงานใหม่** แล้วยืนยัน **ส่งใหม่** ครูจะตรวจงานที่ส่งล่าสุดแทนงานเดิม การบ้านที่ **ประกาศผลแล้ว** แตะแล้วเปิดหน้าผลแทน (UC-S11)
- **2ข** เลยกำหนดส่ง: ถ้าครูยังรับงาน ส่งได้แต่งานติดป้าย **ส่งช้า** ถ้าครูไม่รับ หน้าแสดง **ปิดรับงานแล้ว** และไม่มีปุ่มส่ง
- **4ก** ไฟล์ไม่ผ่าน ระบบแสดงเช่น **ส่งได้ไม่เกิน 5 ไฟล์ต่อครั้ง** หรือ **(ชื่อไฟล์): ไฟล์ใหญ่เกิน 10 MB** ส่งได้เฉพาะรูป JPG, PNG, WebP, HEIC หรือ PDF รวมไม่เกิน 5 หน้า ไฟล์ Word ให้บันทึกเป็น PDF ก่อน
