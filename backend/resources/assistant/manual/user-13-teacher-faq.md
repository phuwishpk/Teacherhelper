# ปัญหาที่พบบ่อยของครู

บทนี้รวมปัญหาที่ครูพบบ่อย พร้อมทางแก้และหัวข้อที่อธิบายละเอียด ถ้าแก้ตามนี้แล้วไม่หาย ให้แจ้งผู้ดูแลระบบ พร้อมบอกข้อความที่ขึ้นบนจอและเวลาที่เกิด

## บัญชีและการเข้าสู่ระบบ

| ปัญหา | ทางแก้ |
|---|---|
| สมัครแล้วเข้าไม่ได้ ขึ้นว่ารอการอนุมัติ | บัญชีครูต้องให้ผู้ดูแลระบบอนุมัติก่อน แจ้งผู้ดูแลระบบ (หัวข้อ 2.2) |
| ต้องการเปลี่ยนรหัสผ่าน | ที่หน้าตั้งค่า แตะ **เปลี่ยนรหัสผ่าน** แล้วกรอกรหัสผ่านปัจจุบันกับรหัสผ่านใหม่ บัญชีที่สมัครด้วย Google และยังไม่เคยตั้งรหัสผ่านเว้นรหัสผ่านปัจจุบันว่างได้ (หัวข้อ 2.5) |
| ลืมรหัสผ่าน | แจ้งผู้ดูแลระบบให้ตั้งรหัสผ่านใหม่ ถ้าเชื่อมบัญชี Google ไว้ ยังเข้าด้วยปุ่ม Google ได้ระหว่างรอ (หัวข้อ 2.3) |
| ไม่มีปุ่ม Google | ผู้ดูแลระบบยังไม่เปิดใช้การเข้าสู่ระบบด้วย Google |
| เข้าบนเว็บแล้วต้องเข้าใหม่บ่อย | ระบบจำการเข้าสู่ระบบ 30 วัน ถ้าเบราว์เซอร์ตั้งให้ล้างข้อมูลเมื่อปิด จะต้องเข้าใหม่ทุกครั้ง |
| นักเรียนลืมรหัสผ่านหรือชื่อผู้ใช้ | ชื่อผู้ใช้ดูได้ในรายชื่อของห้อง รหัสผ่านให้กด **รีเซ็ตรหัสผ่าน** จากเมนูของนักเรียนในหน้าห้องเรียน รหัสผ่านจะกลับเป็นรหัสเริ่มต้น `123456` แล้วนักเรียนตั้งรหัสผ่านใหม่ตอนเข้า (หัวข้อ 3.4) |

## AI และ Gemini API key

| ปัญหา | ทางแก้ |
|---|---|
| ข้อเขียนไม่มีคะแนน มีป้าย **ตรวจเอง · ไม่มี key** | ใส่ key ที่หน้าตั้งค่า แล้วกด **ตรวจข้อที่ค้างใหม่** ในคิวตรวจทาน (หัวข้อ 8.6) |
| **Gemini ไม่ยอมรับ key นี้ ...** | key ผิด ถูกลบ หรือบัญชี Google นั้นยังไม่เปิดใช้บริการ สร้าง key ใหม่แล้วใส่อีกครั้ง (หัวข้อ 2.5) |
| สแกนแล้วนานกว่า 15 นาทียังไม่มีผล | เปิดคิวอัปโหลดดูว่าภาพส่งแล้วหรือยัง แล้วกด **ดึงรายการใหม่** ในคิวตรวจทาน ถ้ายังขึ้น **AI กำลังตรวจ** นานผิดปกติ ให้แจ้งผู้ดูแลระบบ |
| หลายข้อขึ้น **ตรวจเอง: AI ตรวจไม่สำเร็จ** | บริการของ Google อาจขัดข้องชั่วคราวหรือโควตาของ key หมด ให้คะแนนเอง หรือสแกนใหม่ภายหลัง |
| AI อ่านลายมือผิดบ่อย | ให้นักเรียนเขียนในกรอบ ตัวโตและเข้ม ถ่ายในที่สว่าง และแก้คะแนนพร้อมเลือกเหตุผล **AI อ่านลายมือผิด** |
| ไม่แน่ใจว่าค่าใช้จ่ายของ AI เท่าใด | หน้าส่งเอกสารให้ AI อ่านแสดง **ค่าใช้จ่ายโดยประมาณ** ก่อนส่งทุกครั้ง ค่าใช้จ่ายจริงดูได้ในหน้าบัญชีของ Google ที่ออก key |
| ใส่ key ไว้นานแล้ว ไม่แน่ใจว่ายังใช้ได้ | ที่การ์ด **Gemini API key** ในหน้าตั้งค่า กด **ทดสอบอีกครั้ง** ถ้าผ่านจะขึ้น **key ใช้งานได้ ทดสอบผ่านแล้ว** และเวลาที่ทดสอบล่าสุด ถ้าไม่ผ่าน ระบบบอกสาเหตุพร้อมรหัสข้อผิดพลาด |

### รหัสข้อผิดพลาดของ AI

เมื่อฟังก์ชันที่ใช้ AI ทำงานไม่สำเร็จ เช่น ทดสอบ key เขียนคำอธิบายใหม่ หรือผู้ช่วย Krucheck ระบบแสดงสาเหตุพร้อมบรรทัด **รหัส** เช่น **รหัส AI-QUOTA · #48213** ตัวเลขหลัง # คือเลขของการเรียก AI ครั้งนั้น ผู้ดูแลระบบใช้ค้นรายละเอียดได้ กดปุ่มคัดลอกหรือ **คัดลอกรหัส** แล้วส่งให้ผู้ดูแลระบบ ถ้าปัญหาอยู่ที่ key แถบด้านล่างจะมีปุ่ม **ไปใส่ key**

| รหัส | ความหมาย | ทางแก้ |
|---|---|---|
| `AI-KEY-MISSING` | ยังไม่มี Gemini API key | ใส่ key ที่หน้าตั้งค่า (หัวข้อ 2.5) |
| `AI-KEY-INVALID` | Gemini ไม่ยอมรับ key (key ผิด ถูกลบ หรือหมดอายุ) | สร้าง key ใหม่แล้วใส่อีกครั้ง |
| `AI-QUOTA` | โควตาหรือเครดิตของ key หมด หรือเรียกถี่เกินไป | รอสักครู่แล้วลองใหม่ หรือตรวจ billing ใน Google AI Studio |
| `AI-MODEL` | ไม่พบโมเดล AI ที่ระบบตั้งไว้สำหรับ key นี้ | แจ้งผู้ดูแลระบบพร้อมรหัส |
| `AI-TIMEOUT` | AI ตอบไม่ทันเวลาหรือติดต่อ Google ไม่ได้ | ลองใหม่อีกครั้ง |
| `AI-SERVER` | ระบบของ Google ขัดข้องชั่วคราว | ลองใหม่ในอีกสักครู่ |
| `AI-BLOCKED` | ตัวกรองความปลอดภัยของ Google ไม่ยอมตอบ | ปรับข้อความหรือไฟล์ |
| `AI-OUTPUT` | AI ตอบกลับมาในรูปแบบที่ระบบอ่านไม่ได้ | ลองใหม่อีกครั้ง |
| `AI-ERROR` | ข้อผิดพลาดอื่น | ลองใหม่ ถ้ายังเป็นอยู่แจ้งผู้ดูแลระบบพร้อมรหัส |
| `NET-OFFLINE` และ `NET-TIMEOUT` | เครื่องติดต่อเซิร์ฟเวอร์ไม่ได้ หรือเซิร์ฟเวอร์ตอบช้าเกินไป | ตรวจอินเทอร์เน็ตแล้วลองใหม่ |
| `CHAT-LIMIT` | ถามผู้ช่วย Krucheck ครบ 100 ข้อความของวันนี้แล้ว | ถามต่อได้พรุ่งนี้ (บทที่ 14) |

## พิมพ์ใบงานและกระดาษคำตอบ

| ปัญหา | ทางแก้ |
|---|---|
| กด **สร้าง layout** ไม่ได้ | ยังไม่มีคำถาม หรือยังมีข้อแสดงวิธีทำหรืออัตนัยที่ยังไม่อนุมัติ rubric (หัวข้อ 5.4) |
| สร้าง PDF นานเกิน 5 นาที | ลองกดอีกครั้งภายหลัง ถ้ายังไม่ได้ให้แจ้งผู้ดูแลระบบว่าคิวงานของเซิร์ฟเวอร์อาจไม่ทำงาน |
| พิมพ์แล้วสแกนไม่ผ่านบ่อย | ตรวจว่าพิมพ์ **ขนาดจริง 100%** ไม่ได้ย่อให้พอดีหน้า หมึกไม่จาง และสัญลักษณ์ที่มุมทั้ง 4 กับ QR พิมพ์ครบ |
| แก้คำถามหลังพิมพ์ใบงานไปแล้ว | สร้าง layout ใหม่แล้วพิมพ์ใหม่ทั้งห้อง ใบงานชุดเก่าที่แจกไปแล้วยังสแกนได้ตาม layout เดิม (หัวข้อ 5.7) |
| ต้องการเพิ่มหรือลบข้อของข้อสอบที่พิมพ์แล้ว | กด **ปลดล็อกเพื่อแก้โครงสร้าง** ซึ่งทำได้เมื่อยังไม่มีกระดาษคำตอบที่สแกน แล้วพิมพ์ใหม่ทั้งหมด (หัวข้อ 9.5) |
| นักเรียนเข้าห้องมาใหม่หลังพิมพ์ | เพิ่มนักเรียนในห้อง แล้วกด **พิมพ์ใบงาน** อีกครั้งและสั่งพิมพ์เฉพาะหน้าของคนนั้น ส่วนกระดาษคำตอบแบบ QR รายคนใช้ **เลือกบางคน** |

## สแกน

| ปัญหา | ทางแก้ |
|---|---|
| หน้าสแกนไม่มีในเว็บ | การสแกนด้วยกล้องมีเฉพาะแอป Android บนเว็บใช้ **อัปโหลดรูปเพื่อตรวจ** แทน (หัวข้อ 7.3) |
| แอปบอกว่าไม่พบสัญลักษณ์ที่มุม | ถอยกล้องให้เห็นทั้งแผ่น วางบนพื้นสีเข้ม อย่าให้นิ้วบังมุม (หัวข้อ 6.3) |
| อ่าน QR ไม่ได้ | เลี่ยงเงาและแสงสะท้อน ถ้า QR เลอะหรือขาด ให้พิมพ์แผ่นนั้นใหม่ |
| สลับลำดับแผ่น หรือนักเรียนเขียนในใบงานของเพื่อน | ระบบรู้ตัวนักเรียนจาก QR ไม่ใช่จากลำดับที่สแกน จึงสแกนสลับลำดับได้ แต่ถ้านักเรียนเขียนในใบงานของเพื่อน งานจะเป็นของเจ้าของใบงาน ให้ถ่ายรูปแผ่นนั้นแล้วใช้ **อัปโหลดรูปเพื่อตรวจ** โดยเลือกชื่อนักเรียนที่ถูกต้อง (หัวข้อ 7.3) |
| ภาพค้างในคิวอัปโหลด | ตรวจอินเทอร์เน็ต แล้วกด **อัปโหลดตอนนี้** หรือ **ลองใหม่** ที่รายการ (หัวข้อ 6.4) |
| คิวขึ้น **ถูกปฏิเสธ** | อ่านเหตุผลในรายการ เช่น เป็นการบ้านของครูท่านอื่น ถ้าเป็นภาพเสีย ให้ลบแล้วสแกนใหม่ |
| สแกนแล้วแต่ผลเดิมเผยแพร่ไปแล้ว | รายการจะขึ้น **รอครูยืนยัน** กด **ยืนยันแทนที่** ถ้าต้องการใช้ภาพใหม่ (หัวข้อ 8.8) |
| เปลี่ยนมือถือหรือออกจากระบบ | ส่งคิวอัปโหลดให้หมดก่อน เพราะภาพที่ยังไม่ส่งอยู่ในเครื่องเท่านั้น |

## ตรวจทาน เผยแพร่ และคะแนน

| ปัญหา | ทางแก้ |
|---|---|
| ปุ่มเผยแพร่กดไม่ได้ | ยังมีข้อที่ไม่ได้ตรวจทาน หรือยังสแกนไม่ครบทุกหน้าของนักเรียนคนนั้น (หัวข้อ 8.5) |
| เผยแพร่แล้วพบว่าคะแนนผิด | ดูทางแก้ 4 ทางในหัวข้อ 8.8 |
| เฉลยผิดหลังตรวจไปทั้งห้อง | แก้เฉลยแล้วกด **ตรวจใหม่ทั้งห้อง** (หัวข้อ 7.2) |
| นักเรียนบอกว่าไม่เห็นผล | ตรวจว่าเผยแพร่ผลของคนนั้นแล้ว (แท็บ **รายคน**) และนักเรียนเข้าสู่ระบบถูกบัญชี |
| คะแนนไม่เข้าสมุดคะแนน | ผลต้องเผยแพร่ก่อน และงานต้องอยู่ในหมวดคะแนน งานที่ **ยังไม่ระบุหมวด** หรือ **ไม่นับเกรด** จะไม่ถูกนำมาคิด (หัวข้อ 10.3) |
| ประกาศเกรดไม่ได้ | ยังมีหมวดที่ไม่มีรายการที่นับคะแนนได้ เพิ่มรายการหรือย้ายงานเข้าหมวดนั้น (หัวข้อ 10.6) |
| กราฟและตารางทักษะว่าง | ข้อของงานยังไม่ได้ผูกตัวชี้วัด หรือยังไม่มีผลที่เผยแพร่ (หัวข้อ 5.6) |

## ห้องเรียนและนักเรียน

| ปัญหา | ทางแก้ |
|---|---|
| เพิ่มนักเรียนแล้วขึ้นการ์ดสีแดงว่าเลขประจำตัวมีอยู่แล้ว | นักเรียนคนนั้นมีบัญชีอยู่แล้ว กด **เพิ่ม (ชื่อ) เข้าห้องแทน** หรือใช้แท็บ **เลือกนักเรียนที่มีอยู่** แทนการสร้างใหม่ (หัวข้อ 3.2) |
| นักเรียนคนเดียวมีสองบัญชี | ใช้ **รวมบัญชีนักเรียน** (หัวข้อ 3.4) รวมแล้วย้อนกลับไม่ได้ |
| ต้องการสอนห้องของครูท่านอื่น | ให้<span class="nw">ครูประจำชั้น</span>กด **เชิญครู** ในส่วนครูร่วมสอนของห้อง แล้วตอบรับคำเชิญในแท็บห้องเรียน (หัวข้อ 3.6) |
| นักเรียนเข้าห้องด้วยรหัสไม่ได้ ขึ้นว่าปิดรับสมาชิก | เปิดสวิตช์ **รับสมาชิกด้วยรหัสห้อง** ที่หน้าห้องเรียน (หัวข้อ 3.3) ส่วนห้องเก่าเข้าด้วยรหัสห้องไม่ได้จนกว่าจะเปิดห้องอีกครั้ง (หัวข้อ 3.5) |
| เอานักเรียนออกจากห้องไม่ได้ | นักเรียนมีงานหรือคะแนนในห้องนั้นแล้ว ระบบจึงไม่ให้เอาออก เพื่อไม่ให้ผลการเรียนหาย |
| จบปีการศึกษาแล้วทำอย่างไร | **ปิดห้อง** เพื่อย้ายไปห้องเก่า แล้วสร้างห้องของปีใหม่ และใช้ **นำนักเรียนจากห้องเดิม** (หัวข้อ 3.5 และ 3.2) |

## ข้อความทั่วไปของระบบ

| ข้อความ | ความหมาย |
|---|---|
| **เชื่อมต่อเซิร์ฟเวอร์ไม่ได้ (…)** | เครื่องไม่มีอินเทอร์เน็ต หรือเซิร์ฟเวอร์ไม่ตอบ ตรวจเครือข่ายแล้วกด **ลองใหม่** |
| **เกิดข้อผิดพลาดที่ไม่คาดคิด** | ระบบทำงานผิดพลาด ลองอีกครั้ง ถ้าเกิดซ้ำให้จดว่ากดอะไรก่อนหน้า แล้วแจ้งผู้ดูแลระบบ |
| ข้อความว่าทำรายการถี่เกินไป | รอประมาณ 1 นาทีแล้วลองใหม่ |
| ข้อความว่าต้องเข้าสู่ระบบใหม่ | การเข้าสู่ระบบหมดอายุ เข้าสู่ระบบอีกครั้ง |
