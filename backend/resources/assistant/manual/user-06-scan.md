# สแกนใบงานด้วยมือถือ

**ทั้งบทนี้ใช้ได้เฉพาะในแอป Android เพราะต้องใช้กล้องและที่เก็บข้อมูลในเครื่อง บนเว็บ หน้าสแกนจะแจ้งว่า **สแกนใบงานได้เฉพาะในแอป Android** และมีปุ่มไป **อัปโหลดรูปเพื่อตรวจ** แทน (บทที่ 7)**
**ื่อนักเรียนทำใบงานของแอปเสร็จ ครูใช้กล้องมือถือถ่ายทีละแผ่น ไม่ต้องเลือกการบ้านหรือนักเรียนก่อน เพราะ QR บนใบงานบอกทั้งหมด ระบบตัดภาพคำตอบของแต่ละข้อในเครื่อง แล้วส่งขึ้นเซิร์ฟเวอร์ให้ AI ตรวจ**

## เตรียมก่อนสแกน

- วางใบงานบนพื้นเรียบสีเข้ม แสงสว่างพอ ไม่มีเงามือหรือแสงสะท้อนทับ QR
- ถือมือถือให้เห็น **ใบงานทั้งแผ่นและสัญลักษณ์สี่เหลี่ยมครบทั้ง 4 มุม**
- ใบงานยับหรือพับมุมให้คลี่ให้เรียบก่อน
- ครั้งแรกที่เปิดกล้อง Android จะถามสิทธิ์ใช้กล้อง ให้อนุญาต

## สแกนทีละแผ่น

1. ที่หน้าหลัก กดปุ่ม **สแกนใบงาน**
2. เล็งกล้องให้เห็นใบงานทั้งแผ่น แล้วกดปุ่มถ่ายรูปวงกลม ระบบขึ้นว่า **กำลังถ่ายภาพ…** แล้ว **กำลังตรวจใบงาน…**
3. ที่หน้ายืนยัน ตรวจ **เลขที่และชื่อนักเรียน** กับภาพย่อของแต่ละกรอบคำตอบ ใต้ภาพบอกว่า **มีคำตอบ**, **ว่าง**, **ฝน X** หรือ **ไม่ได้ฝน**
4. ถ้าภาพครบและอ่านออก กด **ยืนยัน แล้วสแกนต่อ** ระบบขึ้นว่า **บันทึก (ชื่อ) (เลขที่ N) หน้า P แล้ว สแกนแผ่นต่อไปได้เลย** ถ้าภาพไม่ดี กด **ถ่ายใหม่**
5. ทำซ้ำจนครบทุกแผ่น หัวหน้าจอบอกจำนวนหน้าที่บันทึกแล้ว

แถบด้านบนของหน้าสแกนมีปุ่ม **เปิดไฟฉาย** สำหรับที่มืด **เลือกไฟล์** สำหรับใช้รูปที่ถ่ายไว้แล้ว และ **คิวอัปโหลด**

**ระบบถ่ายเมื่อครูกดปุ่มเท่านั้น หนึ่งภาพต่อหนึ่งหน้า ใบงานที่มีหลายหน้าให้สแกนทีละหน้า หลังกดยืนยัน ภาพจะถูกส่งขึ้นเซิร์ฟเวอร์เองทันทีเมื่อมีอินเทอร์เน็ต ครูสแกนแผ่นต่อไปได้โดยไม่ต้องรอ**

## เมื่อระบบให้ถ่ายใหม่

ถ้าภาพใช้ไม่ได้ ระบบแสดงเหตุผลใต้หัวข้อ **ถ่ายใหม่อีกครั้ง** พร้อมปุ่ม **ถ่ายใหม่**

| ข้อความ | สิ่งที่ต้องทำ |
|---|---|
| **ไม่พบสัญลักษณ์สี่เหลี่ยมที่มุมกระดาษเลย ...** หรือ **มองไม่เห็นสัญลักษณ์ที่มุม... ถอยกล้องออกหรือจัดกระดาษให้เห็นครบทั้ง 4 มุม** | ถอยกล้องให้เห็นทั้งแผ่น อย่าให้นิ้วหรือของอื่นบังมุม |
| **อ่าน QR ที่หัวกระดาษไม่ได้ ระวังเงาหรือแสงสะท้อนบน QR แล้วถ่ายใหม่** | ขยับไม่ให้มีเงาหรือแสงสะท้อนบน QR |
| **ภาพไม่คมชัด ถือโทรศัพท์ให้นิ่งและรอให้กล้องโฟกัสก่อนถ่าย** | ถ่ายใหม่ ถ้าเป็นปัญหาเดียวและครูดูแล้วอ่านออก กด **ใช้ภาพนี้ต่อ** ได้ |
| **QR นี้ไม่ใช่ใบงานของ Krucheck** | กระดาษนี้ไม่ใช่ใบงานการบ้าน (กระดาษคำตอบข้อสอบต้องสแกนจากหน้าข้อสอบ บทที่ 9) |
| **นี่คือบัตรเข้าสู่ระบบของนักเรียน ไม่ใช่ใบงาน** | หยิบผิดแผ่น แผ่นนี้เป็นบัตรเข้าสู่ระบบแบบ QR รุ่นเก่า ซึ่งระบบเลิกออกให้แล้ว |
| **ไม่พบการบ้าน #N ในบัญชีนี้ (อาจเป็นใบงานของครูคนอื่น)** | ใบงานของครูท่านอื่น ต้องสแกนด้วยบัญชีของครูเจ้าของการบ้าน |
| **ไม่พบหน้า P ใน layout เวอร์ชัน V ของการบ้านนี้ ...** | ใบงานพิมพ์จาก layout ที่ไม่มีแล้ว ต้องพิมพ์ใบงานใหม่ |
| **ตัดภาพได้ไม่ครบทุกข้อ ลองถ่ายใหม่** | ถ่ายใหม่ให้กระดาษเรียบและตรงขึ้น |

ข้อความที่เป็นเพียงคำเตือนในหน้ายืนยัน

- **หน้านี้สแกนไว้แล้วและยังรออยู่ในคิว ถ้ายืนยัน ระบบจะใช้ภาพล่าสุดแทน** สแกนซ้ำแผ่นเดิมก่อนที่ภาพแรกจะส่งเสร็จ ยืนยันได้ถ้าต้องการใช้ภาพใหม่
- **นักเรียนรหัส ... ไม่มีในรายชื่อที่เตรียมไว้** เครื่องยังไม่มีรายชื่อล่าสุด ยืนยันได้ตามปกติ เซิร์ฟเวอร์รู้จักนักเรียนจาก QR

## คิวอัปโหลด

ภาพที่สแกนแล้วรออยู่ในคิวของเครื่องจนส่งขึ้นเซิร์ฟเวอร์สำเร็จ เปิดดูได้จากไอคอนรูปเมฆ **คิวอัปโหลด** บนแถบด้านบน ตัวเลขบนไอคอนคือจำนวนรายการที่ยังส่งไม่เสร็จ

| สถานะ | ความหมาย | ปุ่มที่ใช้ได้ |
|---|---|---|
| **รออัปโหลด** | รอส่ง หรือรอลองใหม่ | **ลองใหม่**, **ลบ** |
| **กำลังอัปโหลด** | กำลังส่ง ถ้าค้างเกิน 10 นาทีจะมีข้อความให้กด **ลองใหม่** | (ไม่มี) |
| **ส่งแล้ว** | ส่งสำเร็จ ภาพถูกลบจากเครื่องแล้ว | ไอคอนไม้กวาด **ลบรายการที่ส่งแล้ว** |
| **รอ layout** | สแกนตอนไม่มีเน็ตและเครื่องยังไม่มี layout ของใบงานนั้น | **ประมวลผลต่อ** เมื่อต่อเน็ตได้ |
| **รอครูยืนยัน** | ผลของนักเรียนคนนี้เผยแพร่ไปแล้ว ต้องยืนยันก่อนใช้ภาพใหม่แทน | **ยืนยันแทนที่** |
| **ถูกปฏิเสธ** | เซิร์ฟเวอร์ไม่รับ มีเหตุผลกำกับ | **ลองใหม่**, **ลบ** |

- ระบบส่งเองทันทีหลังสแกน และส่งต่อเบื้องหลังเมื่อมีเครือข่าย ถ้าส่งไม่ได้จะรอแล้วลองใหม่เอง (เว้นช่วงนานขึ้นเรื่อยๆ จนสูงสุด 1 ชั่วโมง)
- ปุ่ม **อัปโหลดตอนนี้** สั่งให้ส่งทั้งคิวทันที แล้วสรุปว่า **ส่งแล้ว N รายการ ...**
- **ลบ** ทิ้งภาพที่ยังไม่ส่ง (ระบบถามยืนยัน) ภาพที่ลบจะไม่ถูกส่งขึ้นเซิร์ฟเวอร์

**อย่าออกจากระบบขณะมีภาพค้างในคิว**
ถ้ากดออกจากระบบขณะยังมีสแกนที่ไม่ได้ส่ง ระบบจะเตือนว่า **ยังมีสแกนที่ยังไม่ได้ส่ง N รายการ** ถ้ายืนยันด้วย **ลบและออกจากระบบ** ภาพเหล่านั้นจะถูกลบจากเครื่องและไม่ถูกส่ง ควรเปิดคิวอัปโหลดแล้วส่งให้เสร็จก่อน

## สแกนเมื่อไม่มีอินเทอร์เน็ต

ห้องเรียนที่สัญญาณไม่ดียังสแกนได้ ถ้าเตรียมข้อมูลลงเครื่องไว้ก่อน

1. ขณะยังมีอินเทอร์เน็ต เปิดหน้าห้องเรียน แล้วกด **เตรียมสแกนออฟไลน์**
2. รอจนขึ้นว่า **พร้อมสแกนออฟไลน์: นักเรียน N คน, การบ้าน N ชุด, layout N หน้า**
3. สแกนตามปกติ ภาพจะรอในคิว และส่งเองเมื่อเครื่องต่ออินเทอร์เน็ตได้

ควรกด **เตรียมสแกนออฟไลน์** ใหม่ทุกครั้งหลังสร้างการบ้านใหม่ สร้าง layout ใหม่ หรือแก้รายชื่อนักเรียน และหลังออกจากระบบแล้วเข้าใหม่ เพราะข้อมูลที่เตรียมไว้เป็นสำเนา ณ เวลาที่กด

ถ้าไม่ได้เตรียมไว้ ระบบจะแจ้งว่า **ยังไม่มี layout ของใบงานนี้ในเครื่อง** ครูกด **เก็บไว้ในคิว** ได้ ภาพจะรอในคิวด้วยสถานะ **รอ layout** และยังไม่ถูกตัดหรือส่งเอง เมื่อต่อเน็ตได้แล้ว ให้เปิดหน้าสแกนอีกครั้ง หรือกด **ประมวลผลต่อ** ในคิวอัปโหลด ระบบจึงตัดภาพและอัปโหลดให้ ภาพกลุ่มนี้ไม่มีหน้ายืนยันให้ตรวจก่อน

## หลังสแกนเสร็จ

AI ใช้เวลาตรวจไม่กี่นาทีหลังภาพขึ้นเซิร์ฟเวอร์ เมื่อเสร็จ ข้อที่ตรวจแล้วจะอยู่ในแท็บ **ตรวจทาน** ให้ครูตรวจและเผยแพร่ (บทที่ 8)
