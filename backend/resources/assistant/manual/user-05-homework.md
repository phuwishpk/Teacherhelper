# การบ้านแบบใบงานของแอป

การบ้านแบบนี้ครูสร้างคำถามในระบบ แล้วพิมพ์ **ใบงานของแอป** ซึ่งมีชื่อนักเรียน QR และกรอบคำตอบของแต่ละข้อ เมื่อนักเรียนทำเสร็จ ครูสแกนด้วยมือถือ ระบบรู้เองว่าเป็นงานของใครและตัดภาพคำตอบของแต่ละข้อส่งให้ AI ตรวจ

ถ้านักเรียนทำในสมุดหรือใบงานของครูเอง ให้ใช้การบ้านแบบ **ไม่ใช้ใบงานของแอป** ในบทที่ 7

## สร้างการบ้าน

1. เปิดแท็บ **การบ้าน** แล้วกด **สร้างการบ้าน** (หรือกด **สร้างการบ้าน** จากหน้าห้องเรียน)
2. กรอกฟอร์มตามตารางด้านล่าง แล้วกด **สร้างการบ้าน**
3. ระบบเปิดหน้าการบ้านให้เพิ่มคำถามต่อได้ทันที

| ช่อง | ความหมาย |
|---|---|
| **ชื่อการบ้าน** | ชื่อที่ครูและนักเรียนเห็น |
| **คำชี้แจงถึงนักเรียน (ไม่บังคับ)** | ข้อความไม่เกิน 2,000 ตัวอักษร นักเรียนเห็นในหน้าส่งงาน และอยู่ในคำอธิบายงานใน Google Classroom ด้วย |
| **ห้องเรียน** | ห้องที่จะสั่งงาน เลือกได้ตอนสร้างเท่านั้น แก้ภายหลังไม่ได้ |
| **รายวิชา** | แสดงหลังเลือกห้อง ต้องเลือก ถ้าห้องยังไม่มีรายวิชา ระบบจะมีปุ่ม **สร้างรายวิชา** ให้ |
| **แผนการสอน (ไม่บังคับ)** | แผนที่การบ้านนี้วัดผล ช่วยให้ AI เสนอตัวชี้วัดของแต่ละข้อได้ |
| **หัวข้อ** | เลือก **ไม่มีหัวข้อ** หน่วยการเรียนรู้ของรายวิชา หรือ **พิมพ์หัวข้อเอง…** แล้วกรอก **ชื่อหัวข้อ** นักเรียนเห็นการบ้านจัดกลุ่มตามหัวข้อ และใน Google Classroom งานอยู่ในหัวข้อชื่อเดียวกัน |
| **หมวดคะแนน** | หมวดในสมุดคะแนน การบ้านใหม่เข้าหมวดตั้งต้นของการบ้านให้เอง เปิด **ไม่นับเกรด** ถ้าเป็นงานฝึกที่ไม่คิดคะแนน |
| **ไฟล์และลิงก์** | กด **แนบไฟล์** หรือ **แนบลิงก์** เพื่อแนบใบความรู้หรือคลิปให้นักเรียน (PDF รูปภาพ และไฟล์ Word, Excel, PowerPoint ไฟล์ละไม่เกิน 10 MB รวมกับลิงก์ไม่เกิน 5 รายการ) บนเว็บแอปที่ผู้ดูแลระบบตั้งค่าตัวเลือกไฟล์ของ Google (Google Picker) ไว้ตอนติดตั้ง มีปุ่ม **เลือกจาก Google Drive** เพิ่ม ไฟล์ที่เลือกถูกแนบเป็นลิงก์ หลังโพสต์ลง Google Classroom แล้วแก้ไฟล์แนบไม่ได้ |
| **ส่งถึง** | **ทั้งห้อง** หรือ **เลือกนักเรียน** (ติ๊กชื่อแล้วกด **เลือก N คน**) นักเรียนที่ไม่ได้รับมอบจะไม่เห็นการบ้านนี้ ใบงานพิมพ์เฉพาะคนที่ได้รับ และช่องในสมุดคะแนนของคนอื่นเป็น **ไม่ได้รับมอบ** ซึ่งไม่นับคะแนน หลังโพสต์ลง Google Classroom แล้วเปลี่ยนผู้รับไม่ได้ |
| **ส่งไป Google Classroom ด้วย** | มีเฉพาะเมื่อครูผูกห้องที่เลือกกับคอร์สของตัวเองไว้ (หัวข้อ 12.3) ติ๊กไว้ให้แล้ว ระบบโพสต์เป็นงานในคอร์สให้เองทันทีที่การบ้านพร้อมใช้ (หัวข้อ 12.4) |
| **รูปแบบการบ้าน** | **ใบงานของแอป** (บทนี้) หรือ **ไม่ใช้ใบงานของแอป** (บทที่ 7) เปลี่ยนไม่ได้หลังสร้าง layout หรือมีงานส่งแล้ว |
| **ความเข้มงวดในการตรวจ** | **ผ่อนปรน** **ปกติ** หรือ **เข้มงวด** มีผลกับคะแนนบางส่วนของข้อที่ไม่ใช่ปรนัย เช่น คำตอบสั้นที่เกือบถูก |
| **วันส่ง** | แตะแถว **ไม่กำหนดวันส่ง** เพื่อเลือกวัน ระบบนับถึงเวลา 23:59 ของวันนั้น |
| **รับงานส่งช้า** | เปิด: งานที่ส่งหลังกำหนดยังตรวจได้และมีป้าย **ส่งช้า** ปิด: งานหลังกำหนดไม่ถูกตรวจ และนักเรียนส่งในแอปไม่ได้ |
| **เฉพาะคะแนน** | เปิด: นักเรียนเห็นคะแนนกับข้อความสำเร็จรูป AI ไม่เขียนคำอธิบายรายข้อ ประหยัดค่าใช้จ่าย |

## หน้าการบ้าน

หน้าการบ้านรวมทุกอย่างของการบ้านชิ้นนั้น เรียงเป็นการ์ดตามลำดับที่ครูต้องทำ

| จุด | การ์ด | ใช้ทำอะไร |
|---|---|---|
| (1) | สรุป | สถานะ (**ร่าง**, **พร้อมใช้**, **ปิดแล้ว**) ห้อง รายวิชา แผน ความเข้มงวด รูปแบบ และเวอร์ชันของ layout |
| (2) | **เฉลย** | ดูและแก้เฉลยของทุกข้อ |
| (3) | **ใบงาน** | **สร้าง layout** และ **พิมพ์ใบงาน** |
| (4) | **อัปโหลดรูปเพื่อตรวจ** | แนบรูปหรือ PDF ของงานนักเรียนแทนการสแกน (บทที่ 7) |
| (5) | **ตรวจทานและเผยแพร่** | เปิดคิวตรวจทานของการบ้านนี้ (บทที่ 8) |
| (6) | **วิเคราะห์ผล** | ข้อที่ผิดบ่อย ค่าความยากง่าย (หัวข้อ 11.1) |

ถัดลงไปคือการ์ด **Google Classroom** (ถ้าเปิดใช้) **จับคู่ข้อกับตัวชี้วัด** และรายการ **คำถาม** ปุ่ม **เพิ่มคำถาม** อยู่มุมล่าง ไอคอนดินสอด้านบนใช้แก้การตั้งค่าของการบ้าน

## เพิ่มคำถาม

กด **เพิ่มคำถาม** เลือก **ประเภทคำถาม** พิมพ์ **โจทย์** ใส่ **คะแนนเต็ม** เลือก **ตัวชี้วัด / ทักษะ** แล้วกรอกเฉลยตามประเภท จากนั้นกด **เพิ่มข้อ**

| ประเภท | นักเรียนตอบอย่างไร | เฉลยที่ครูกรอก | ตรวจโดย |
|---|---|---|---|
| **ปรนัย** | ฝนวงกลม A–D บนใบงาน | เลือกข้อที่ถูกหนึ่งข้อ (ตัวเลือกมี 4 ข้อเสมอ พิมพ์ข้อความตัวเลือกไว้ในโจทย์) | ระบบ เทียบวงที่ฝนกับเฉลย |
| **เติมคำตอบสั้น** | เขียนคำตอบในกรอบ | **คำตอบที่ยอมรับ** บรรทัดละหนึ่งคำตอบ | AI อ่านลายมือ แล้วเทียบกับเฉลย |
| **แสดงวิธีทำ** | เขียนวิธีทำทีละบรรทัด และคำตอบสุดท้ายในกรอบ | **คำตอบสุดท้ายที่ยอมรับ** **จำนวนบรรทัดคำตอบ** และ **ขั้นตอนอ้างอิง** | AI ตรวจวิธีทำทีละบรรทัดและคำตอบสุดท้าย |
| **อัตนัย** | เขียนตอบเป็นข้อความ | ไม่มีเฉลยตายตัว ใช้ rubric ใส่ **คำตอบตัวอย่างของครู** ได้ | AI ตรวจตาม rubric |

รายละเอียดที่ควรรู้

- **คำตอบเป็นตัวเลข** (ข้อเติมคำตอบสั้นและแสดงวิธีทำ) เมื่อเปิด ให้กรอก **ค่าตัวเลข** และ **คลาดเคลื่อนได้ ±** คำตอบที่อยู่ในช่วงนั้นถือว่าถูก ในแอป Android ตัวอ่านตัวเลขในเครื่องจะช่วยอ่านซ้ำอีกชั้น
- **การเทียบคำตอบ** ของข้อเติมคำตอบสั้น เลือก **ยืดหยุ่น** (ค่าตั้งต้น) หรือ **ตรงตัว (สะกดคำ)** เมื่อต้องการให้สะกดถูกทุกตัว
- คำตอบที่มีจุลภาค เช่น `1,000` พิมพ์ได้ตามปกติ เพราะระบบแยกคำตอบด้วยการขึ้นบรรทัดใหม่
- ข้อ **แสดงวิธีทำ** และ **อัตนัย** ตั้ง **จำนวนบรรทัดคำตอบ** บนใบงานได้ 1–15 บรรทัด
- ข้อ **แสดงวิธีทำ** และ **อัตนัย** ต้องอนุมัติ rubric ก่อนจึงจะสร้าง layout ได้ (หัวข้อถัดไป)

แก้คำถามโดยแตะที่ข้อในรายการ ลบด้วยไอคอนถังขยะท้ายข้อ ข้อที่มีคำตอบของนักเรียนสแกนเข้ามาแล้วลบไม่ได้

## Rubric ของข้อแสดงวิธีทำและข้ออัตนัย

Rubric คือเกณฑ์ที่ AI ใช้ให้คะแนน ครูต้องตรวจและอนุมัติเองทุกข้อ ระบบจึงจะยอมให้สร้าง layout

เปิดได้จากป้าย **rubric: ...** ท้ายคำถามในหน้าการบ้าน หรือปุ่ม **Rubric** มุมขวาบนของหน้าแก้คำถาม

**ข้อแสดงวิธีทำ** ตรวจจากวิธีทำทีละบรรทัดกับคำตอบสุดท้าย ครูกรอก **ขั้นตอนอ้างอิง** บรรทัดละขั้น หรือกด **ให้ AI ร่างขั้นตอนอ้างอิง** แล้วแก้ให้ถูก

**ข้ออัตนัย** ใช้ **เกณฑ์การให้คะแนน** หลายข้อ

1. กด **ให้ AI ร่าง rubric** แล้วรอสักครู่ (หรือกด **เพิ่มเกณฑ์** เพื่อเขียนเอง)
2. แก้ข้อความ **เกณฑ์** และ **คะแนน** ของแต่ละข้อ ลบเกณฑ์ที่ไม่ต้องการด้วยเครื่องหมาย X คะแนนของทุกเกณฑ์รวมกันต้องเท่ากับคะแนนเต็มของข้อพอดี
3. ติ๊ก **เกณฑ์หลัก (แก่นของคำตอบ)** ที่เกณฑ์สำคัญที่สุด ต้องมีหนึ่งข้อพอดี
4. กด **บันทึกและอนุมัติ**

| ข้อความ | ความหมาย |
|---|---|
| **เกณฑ์ข้อ N ต้องมีคำอธิบายและคะแนน** / **ต้องมีเกณฑ์อย่างน้อย 1 ข้อ** / **เลือกเกณฑ์หลักได้เพียงข้อเดียว** | ต้องแก้ก่อนจึงบันทึกได้ |
| **เลือกเกณฑ์หลัก (แก่นของคำตอบ) 1 ข้อก่อนอนุมัติ** / **คะแนนรวมของเกณฑ์ (…) ต้องเท่ากับคะแนนเต็มของข้อ (…)** | ระบบไม่อนุมัติ rubric ที่ไม่มีเกณฑ์หลัก หรือคะแนนรวมไม่เท่ากับคะแนนเต็ม ต้องแก้ก่อน |
| **ยังไม่มีขั้นตอนอ้างอิง** | คำเตือนของข้อแสดงวิธีทำ ครูกด **อนุมัติ** เพื่อผ่านได้ AI จะตรวจวิธีทำโดยไม่มีขั้นตอนตัวอย่างให้เทียบ |
| **ยังไม่ได้ร่างจาก AI (คิวอาจยังไม่ทำงาน) ลองกดใหม่ภายหลัง** | รอเกิน 3 นาทีแล้วยังไม่ได้ผล ลองกดอีกครั้ง หรือเขียนเอง |

**ถ้าแก้คะแนนเต็มของข้อ หรือให้ AI ร่างใหม่ rubric ของข้อนั้นจะกลับเป็น **ร่างแล้ว รออนุมัติ** ต้องอนุมัติอีกครั้ง**

## สร้าง layout และพิมพ์ใบงาน

**Layout** คือการจัดหน้าใบงาน ระบบจำตำแหน่งกรอบคำตอบของทุกข้อไว้ เพื่อใช้ตัดภาพตอนสแกน

1. ที่การ์ด **ใบงาน** กด **สร้าง layout** ระบบขึ้นว่า **สร้าง layout เวอร์ชัน N แล้ว (P หน้า) พิมพ์ใบงานได้เลย** และการบ้านเปลี่ยนสถานะเป็น **พร้อมใช้**
2. กด **พิมพ์ใบงาน** รอระบบสร้าง PDF (ข้อความเปลี่ยนเป็น **อยู่ในคิว** → **กำลังสร้าง PDF** → **กำลังดาวน์โหลด…**)
3. เมื่อเสร็จ ระบบแสดงตัวเลือกของไฟล์ บนเว็บกด **ดาวน์โหลด** ในแอป Android กด **เปิดไฟล์** **บันทึกลงเครื่อง** หรือ **แชร์ / ส่งไปพิมพ์**
4. พิมพ์ลงกระดาษ A4 ขนาดจริง (ไม่ย่อ ไม่ขยาย) แจกให้ตรงชื่อ

| จุด | ส่วนของใบงาน |
|---|---|
| (1) | **สัญลักษณ์สี่เหลี่ยมที่มุมทั้ง 4** ระบบใช้หาขอบกระดาษ ห้ามพับ ขีดเขียน หรือตัดออก |
| (2) | **QR** บอกว่าเป็นการบ้านใด ของนักเรียนคนใด หน้าใด |
| (3) | ชื่อการบ้าน ชื่อ เลขที่ และห้องของนักเรียน |
| (4) | กรอบคำตอบของข้อเติมคำตอบสั้น |
| (5) | บรรทัดวิธีทำและกรอบ **คำตอบ** สุดท้ายของข้อแสดงวิธีทำ |

**ใบงานเป็นของรายคน ห้ามถ่ายเอกสารแจก**
QR บนใบงานแต่ละแผ่นระบุตัวนักเรียน ถ้าถ่ายเอกสารแผ่นเดียวแจกหลายคน งานทุกแผ่นจะถูกบันทึกเป็นของนักเรียนคนเดียว ต้องพิมพ์จากไฟล์ PDF ให้ครบทุกคน และให้นักเรียนเขียนคำตอบ **ในกรอบเท่านั้น**

| ข้อความบนการ์ดใบงาน | ความหมาย |
|---|---|
| **เพิ่มคำถามก่อน จึงจะสร้าง layout ได้** | ยังไม่มีคำถาม |
| **มี N ข้อ (แสดงวิธีทำ/อัตนัย) ที่ยังไม่อนุมัติ rubric ...** | อนุมัติ rubric ให้ครบก่อน |
| **ถ้าแก้คำถามหลังพิมพ์ ให้สร้าง layout ใหม่ก่อนพิมพ์อีกครั้ง** | ดูหัวข้อ 5.7 |
| **สร้าง PDF ใช้เวลานานเกินไป ลองดูสถานะใหม่ภายหลัง** | รอเกิน 5 นาที ลองกดพิมพ์อีกครั้งภายหลัง ถ้ายังไม่ได้ให้แจ้งผู้ดูแลระบบ |

## จับคู่ข้อกับตัวชี้วัด

ตัวชี้วัดของแต่ละข้อเลือกได้ตอนเพิ่มคำถาม หรือทำรวมทีเดียวที่การ์ด **จับคู่ข้อกับตัวชี้วัด**

1. ถ้าการบ้านผูกกับแผนการสอนที่มีตัวชี้วัด กด **ให้ AI เสนอตัวชี้วัด** แล้วรอ 1–2 นาที AI เลือกได้เฉพาะตัวชี้วัดของแผนนั้น
2. ในแต่ละข้อ กด **ใช้** ที่ข้อเสนอที่ถูกต้อง หรือ **ใช้ข้อเสนอทั้งหมด** หรือกด **เลือกตัวชี้วัดเอง**
3. กด **บันทึก** มุมขวาบน

ข้อที่ยังไม่ผูกตัวชี้วัดมีคำเตือน **มี N ข้อยังไม่ผูกตัวชี้วัด คะแนนข้อเหล่านี้จะไม่นับในกราฟ** แต่ไม่ได้ห้ามพิมพ์หรือตรวจ

## แก้ไขหลังพิมพ์ และการลบ

- **แก้คำถามหลังพิมพ์** ถ้าเพิ่ม ลบ หรือแก้ข้อจนหน้ากระดาษเปลี่ยน การบ้านจะกลับเป็น **ร่าง** ให้กด **สร้าง layout ใหม่** แล้วพิมพ์อีกครั้ง ใบงานที่พิมพ์ไปก่อนยังสแกนได้ เพราะ QR จำเวอร์ชันของ layout ไว้
- **แก้เฉลยหลังตรวจไปแล้ว** แก้ที่การ์ด **เฉลย** แล้วใช้ **ตรวจใหม่ทั้งห้อง** (หัวข้อ 7.2) เพื่อตรวจงานที่ตรวจแล้วอีกครั้งด้วยเฉลยใหม่
- **ลบการบ้าน** ไอคอนถังขยะด้านบนมีเฉพาะตอนสถานะ **ร่าง** คำถามทั้งหมดจะถูกลบด้วย การบ้านที่เคยพิมพ์ใบงานหรือโพสต์ลง Google Classroom แล้วลบไม่ได้ แม้จะกลับเป็นร่างแล้วก็ตาม ระบบขึ้นว่า **การบ้านนี้พิมพ์ใบงานไปแล้ว ลบไม่ได้** หรือ **การบ้านนี้โพสต์ลง Google Classroom แล้ว ลบไม่ได้**
