# ส่งงาน

เมื่อครูเปิดรับการบ้าน นักเรียนส่งงานได้เองโดยถ่ายรูปงานที่ทำในสมุดหรือในใบงาน หรือเลือกไฟล์รูปและ PDF จากเครื่อง แล้วระบบจะส่งให้ครูตรวจ

**งานที่ครูเก็บไปสแกนเอง**
ถ้าครูแจก **ใบงานที่มี QR** และเก็บใบงานกลับไปสแกนเอง นักเรียนไม่ต้องส่งในแอปอีก ให้ทำตามที่ครูบอก ส่วน **ข้อสอบ** ไม่มีการส่งในแอป ครูสแกนกระดาษคำตอบเอง

## ดูงานที่ต้องส่ง

แตะ **ส่งงาน** ที่เมนูหลัก จะเห็นการบ้านที่ครูเปิดรับ จัดกลุ่มตามวิชา ถ้าเรียนหลายวิชาจะมีป้ายให้กรองเฉพาะวิชา

| ป้ายในรายการ | ความหมาย |
|---|---|
| **กำหนดส่ง (วันเวลา)** หรือ **ไม่มีกำหนดส่ง** | วันและเวลาที่ต้องส่ง |
| **ส่งแล้ว (วันเวลา)** | ส่งงานนี้แล้ว รอครูตรวจ |
| **ประกาศผลแล้ว** | ครูเผยแพร่ผลแล้ว แตะเพื่อดูผล |
| **ส่งช้า** | ส่งหลังกำหนด |
| **เลยกำหนด ส่งได้แต่จะติดป้ายส่งช้า** | เลยกำหนดแล้ว แต่ครูยังรับงาน |
| **ปิดรับแล้ว** | เลยกำหนดและครูไม่รับงานส่งช้า |
| **ห้องเก่า ส่งไม่ได้แล้ว** | ห้องปิดแล้ว |

## ส่งงานทีละขั้น

1. แตะการบ้านที่ต้องการส่ง
2. ในแอป Android กด **ถ่ายรูป** แล้วถ่ายงานทีละหน้า เสร็จแล้วกด **เสร็จ** หรือกด **เลือกรูปหรือ PDF** เพื่อเลือกไฟล์ที่มีอยู่ในเครื่อง (บนเว็บมีเฉพาะปุ่ม **เลือกรูปหรือ PDF**)
3. ตรวจรายการไฟล์ที่เลือก แต่ละไฟล์มีป้าย **หน้า N** ถ้าเลือกผิดให้กดเครื่องหมาย ✕ เพื่อเอาไฟล์นั้นออก
4. กด **ส่งงาน** แล้วรอจนขึ้นว่า **ส่งงานแล้ว** ระหว่างนี้อย่าปิดหน้าจอ
5. กด **เสร็จ**

หลังส่ง หน้าจอบอกเวลาที่ส่งและจำนวนหน้า ครูจะตรวจและประกาศผล แล้วคะแนนจะขึ้นในแท็บ **ผลการบ้าน**

| ข้อกำหนดของไฟล์ | ค่า |
|---|---|
| จำนวนไฟล์ต่อครั้ง | ไม่เกิน 5 ไฟล์ |
| จำนวนหน้ารวม | ไม่เกิน 5 หน้า (ไฟล์ PDF นับทุกหน้า) |
| ขนาดไฟล์ | ไฟล์ละไม่เกิน 10 MB |
| ชนิดไฟล์ | รูป JPG, PNG, WebP, HEIC หรือ PDF |

ไฟล์ Word ส่งไม่ได้ ให้บันทึกเป็น PDF ก่อน

## ถ่ายรูปงานให้ครูตรวจง่าย

- ถ่าย **ให้เห็นทั้งหน้า** ตั้งกล้องตรงกับกระดาษ ไม่เอียง
- ใช้ที่สว่าง อย่าให้เงามือหรือเงามือถือทับกระดาษ
- รอให้ภาพชัดก่อนกดถ่าย ถ้าภาพเบลอให้ถ่ายใหม่
- **หนึ่งรูปต่อหนึ่งหน้า** และเรียงตามลำดับหน้า
- เขียน **เลขข้อ** กำกับทุกข้อให้ชัด เพื่อให้ระบบหาคำตอบของแต่ละข้อได้ถูก

## ส่งช้า และส่งใหม่

- **เลยกำหนดส่งแล้ว** ถ้าครูยังรับงาน หน้าส่งงานจะบอกว่า **ยังส่งได้ แต่งานจะติดป้าย "ส่งช้า"** ถ้าครูไม่รับงานส่งช้า จะขึ้นว่า **ปิดรับงานแล้ว** และไม่มีปุ่มส่ง ให้ติดต่อครูผู้สอน
- **ส่งผิดหรือถ่ายไม่ชัด** ก่อนครูประกาศผล นักเรียนส่งใหม่ได้ เปิดการบ้านนั้นแล้วกด **ส่งงานใหม่** และยืนยัน **ส่งใหม่** ครูจะตรวจงานที่ส่งล่าสุดแทนงานเดิม
- หลังครูประกาศผลแล้ว ส่งใหม่เองไม่ได้ ถ้าคิดว่าครูตรวจผิด ให้ใช้ **ขอให้ครูตรวจใหม่** (บทที่ 18)

| ข้อความ | วิธีแก้ |
|---|---|
| **ส่งได้ไม่เกิน 5 ไฟล์ต่อครั้ง** | เอาไฟล์ออกให้เหลือไม่เกิน 5 ไฟล์ ถ้างานมีหลายหน้า รวมเป็น PDF ไฟล์เดียวที่ไม่เกิน 5 หน้า |
| **(ชื่อไฟล์): ส่งได้เฉพาะรูป (JPG, PNG, WebP, HEIC) หรือ PDF …** | เปลี่ยนเป็นรูปหรือ PDF |
| **(ชื่อไฟล์): ไฟล์ใหญ่เกิน 10 MB** | ถ่ายใหม่ด้วยความละเอียดต่ำลง หรือย่อขนาดไฟล์ |

**งานที่ครูสั่งผ่าน Google Classroom**
ให้ส่งในงานของ Classroom ตามปกติ ผลจะขึ้นใน Krucheck หลังครูเผยแพร่ ถ้าแท็บ **ผลการบ้าน** มีการ์ด **ครูขอให้ถ่ายรูปใหม่** ให้ถ่ายรูปใหม่ให้ชัด แล้วส่งอีกครั้งในงานเดิมบน Classroom
