# เกรดและกราฟ

## ดูเกรด

นักเรียนเห็นเกรดของรายวิชาเมื่อครู **ประกาศเกรด** แล้ว เปิดดูได้ 3 ทาง

- กล่องเกรดบนการ์ดของวิชาในหน้า **วิชาของฉัน**
- ปุ่ม **เกรดทั้งหมด** ในหน้าวิชาของฉัน เปิดหน้า **เกรดของฉัน** ที่รวมทุกวิชา
- แท็บ **เกรด** ในหน้าของวิชา

หน้ารายละเอียด () แสดง

| ส่วน | ความหมาย |
|---|---|
| **เกรด** | 4, 3.5, 3, 2.5, 2, 1.5, 1 หรือ 0 หรือ **ร** (รอการตัดสิน เช่น ยังส่งงานไม่ครบ) หรือ **มส** (ไม่มีสิทธิ์เข้ารับการวัดผลปลายภาค) |
| **คะแนนรวม … (ปัดเป็น …)** | คะแนนรวมเต็ม 100 และค่าที่ปัดเป็นจำนวนเต็มซึ่งใช้ตัดเกรด |
| **ห้อง** และวันที่ **ประกาศ** | ห้องเรียนของเกรดนี้ และวันที่ครูประกาศ |
| แถวของแต่ละ **หมวดคะแนน** | ชื่อหมวดและน้ำหนัก เช่น **คะแนนเก็บ (70%)** และ **ได้ 86.67% = 60.67 จาก 70 คะแนน** |

แตะแถวของหมวดเพื่อดูรายการคะแนนในหมวดนั้น

| ข้อความในรายการ | ความหมาย |
|---|---|
| **x/เต็ม** | คะแนนที่ได้ของงานนั้น |
| **ไม่ส่ง / ไม่มีคะแนน** | ไม่ได้ส่งงานหรือไม่มีคะแนน นับเป็น 0 |
| **รอประกาศผล (ไม่นับ)** | ส่งแล้ว ครูยังไม่เผยแพร่ผล ยังไม่นำมาคิด |
| **ยังไม่ถึงกำหนด (ไม่นับ)** | ยังไม่เลยวันส่ง ยังไม่นำมาคิด |
| **ยกเว้น** | ครูยกเว้นงานนี้ให้ ไม่นำมาคิด |
| **ตัดออก (คะแนนต่ำสุดของหมวด)** | ครูตั้งให้ตัดคะแนนที่ต่ำสุดของหมวดออก งานนี้จึงไม่นำมาคิด |

ถ้าครูยังไม่ประกาศ หน้านี้จะขึ้นว่า **ยังไม่ได้ประกาศเกรด** ถ้าครูแก้คะแนนหลังประกาศ นักเรียนจะเห็นค่าใหม่เมื่อครูประกาศอีกครั้ง

นักเรียนเห็นเฉพาะเกรดและคะแนนของตัวเอง ไม่เห็นของเพื่อน ค่าเฉลี่ยของห้อง หรืออันดับ ถ้าสงสัยเรื่องเกรด ให้สอบถามครูผู้สอนของวิชานั้น

## ดูกราฟความเข้าใจ

เปิดจากแท็บ **กราฟ** ในหน้าของวิชา หรือ **กราฟตามรายวิชา** ในแท็บทักษะ

**ความเข้าใจของฉัน** แสดงระดับความเข้าใจในแต่ละกลุ่มของวิชา สลับดู **ตามมาตรฐาน** หรือ **ตามหน่วย** ได้ ยิ่งจุดอยู่ใกล้ขอบนอก ยิ่งเข้าใจดี แตะที่แกนหรือแถวเพื่อดูตัวชี้วัดในกลุ่มนั้น กลุ่มที่ยังไม่มีผลจะขึ้นว่า **ยังไม่ประเมิน**

**พัฒนาการตามเวลา** แสดงว่าความเข้าใจของแต่ละตัวชี้วัดเปลี่ยนไปอย่างไรในแต่ละวัน หนึ่งเส้นต่อหนึ่งตัวชี้วัด กดไอคอน **เลือกตัวชี้วัด** เพื่อเลือกเส้นที่ต้องการดู แสดงได้ไม่เกิน 5 เส้น กราฟนี้จะมีข้อมูลหลังครูเผยแพร่ผลการบ้าน
