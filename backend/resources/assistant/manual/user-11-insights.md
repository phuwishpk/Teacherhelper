# ติดตามผลการเรียน

หลังเผยแพร่ผล Krucheck นำคะแนนไปสรุปให้ครูเห็นใน 5 มุม ทุกหน้าใช้เฉพาะ **ผลที่เผยแพร่แล้ว**

| หน้า | ตอบคำถามว่า | เปิดจาก |
|---|---|---|
| **วิเคราะห์ผล** | งานชิ้นนี้ข้อใดยาก ข้อใดผิดมาก ผิดแบบใด | หน้าการบ้านหรือหน้าข้อสอบ |
| **ทักษะของห้อง** | นักเรียนคนใดยังไม่เข้าใจตัวชี้วัดใด | หน้าห้องเรียน |
| **กราฟและความคืบหน้า** | สอนและประเมินตามแผนไปเท่าใด ห้องเข้าใจมาตรฐานใดดี | หน้ารายวิชา |
| **วิเคราะห์รายคน** | นักเรียนแต่ละคนเด่นและควรพัฒนาเรื่องใด | หน้าห้องเรียน (ครูประจำชั้น) |
| **คลังแบบฝึก** | จะให้นักเรียนฝึกเรื่องที่ยังอ่อนอย่างไร | หน้าหลัก |

ตารางทักษะ กราฟ และการวิเคราะห์รายคนคิดจากข้อที่ **ผูกตัวชี้วัดไว้** เท่านั้น (หัวข้อ 5.6)

## วิเคราะห์ผลของงานหนึ่งชิ้น

กดการ์ด **วิเคราะห์ผล** ในหน้าการบ้าน หรือปุ่ม **วิเคราะห์ผล** ในหน้าข้อสอบ ถ้ายังไม่มีผลที่เผยแพร่ หน้านี้จะขึ้นว่า **ยังไม่มีผลที่เผยแพร่**

| การ์ด | อ่านอย่างไร |
|---|---|
| สรุปด้านบน | จำนวนนักเรียนที่เผยแพร่ผลแล้ว จำนวนข้อ และ **ข้อที่ควรทบทวนคุณภาพ** (ข้อที่มีป้ายเตือน) |
| **การกระจายคะแนน** | แท่งคือจำนวนนักเรียนในแต่ละช่วงคะแนน ช่วงละ 10% ของคะแนนเต็ม พร้อมค่า **เฉลี่ย** และ **มัธยฐาน** |
| **ข้อที่ทั้งห้องผิดมากที่สุด** | ห้าข้อที่นักเรียนได้คะแนนเฉลี่ยต่ำสุด แตะค้างที่แถวเพื่อดูรายละเอียด |
| **ค่าความยากง่าย (p) และอำนาจจำแนก (r)** | ตารางของทุกข้อ ดูคำอธิบายด้านล่าง |
| **ทักษะ × ประเภทข้อผิดพลาด** (การบ้าน) | จำนวนข้อที่ครูยืนยันประเภทข้อผิดพลาดนั้นในแต่ละทักษะ สีเข้มคือพบมาก แตะค้างที่ช่องเพื่อดูรายละเอียด |
| **วิเคราะห์ตัวเลือก** (ข้อสอบ) | จำนวนคนที่เลือกแต่ละตัวเลือก (หัวข้อ 9.8) |

**ค่า p (ความยากง่าย)** คือสัดส่วนคะแนนเฉลี่ยที่นักเรียนได้ในข้อนั้น มีค่า 0–1 ยิ่งสูงยิ่งง่าย เช่น p = 0.80 แปลว่านักเรียนได้เฉลี่ย 80% ของคะแนนเต็ม

**ค่า r (อำนาจจำแนก)** คือผลต่างของสัดส่วนคะแนนระหว่างกลุ่มคะแนนสูง 27% กับกลุ่มคะแนนต่ำ 27% ยิ่งสูงแปลว่าข้อนั้นแยกนักเรียนที่เข้าใจกับยังไม่เข้าใจได้ดี ค่า r แสดงเมื่อเผยแพร่ผลแล้วตั้งแต่ 20 คนขึ้นไป ถ้าน้อยกว่านั้นจะขึ้นว่า **ข้อมูลน้อย**

| ป้ายเตือน | เงื่อนไข | ควรทำอย่างไร |
|---|---|---|
| **ยากเกินไป** | p ต่ำกว่า 0.20 | ตรวจว่าโจทย์กำกวม เฉลยผิด หรือยังไม่ได้สอนหรือไม่ |
| **ง่ายเกินไป** | p สูงกว่า 0.80 | ใช้เป็นข้อเก็บคะแนนพื้นฐานได้ แต่แยกระดับนักเรียนไม่ได้ |
| **จำแนกได้น้อย** | r ต่ำกว่า 0.20 | นักเรียนเก่งและอ่อนทำได้พอกัน ควรปรับโจทย์ |

**ประเภทข้อผิดพลาดมาจากการตรวจทาน**
ตาราง **ทักษะ × ประเภทข้อผิดพลาด** นับจากประเภทข้อผิดพลาดที่ครูเลือกตอนตรวจทาน (หัวข้อ 8.3) ถ้าครูไม่ได้เลือก ตารางนี้จะว่าง

## ทักษะของห้องและของนักเรียน

### ตารางทักษะของห้อง

ที่หน้าห้องเรียน กด **ทักษะของห้อง** ตารางแสดงนักเรียนเป็นแถว ตัวชี้วัดเป็นคอลัมน์ แต่ละช่องคือระดับความเข้าใจเป็นร้อยละ

| สี | ระดับ | เกณฑ์ |
|---|---|---|
| เขียว | **เข้าใจดี** | ตั้งแต่ 75% |
| ส้ม | **เข้าใจบางส่วน** | 40–74% |
| แดง | **ยังไม่เข้าใจ** | ต่ำกว่า 40% |
| เทา | **ข้อมูลยังน้อย** | ทำข้อของตัวชี้วัดนั้นไม่ถึง 2 ครั้ง ไม่ว่าจะได้ร้อยละเท่าใด |

- **รายวิชา** เลือกดูเฉพาะตัวชี้วัดของรายวิชาหนึ่ง (ครูประจำชั้นเลือก **ทุกทักษะ** ได้) และ **หน่วย** เลือกดูเฉพาะหน่วยการเรียนรู้
- การ์ด **ทักษะที่ห้องนี้ควรทบทวน** แสดงไม่เกิน 3 ทักษะที่ค่าเฉลี่ยของห้องต่ำที่สุดและต่ำกว่า 75%
- แตะค้างที่ช่องเพื่อดูชื่อ ตัวชี้วัด ร้อยละ ระดับ และจำนวนครั้ง แตะที่แถวเพื่อเปิดหน้าของนักเรียนคนนั้น
- เครื่องหมาย **–** แปลว่ายังไม่มีข้อมูล

ค่าในตารางเป็นค่าเฉลี่ยแบบถ่วงน้ำหนักที่ให้ผลล่าสุดมีผลมากกว่า ผลใหม่จากการบ้านหรือข้อสอบมีน้ำหนัก 30% และผลจากแบบฝึกมีน้ำหนัก 15% ค่าจึงขยับตามพัฒนาการของนักเรียน ไม่ใช่ค่าเฉลี่ยของทุกครั้งเท่ากัน

### หน้าทักษะของนักเรียนรายคน

เปิดจากแถวในตารางทักษะ หรือเมนูของนักเรียน **ทักษะและจุดอ่อน** ในหน้าห้องเรียน ()

- **จุดอ่อน 3 อันดับ** สามทักษะที่ต่ำที่สุดในระดับยังไม่เข้าใจหรือเข้าใจบางส่วน
- **กราฟตามรายวิชา** ทางลัดไปกราฟของนักเรียนคนนี้ในแต่ละรายวิชา
- รายการทักษะทั้งหมด เรียงจากอ่อนที่สุด แต่ละแถวบอกร้อยละ จำนวนครั้ง และวันที่อัปเดต แถบมีขีดบอกเกณฑ์ 40% และ 75%
- ไอคอน **วิเคราะห์รายคน (AI)** มุมขวาบน สำหรับครูประจำชั้น

## กราฟและความคืบหน้าของรายวิชา

ที่หน้ารายวิชา กด **กราฟและความคืบหน้า** (หรือ **กราฟรายวิชา …** ในหน้าห้องเรียน) ถ้ารายวิชามีหลายห้อง เลือก **ห้องเรียน** ด้านบน

| กราฟ | อ่านอย่างไร |
|---|---|
| **ความคืบหน้าตามแผนรายวิชา** | หนึ่งแท่งต่อหนึ่งหน่วย แบ่งเป็น **ประเมินแล้ว** (มีผลที่เผยแพร่ของตัวชี้วัดนั้น) **สอนแล้ว ยังไม่ประเมิน** (บันทึกว่าสอนแผนแล้ว หัวข้อ 4.3) และ **ยังไม่สอน** กด **ดูเป็นตาราง** เพื่อดูตัวเลข |
| **ภาพรวมของห้อง** | ระดับความเข้าใจเฉลี่ยของห้อง สลับ **ตามมาตรฐาน** หรือ **ตามหน่วย** ได้ แตะแกน แท่ง หรือแถว เพื่อดูตัวชี้วัดในกลุ่มนั้นและจำนวนคนที่ผ่าน |
| **ร้อยละนักเรียนที่ผ่านแต่ละตัวชี้วัด** | ผ่าน = ความเข้าใจตั้งแต่ 50% ขึ้นไป ค่า n ใต้แท่งคือจำนวนนักเรียนที่ประเมินแล้ว |
| **Heatmap นักเรียน × ตัวชี้วัด** | เปิดตารางทักษะของห้องเฉพาะรายวิชานี้ (หัวข้อ 11.2) |
| **รายคน** | เปิดกราฟของนักเรียนหนึ่งคน: กราฟเรดาร์ความเข้าใจ และ **พัฒนาการตามเวลา** |

กราฟภาพรวมเป็นเรดาร์เมื่อมีกลุ่มที่ประเมินแล้ว 3–12 กลุ่ม ถ้าน้อยกว่านั้นระบบแสดงรายตัวชี้วัดแทน และถ้ามากกว่านั้นจะแสดงเป็นกราฟแท่ง ในกราฟ **พัฒนาการตามเวลา** กด **เลือกตัวชี้วัด** เพื่อเลือกเส้นที่จะดู แสดงได้ไม่เกิน 5 ตัวชี้วัดต่อครั้ง

## วิเคราะห์รายคนด้วย AI

สำหรับ **ครูประจำชั้น** ระบบสรุปจุดเด่นและจุดที่ควรพัฒนาของนักเรียนแต่ละคน และให้ AI เขียนเป็นข้อความสองฉบับ คือ **ฉบับครู** และ **ฉบับนักเรียน** ซึ่งเขียนให้กำลังใจและแนะนำสิ่งที่ควรฝึกต่อ

ที่หน้าห้องเรียน กด **วิเคราะห์รายคน**

### ข้อความมาจากไหน

- **จุดเด่น** และ **จุดที่ควรพัฒนา** คำนวณจากคะแนนล่าสุดทันทีหลังเผยแพร่ผล ไม่ได้ใช้ AI
- **ข้อความจาก AI** เขียนใน **รอบกลางคืน** (หลังตี 1) เฉพาะนักเรียนที่คะแนนเปลี่ยน ต้องมี Gemini API key ของครูประจำชั้น (หรือ key ของเซิร์ฟเวอร์) ถ้าไม่มี key ห้องนั้นจะถูกข้ามและยังคงขึ้นว่า **ยังไม่มีข้อความ**
- ครูกด **วิเคราะห์ตอนนี้** เพื่อให้ AI เขียนทันทีได้ (ใช้เวลาไม่เกินครึ่งนาที) ใส่ **คำแนะนำถึง AI** ได้ แต่ห้ามใส่ชื่อหรือข้อมูลของนักเรียน
- ครูกด **แก้ไข** เพื่อแก้ข้อความ หรือ **เขียนเอง** เมื่อยังไม่มีข้อความ

### อนุมัติก่อนนักเรียนเห็น

นักเรียนจะเห็น **ฉบับนักเรียน** ก็ต่อเมื่อครูอนุมัติ

1. เปิดนักเรียนที่มีป้าย **รออนุมัติ**
2. อ่าน **ฉบับนักเรียน** ถ้าต้องการแก้ กด **แก้ไข** แล้ว **บันทึก**
3. กด **อนุมัติและแชร์ให้นักเรียน**

นักเรียนเห็นข้อความเป็นการ์ด **ข้อความจากครู** ในแท็บ **ทักษะ** พร้อมทางลัดไปแบบฝึก (บทที่ 20)

ถ้าไม่ต้องการอนุมัติทีละคน เปิดสวิตช์ **แชร์ให้นักเรียนอัตโนมัติ** ที่ด้านบนของรายชื่อ ข้อความที่ AI เขียนครั้งต่อไปจะถึงนักเรียนทันที ส่วนข้อความที่ร่างไว้ก่อนเปิดยังต้องอนุมัติเอง

| ป้ายในรายชื่อ | ความหมาย |
|---|---|
| **ยังไม่มีคะแนน** | นักเรียนยังไม่มีผลที่ประเมินตัวชี้วัดของห้องนี้ |
| **รออนุมัติ** | มีข้อความใหม่ รอครูอนุมัติ |
| **รอรอบกลางคืน** | คะแนนเปลี่ยนแล้ว AI จะเขียนใหม่คืนนี้ |
| **เขียนข้อความไม่สำเร็จ** | AI เขียนไม่สำเร็จ กด **วิเคราะห์ตอนนี้** หรือเขียนเอง |
| **แชร์แล้ว** | นักเรียนเห็นข้อความแล้ว |
| **มีข้อความแล้ว** / **ยังไม่มีข้อความ** | สถานะทั่วไป |

**สิ่งที่นักเรียนไม่เห็น**
นักเรียนเห็นเฉพาะฉบับนักเรียนที่ครูอนุมัติแล้ว ไม่เห็นฉบับครู รายการจุดเด่นและจุดที่ควรพัฒนาของหน้านี้ หรือข้อมูลของเพื่อน

## คลังแบบฝึกและลิงก์ทบทวน

แบบฝึกเป็นข้อสั้นๆ ที่นักเรียนทำในแอปและรู้ผลทันที ระบบแนะนำให้นักเรียนแต่ละคนตามทักษะที่ยังต่ำกว่า 75% ครูมีหน้าที่ **ตรวจและอนุมัติ** ข้อที่ AI ร่าง นักเรียนจะเห็นเฉพาะข้อที่อนุมัติแล้ว

ที่หน้าหลัก กด **คลังแบบฝึกและลิงก์ทบทวน** หรือแตะตัวเลข **ข้อฝึกรออนุมัติ**

### สร้างและอนุมัติข้อฝึก

1. กด **สร้างข้อใหม่ด้วย AI** เลือกตัวชี้วัด แล้วเลือก **สร้าง 3 ข้อ**, **สร้าง 5 ข้อ** หรือ **สร้าง 10 ข้อ** (ต้องมี Gemini API key)
2. รอไม่กี่นาที แล้วลากรายการลงเพื่อรีเฟรช ข้อใหม่จะอยู่ในแท็บ **ร่าง**
3. อ่านโจทย์ **คำตอบ** และ **คำอธิบาย** ของแต่ละข้อ ถ้าต้องแก้ กด **แก้ไข**
4. กด **อนุมัติ** ข้อจะย้ายไปแท็บ **อนุมัติแล้ว** และเริ่มแสดงให้นักเรียน

ข้อฝึกมี 3 ชนิด คือ **ปรนัย**, **ตัวเลข** (ตั้ง **ค่าที่ถูก** และ **คลาดเคลื่อนได้ ±**) และ **ตอบสั้น** (ใส่ **คำตอบที่ยอมรับ** บรรทัดละ 1 แบบ) **คำอธิบาย** คือข้อความที่นักเรียนเห็นเมื่อตอบผิด ในหน้าแก้ไขกด **บันทึกและอนุมัติ** เพื่อทำสองขั้นพร้อมกันได้

- **เลิกใช้** ซ่อนข้อจากนักเรียน ข้อจะไปอยู่แท็บ **เลิกใช้** กด **นำกลับมาใช้** ได้
- ตัวกรอง **ทุกทักษะ** ด้านบนใช้เลือกดูเฉพาะข้อของตัวชี้วัดหนึ่ง
- อนุมัติได้เฉพาะครูที่สอนวิชาของทักษะนั้น (มีการบ้านในวิชานั้นในห้องที่สอน)
- ข้อฝึกที่อนุมัติแล้วอยู่ในคลังของครูที่สร้าง ครูท่านอื่นไม่เห็น
- แอปยังไม่มีหน้าสำหรับเขียนข้อฝึกใหม่เองตั้งแต่ต้น ให้ AI ร่างแล้วแก้ข้อความแทน

### ลิงก์ทบทวน

เลือกตัวชี้วัดที่ตัวกรองก่อน แล้วกด **ลิงก์ทบทวน** จากนั้นกด **เพิ่มลิงก์** ใส่ **ชื่อ** และ **ลิงก์** (ต้องขึ้นต้นด้วย http:// หรือ https://) เช่น วิดีโอสอนหรือใบความรู้ นักเรียนที่ทักษะนั้นยังไม่ผ่านจะเห็นลิงก์ในหน้าแบบฝึก ลิงก์อยู่ในคลังของครูที่เพิ่ม ครูท่านอื่นไม่เห็น และยังแก้หรือลบจากแอปไม่ได้ จึงควรตรวจให้ถูกก่อนเพิ่ม

### นักเรียนได้ข้อฝึกอย่างไร

แท็บ **แบบฝึก** ของนักเรียนแสดงทักษะที่ยังต่ำกว่า 75% เรียงจากอ่อนที่สุด แต่ละทักษะมีข้อที่อนุมัติแล้วไม่เกิน 3 ข้อที่นักเรียนยังไม่ได้ทำใน 7 วันล่าสุด พร้อมลิงก์ทบทวน ระบบตรวจคำตอบทันทีโดยไม่ใช้ AI และนำผลไปปรับระดับทักษะของนักเรียน (บทที่ 20)

นักเรียนได้รับข้อฝึกและลิงก์ทบทวนเฉพาะจากคลังของพื้นที่ที่บัญชีนักเรียนสังกัด คือของครูที่สร้างบัญชีให้ หรือของเจ้าของห้องแรกที่นักเรียนสร้างบัญชีด้วย Google ตอนเข้าห้อง นักเรียนที่มีบัญชีจากห้องของครูท่านอื่นแล้วเข้าห้องของครูด้วยรหัสห้อง จึงไม่เห็นข้อฝึกและลิงก์ในคลังของครู
