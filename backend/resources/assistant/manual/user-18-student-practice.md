# แบบฝึกและทักษะ

Krucheck ดูจากผลการบ้านและข้อสอบว่านักเรียนเข้าใจ **ทักษะ** (ตัวชี้วัด) ใดแล้ว และทักษะใดควรทบทวน จากนั้นแนะนำ **แบบฝึก** ในเรื่องที่ยังไม่มั่นใจให้ทำในแอป ตอบแล้วรู้ผลทันที

## แท็บทักษะ

แตะ **ทักษะ** ที่เมนูหลัก

| ส่วน | ความหมาย |
|---|---|
| **ข้อความจากครู** | ข้อความสรุปจุดเด่นและสิ่งที่ควรฝึกต่อ ซึ่งครูประจำชั้นส่งให้ มีทางลัด **ลองฝึกต่อ** ไปยังแบบฝึกของเรื่องนั้น (แสดงเมื่อครูส่งให้แล้ว) |
| **กราฟตามรายวิชา** | เปิดกราฟความเข้าใจของตัวเองในแต่ละวิชา (บทที่ 21) |
| **ภาพรวมทักษะ** | จำนวนทักษะในแต่ละระดับ และปุ่ม **ฝึกทักษะที่ควรทบทวน** |
| รายการทักษะ | ทุกทักษะที่มีผลแล้ว เรียงจากที่ควรทบทวนที่สุด แต่ละทักษะบอกร้อยละ จำนวนครั้งที่ทำ และวันที่อัปเดต |

ระดับของทักษะ

| สี | ระดับ | เกณฑ์ |
|---|---|---|
| เขียว | **เข้าใจดี** | ตั้งแต่ 75% |
| ส้ม | **เข้าใจบางส่วน** | 40–74% |
| แดง | **ยังไม่เข้าใจ** | ต่ำกว่า 40% |
| เทา | **ข้อมูลยังน้อย** | ทำข้อของทักษะนั้นไม่ถึง 2 ครั้ง |

ร้อยละของทักษะเปลี่ยนทุกครั้งที่ครูเผยแพร่ผลงานชิ้นใหม่ หรือเมื่อนักเรียนทำแบบฝึก ผลครั้งล่าสุดมีผลมากกว่าครั้งเก่า ถ้าทำได้ดีขึ้น ร้อยละจะค่อยๆ เพิ่ม

## ทำแบบฝึก

แตะ **แบบฝึก** ที่เมนูหลัก () ระบบแสดงทักษะที่ยังต่ำกว่า 75% เรียงจากที่ควรทบทวนที่สุด แต่ละทักษะมีข้อฝึกไม่เกิน 3 ข้อ

1. แตะข้อที่ต้องการทำ
2. ตอบตามชนิดของข้อ
   - **ปรนัย** แตะตัวเลือกที่คิดว่าถูก
   - **ตัวเลข** พิมพ์คำตอบเป็นตัวเลข เช่น `12.5`, `-3` หรือ `3/4`
   - **ตอบสั้น** พิมพ์คำตอบ ไม่เกิน 200 ตัวอักษร
3. กด **ส่งคำตอบ**
4. ระบบบอกผลทันที: **ถูกต้อง เก่งมาก**, **ถูกบางส่วน** หรือ **ยังไม่ถูก** ถ้ายังไม่ถูกจะมี **คำอธิบาย** ให้อ่าน และบอกว่า **ทักษะนี้ตอนนี้ N%**
5. กด **ข้อต่อไป** หรือ **กลับไปหน้าแบบฝึก**

ควรรู้ก่อนทำ

- แต่ละข้อ **ตอบได้ครั้งเดียว** เมื่อส่งแล้วแก้ไม่ได้ ข้อเดิมจะกลับมาให้ทำอีกครั้งหลัง 7 วัน
- ระบบไม่เฉลยคำตอบที่ถูกให้ดู มีเพียงคำอธิบายวิธีคิด ให้ลองคิดใหม่ตามคำอธิบาย
- ผลของแบบฝึก **ไม่เป็นคะแนนในสมุดคะแนนและไม่มีผลต่อเกรด** แต่ทำให้ร้อยละของทักษะเปลี่ยน

ใต้ข้อฝึกของแต่ละทักษะอาจมี **ทบทวนเนื้อหา** ซึ่งเป็นลิงก์ที่ครูเตรียมไว้ เช่น วิดีโอสอน แตะที่ลิงก์เพื่อ **คัดลอก** แล้วนำไปวางในเบราว์เซอร์เพื่อเปิด

| ข้อความ | ความหมาย |
|---|---|
| **ยังไม่มีแบบฝึกแนะนำ** | ยังไม่มีผลที่เผยแพร่ ครูยังไม่ได้อนุมัติข้อฝึกของเรื่องนั้น ทุกทักษะอยู่ในระดับเข้าใจดีแล้ว หรือทำข้อที่มีครบแล้วใน 7 วันนี้ |
| **ยังไม่มีข้อมูลทักษะ** | ยังไม่มีผลการบ้านที่เผยแพร่ หรือยังไม่เคยทำแบบฝึก |
| **เลือกคำตอบก่อน** / **พิมพ์คำตอบก่อน** | ยังไม่ได้ตอบ |
