# ปัญหาที่พบบ่อยและรหัสข้อผิดพลาด

## รหัสข้อผิดพลาดของ AI
เมื่อฟังก์ชันที่ใช้ AI ไม่สำเร็จ แอปแสดง «รหัส AI-xxx · #เลข» เลขคือหมายเลขการเรียก AI ที่ผู้ดูแลระบบใช้ค้นในหน้า «การเรียก AI» ของ /admin
- AI-KEY-MISSING: ยังไม่มี Gemini API key → ตั้งค่า > วาง key > «ทดสอบและบันทึก»
- AI-KEY-INVALID: Google ไม่รับ key (ผิด ถูกลบ หมดอายุ หรือยังไม่เปิด Generative Language API) → ใส่ key ใหม่ หรือกด «ทดสอบอีกครั้ง»
- AI-QUOTA: โควตาหรือเครดิตหมด หรือเรียกถี่เกินไป → รอสักครู่ ตรวจ billing ใน Google AI Studio
- AI-MODEL: ไม่พบโมเดลที่ระบบตั้งไว้ → แจ้งผู้ดูแลระบบพร้อมรหัส
- AI-TIMEOUT: AI ตอบไม่ทันหรือติดต่อ Google ไม่ได้ → ลองใหม่
- AI-SERVER: Google ขัดข้องชั่วคราว → ลองใหม่ในอีกสักครู่
- AI-BLOCKED: ตัวกรองความปลอดภัยของ Google ไม่ยอมตอบ → ปรับข้อความหรือไฟล์
- AI-OUTPUT: AI ตอบในรูปแบบที่ระบบอ่านไม่ได้ → ลองใหม่
- AI-ERROR: อื่น ๆ → ลองใหม่ ถ้ายังเป็น แจ้งผู้ดูแลระบบพร้อมรหัส
- NET-OFFLINE: เครื่องเชื่อมต่อเซิร์ฟเวอร์ไม่ได้ → ตรวจอินเทอร์เน็ต
- NET-TIMEOUT: เซิร์ฟเวอร์ตอบช้าเกินไป → ลองใหม่

## Gemini API key
- ขอ key ได้ที่ Google AI Studio ควรใช้บัญชีที่เปิด billing (paid tier) เพราะ key แบบฟรีอาจให้ Google นำข้อมูลไปใช้
- key ของครูใช้ตรวจเฉพาะงานของครูคนนั้น ระบบเก็บแบบเข้ารหัสและแสดงแค่ 4 ตัวท้าย
- ปุ่ม «ทดสอบอีกครั้ง» ทดสอบ key ที่บันทึกไว้โดยไม่ต้องพิมพ์ใหม่
- ค่าใช้จ่ายดูได้ในบัญชี Google ของครู

## เข้าสู่ระบบด้วย Google
- ถ้าหน้า Google ขึ้น «Access blocked» หรือ 403 access_denied ปัญหาอยู่ที่การตั้งค่าแอปฝั่ง Google ให้แจ้งผู้ดูแลระบบ
- นักเรียนกดเข้าด้วย Google แล้วระบบบอกว่ายังไม่ผูกบัญชี: ให้ยืนยันตัวตนครั้งแรกด้วยชื่อผู้ใช้และรหัสผ่านที่ครูให้ หรือเข้าห้องด้วยรหัสห้อง ถ้าห้องผูก Google Classroom ให้ครูกด «ซิงก์รายชื่อ» แล้วลองใหม่
- ผู้ดูแลระบบดูเหตุผลรายบัญชีได้ที่หน้า «ปัญหาการเชื่อม Google» ใน /admin

## Google Classroom
- การเชื่อม Classroom หลุด: แถบเตือนขึ้นในแอป ให้กด «เชื่อมใหม่» ที่หน้าตั้งค่า
- ตอนกดเชื่อมเจอหน้า «Google hasn't verified this app»: กด Advanced แล้ว Go to … (unsafe) และติ๊กสิทธิ์ให้ครบทุกช่อง ถ้าติ๊กไม่ครบ ระบบจะบอกว่าขาดสิทธิ์ไหนแล้วให้เชื่อมใหม่

## สแกนและอัปโหลด
- สแกนใบงานใช้ได้เฉพาะแอป Android บนเว็บใช้ «อัปโหลดรูปเพื่อตรวจ»
- ภาพเบลอ มืด หรือเอียง แอปให้ถ่ายใหม่ ถ่ายบนพื้นเรียบ แสงสม่ำเสมอ ให้ทั้งแผ่นอยู่ในกรอบ
- QR ไม่ใช่ของการบ้านนี้: หยิบกระดาษผิดชุด หรือเป็นกระดาษคำตอบข้อสอบ ให้สลับโหมด
- ภาพที่ยังไม่ส่งอยู่ใน «คิวอัปโหลด» และหายเมื่อออกจากระบบ อย่าออกจากระบบก่อนคิวว่าง
- ไฟล์รูปหรือ PDF ไม่เกิน 10 MB ต่อไฟล์

## บัญชี
- นักเรียนลืมรหัสผ่าน: เมนู «⋯» ของนักเรียนในหน้าห้อง > «รีเซ็ตรหัสผ่าน» กลับเป็น 123456 นักเรียนต้องตั้งรหัสใหม่ตอนเข้า
- ครูลืมรหัสผ่าน: ให้ผู้ดูแลระบบตั้งใหม่ ถ้าเชื่อม Google ไว้ เข้าด้วยปุ่ม Google ได้ระหว่างรอ
