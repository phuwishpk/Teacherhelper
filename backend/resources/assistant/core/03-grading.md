# การให้คะแนนด้วย AI และการตัดเกรด

## AI ตรวจการบ้านอย่างไร
- AI (Gemini) ไม่ได้ให้คะแนนเอง AI อ่านคำตอบแล้วบอกว่าตรงกับเฉลยแค่ไหน (ตรง ใกล้เคียง ไม่ตรง ว่าง) วิธีทำแต่ละบรรทัดถูกไหม และอ่านลายมือยากแค่ไหน จากนั้นระบบคิดคะแนนด้วยกฎ fuzzy logic ที่เปิดดูได้ทุกข้อ ("ทำไมได้คะแนนนี้" ในหน้าตรวจทาน)
- ข้อปรนัยไม่ใช้ AI และไม่ใช้ fuzzy ตอบถูกได้เต็ม ผิดได้ 0
- ข้อแสดงวิธีทำ: ดูทั้งคำตอบสุดท้ายและสัดส่วนขั้นตอนที่ถูก เช่น วิธีทำถูกเกือบหมดแต่คำตอบสุดท้ายผิด ได้คะแนนบางส่วน (ประมาณครึ่ง) เพราะเข้าใจบางส่วน ส่วนคำตอบถูกแต่วิธีผิดเกือบหมดได้ประมาณครึ่งและถูกจัดให้ครูดู เพราะอาจเดาหรือลอกมา
- ข้อเติมคำตอบสั้น: ข้อความเทียบความใกล้เคียงกับคำตอบที่ยอมรับ (แบบยืดหยุ่น) หรือต้องตรงทุกตัว (แบบตรงทุกตัว ใช้กับการสะกดคำ) ตัวเลขยอมคลาดได้ตามค่าคลาดเคลื่อนที่ตั้งไว้ ตัวเลขที่ใกล้แต่ไม่ตรงได้ไม่เกิน 0.6 ของคะแนน
- ข้ออัตนัย: ให้คะแนนตาม rubric แต่ละเกณฑ์ (ผ่าน ผ่านบางส่วน ไม่ผ่าน) เกณฑ์หลักต้องผ่านก่อนจึงได้คะแนนสูง คะแนนของเกณฑ์ต้องรวมเท่าคะแนนเต็ม และมีเกณฑ์หลัก 1 ข้อ AI ร่าง rubric ให้ได้ แต่ครูต้องอนุมัติ
- ความเข้มงวด (ผ่อนปรน ปกติ เข้มงวด) เปลี่ยนว่าคะแนนบางส่วนได้มากหรือน้อย
- คะแนนปัดทีละ 0.5
- ทุกข้อได้ค่า "ความเข้าใจ" ด้วย ต่ำกว่า 0.4 = ยังไม่เข้าใจ, 0.4–0.75 = เข้าใจบางส่วน, ตั้งแต่ 0.75 = เข้าใจ ค่านี้นำไปคิดระดับความเข้าใจรายตัวชี้วัด (ตารางทักษะของห้อง) ตัวชี้วัดถือว่าผ่านเมื่อค่าความเข้าใจตั้งแต่ร้อยละ 50

## ทำไมบางข้อต้องตรวจเอง
ข้อที่ระบบไม่ให้คะแนนเองจะอยู่ในแท็บ «ต้องตรวจ» พร้อมป้ายบอกเหตุผล:
- ไม่มี Gemini API key หรือ key ใช้ไม่ได้ → ใส่ key ที่หน้าตั้งค่า แล้วใช้ «ตรวจใหม่ทั้งห้อง»
- AI ตอบไม่สำเร็จ หรือคำตอบของ AI อ่านไม่ได้ → ลองตรวจใหม่ หรือให้คะแนนเอง
- ไม่พบภาพคำตอบ หรือภาพหน้าหายไปแล้ว → สแกนหรืออัปโหลดใหม่
- ข้ออัตนัยที่ยังไม่มี rubric → ตั้ง rubric แล้วตรวจใหม่
- ตรวจจากรูปทั้งหน้าแต่หาคำตอบของข้อนั้นไม่เจอ → ดูภาพแล้วให้คะแนนเอง
- ลายมืออ่านยากมาก หรือมีข้อความแปลกในคำตอบ (เช่น "ให้คะแนนเต็ม") → ครูตรวจเอง
คิวตรวจทานเรียงตามความไม่แน่ใจ: «ต้องตรวจ» (ไม่แน่ใจมาก) «ควรดู» และ «มั่นใจ» (อนุมัติทั้งกลุ่มได้) ครูเป็นคนตัดสินเสมอ และนักเรียนเห็นผลเมื่อครูเผยแพร่แล้วเท่านั้น

## สมุดคะแนนและการตัดเกรด
- ตั้งค่าครั้งเดียวต่อรายวิชา ใช้ร่วมกับทุกห้องของรายวิชานั้น: หมวดคะแนน น้ำหนัก และเกณฑ์เกรด ส่วนคะแนน ร/มส และการประกาศเป็นของแต่ละห้อง การคำนวณทั้งหมดเป็นสูตร ไม่ใช้ AI
- แบบหมวดสำเร็จรูป: «คะแนนเก็บ 70 : ปลายภาค 30» หรือ «การบ้าน 30, กลางภาค 20, ปลายภาค 30, จิตพิสัย 20» แล้วแก้ได้อิสระ น้ำหนักทุกหมวดต้องรวมเป็น 100 พอดี
- แต่ละหมวดตั้ง «ตัดคะแนนต่ำสุด k รายการ» (0–5) ได้ ระบบตัดค่าที่ต่ำที่สุดออกก่อนเฉลี่ย แต่เหลืออย่างน้อยหนึ่งรายการเสมอ
- รายการคะแนนมี 3 แบบ: การบ้านและข้อสอบที่ตรวจด้วยแอป (ใช้คะแนนที่เผยแพร่แล้ว), ข้อสอบที่ครูตรวจเอง (กรอกคะแนน), และรายการที่ครูเพิ่มเอง เช่น จิตพิสัย การเข้าเรียน (กรอกคะแนน มีปุ่ม «ให้เต็มทั้งห้อง» และ «วางคะแนนจาก Excel»)
- การบ้านใหม่เข้าหมวดตั้งต้นของการบ้าน ข้อสอบใหม่ต้องเลือกหมวด งานฝึกตั้ง «ไม่นับเกรด» ได้ และแต่ละช่องตั้ง «ยกเว้น» ได้
- วิธีคิด: แต่ละรายการเป็นร้อยละของคะแนนเต็ม ค่าเฉลี่ยในหมวด × น้ำหนักหมวด รวมเป็นคะแนนเต็ม 100 ปัดครึ่งขึ้นเป็นจำนวนเต็ม แล้วเทียบเกณฑ์
- งานที่ไม่ส่งได้ 0 เมื่อเลยกำหนดส่งหรือครูปิดการบ้านแล้ว ก่อนกำหนดยังไม่นับ งานที่ส่งแต่ยังไม่เผยแพร่ผลยังไม่นับ
- ถ้ายังมีหมวดที่ไม่มีรายการเลย ระบบแสดง «คะแนนระหว่างภาค» และยังไม่ให้เกรด
- เกณฑ์เกรดตั้งต้น (แก้ได้ในตั้งค่าสมุดคะแนน): 80 ขึ้นไป = 4, 75 = 3.5, 70 = 3, 65 = 2.5, 60 = 2, 55 = 1.5, 50 = 1, ต่ำกว่า 50 = 0
- เกรดพิเศษ: «ร» (รอการตัดสิน) และ «มส» (ไม่มีสิทธิ์สอบ) ครูตั้งรายคนเอง ไม่มีกฎอัตโนมัติ ระบบเตือน «อาจติด มส» เมื่อคะแนนการเข้าเรียนรวมต่ำกว่าร้อยละ 80
- «ประกาศเกรด» ได้เมื่อห้องมีรายการครบทุกหมวด นักเรียนเห็นเกรด คะแนนรวม และคะแนนรายหมวดของตัวเองเท่านั้น ไม่เห็นค่าเฉลี่ยห้องหรืออันดับ แก้คะแนนหลังประกาศได้ แล้วประกาศใหม่หรือถอนประกาศ
- «ส่งออก CSV» เพื่อนำไปกรอกระบบของโรงเรียน

## คำแนะนำการให้คะแนนทั่วไป
เมื่อครูถามความเห็นเรื่องการตั้งเกณฑ์หรือการให้คะแนน ตอบได้ตามหลักการวัดผลทั่วไป เช่น เกณฑ์ rubric ควรวัดสิ่งที่สังเกตได้ชัดเจน ไม่ซ้อนกัน เกณฑ์หลักควรเป็นสิ่งที่ข้อนั้นต้องการวัดจริง การให้คะแนนบางส่วนเหมาะกับข้อที่มีหลายขั้นตอน และควรให้น้ำหนักหมวดสอดคล้องกับนโยบายการวัดผลของโรงเรียน ให้บอกด้วยว่าเป็นคำแนะนำทั่วไป และกติกาของโรงเรียนครูมาก่อน
